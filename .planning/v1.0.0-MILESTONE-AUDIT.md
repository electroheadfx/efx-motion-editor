## Cross-Phase Integration (gsd-integration-checker, 2026-09-11)

All eight seams between phases verified **WIRED** against the code:

1. **Document lifecycle** — create (`AddFxMenu.tsx:141-158`) → launch context → child sync (`PhysicsPaintStudio.tsx:3803-3867`) → main listener → save (`projectStore.ts:749-797`) → reopen gate/load/hydrate (`projectStore.ts:851-861`, `efxPaintStore.ts:1695-1704`). WIRED.
2. **Track addressing** — projection iterates `document.tracks` by id; install throws on mismatch; all Studio reads route through `studioActiveTrackId()`; per-track revisions feed the flattened cache key. WIRED.
3. **Compositor parity** — one `getFlattenedFrame` entry point consumed by Studio monitor, preview, and export; parent opacity/blend applied exactly once at the main-renderer boundary. WIRED.
4. **Background → compositor** — `_resolveDocumentFondInstruction` reads only the document fallback; clip/gap resolution via the single resolver; gaps draw fallback beneath. WIRED (one fragile edge below).
5. **Reveal leak containment** — bake writes ordinary real-key records; `_referenceSourceImages` read only by bake + revision term; ghost is a separate overlay. WIRED.
6. **Audio ↔ cursor** — `getCurrentAppFrame` feeds seek/scrub; main audio suppressed via ownership; release on close/unmount. WIRED.
7. **52.1 runtime cutover** — bytes-only frames; Rust commands registered and invoked; base64 confined to the JSON transport boundary and script thumbnails. WIRED.
8. **E2E flows** — all three traced statically end-to-end with no break: (i) create → paint → add track → cross-track drag → Bg import → save/reopen; (ii) reference → reveal rail → baked records → compositor → undo by reference; (iii) play/seek/scrub/close with audio.

**Warnings (non-blocking, map to requirement IDs):**

- **Hide/solo truth-table divergence** (TML-04, CMP-02): the Studio predicate arms solo over all tracks; the compositor authority arms solo only over visible tracks. A hidden+soloed track makes Studio hide a track the flattened output still renders. Verified in code at `previewRenderer.ts:97` vs `efxPaintHideSolo.ts:36`.
- **Fond paper preload gate** (BKG-07/09, CMP-01): the export paper-texture gate reads per-track metadata while the fond authority is the document fallback; works only because `useRotoBackgroundMetadataSync` dual-writes — fragile if the sync lags.
- **Unverifiable offline** (DOC-05, CMP-01): refs-only frame carriers in the main window have no traced sidecar-read path; all producers traced mount records with bytes, but the reopen path could not be executed. Flagged for Phase 53 native UAT.
