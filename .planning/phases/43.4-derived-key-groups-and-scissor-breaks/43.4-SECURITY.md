# Phase 43.4 — Security

> Per-phase security contract: threat register, accepted risks, and audit trail.

---

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| child view -> resolver | Untrusted toolbar/cursor/session-derived intent (scissor target, move/delete key lists, destination frames) crosses into the pure canonical edit authority | keyId + member-key lists + destination frames |
| child -> parent bridge | Intent + proposal cross the transport; parent revalidates before store replacement | proposal + retained publication (keys, gaps, breaks) |
| session -> commit port | Retained immutable publication crosses to the canonical edit path; session never recomputes it | retained objects forwarded by identity |
| prepare-time snapshot -> commit-time authority | Document authority (including breaks) may change between prepare and commit | proposalVersion revision fingerprint |
| preview paint -> accepted document | Presentation-only ghost/gap/selection state must never read as accepted truth | DOM attributes, pointer events, session signals |
| history replay -> store | Undo/Redo re-applies immutable before/after documents to the canonical store | immutable document snapshots |
| persistence round-trip | Serialized documents cross save/reopen; strict parsing is the integrity gate | serialized document |
