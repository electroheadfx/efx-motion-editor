<objective>
Define the one persisted shape for a vector stroke: an optional anchor list plus an explicit render
mode, carried inside the existing opaque engine block, validated fail-closed, and copied through
every seam that today lists fields by hand.

Purpose: the phase's single largest silent-failure risk is a field that exists in memory but is
dropped by one of the hand-written field lists on the way to disk (`toStudioStroke`'s engine block,
the wire codec, then 61-05's AQTL and `restoreAquarelleRecordTimeline`). This plan establishes the
shape and the first two seams, so 61-05 has a single source of truth to extend.

Output: `payload/vectorPath.ts` and its test, the two new optional fields on the runtime and payload
stroke types, the conditional engine-block copy, the wire validation, and the package re-export.
</objective>

Project law for this plan: `renderMode` is an explicit per-stroke persisted discriminator that any
stroke may carry, never inferred from a zeroed parameter and never a global setting (D-12); a width
factor is sparse, so "absent means 1.0" and a uniform stroke writes no key (D-10). No
backward-compatibility code for old projects, so the new fields are optional-and-absent rather than
migrated; the engine block is the opaque slot where vector data lives, so the host generic contract
(`StudioStroke<P>`) is untouched; validators return null and never throw.
