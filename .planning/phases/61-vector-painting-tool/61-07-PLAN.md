<objective>
Add the second deposit mode inside the one engine: a clean sweep along the stroke spine, selected by
a per-stroke discriminator, discoverable through a new brush preset, and proven clean on real pixels
rather than assumed from the parameters being zero.

Purpose: VEC-04's "brush type and colour are per stroke" only becomes visible if the simple path is
one click away. C-04 is also explicit that this branch belongs in `Engine.ts` `trace`/`stamp`, where
the sampling law already lives — `aquarelleBake.ts` stays untouched. D-14 makes the mode a stroke
property rather than a path property, so this plan carries both halves of the hand-painted case: the
live deposit reads it from the brush, and the record path stamps it onto the stroke.

Output: the ribbon stamp branch, the render-mode argument on the script path, the `simple-ribbon`
preset with its crisp thumb, the eraser-branch filter, the record-time mode stamp, and the
mode-parameterised determinism arm.
</objective>
