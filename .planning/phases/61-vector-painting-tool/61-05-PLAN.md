<objective>
Persist the vector fields into the binary script payload: AQTL v2 carries the anchor block, the
sparse width factors and the render mode, refuses v1 outright, and survives the reopen restore path
that today rebuilds a stroke field by field.

Purpose: this is the second and third links of the persistence chain. The codec is the only layer
that can lose information — Rust stores the payload opaquely and accepts unknown keys — and
`restoreAquarelleRecordTimeline` silently drops any field it does not list, so a vector stroke that
survives the codec can still reopen as a plain painted stroke. Both seams are closed here.

Output: AQTL v2 encode/decode, the v1 refusal, the reopen seeding, and the round-trip plus
reopen-lossless pins.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| AQTL bytes -> decoder | Persisted binary is untrusted; a truncated or hostile stream must not produce a stroke |
| decoded stroke -> restore path | The rebuilt runtime stroke decides what a reopened document can be edited as |
