<objective>
Make render mode and the collapsed wet globals editable in the Paint tab: a two-segment `Render` row at
the top and an `Advanced — wet globals` disclosure that only exists in simple-ribbon mode.

Purpose: VEC-04's user surface. The row is a string discriminator, so it must not ride the numeric
field path; the disclosure must not redesign the watercolor tab. The commit is the risky half: one
entry for the whole selection, anchors or none, and no stroke's anchor list ever created, dropped or
rewritten by a mode write (D-12/D-14: the mode is a stroke property, not a path property).

Output: the pure readings, the two mounts, the batch render-mode seam with its one-entry wrapper, and
the tests that pin the mount points, the mixed state, the zero state and the single commit.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| render-mode option click -> every selected stroke | A batch field write must touch the mode and nothing else in the stroke |
| wet-global stepper -> stored params | Untrusted numeric entry reaches persisted paint params |
