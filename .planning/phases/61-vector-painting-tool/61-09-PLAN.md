<objective>
Draw a vector path end-to-end: place anchors on the canvas, see the spine, finish the path, and have
it land as one recorded stroke that bakes like any other.

Purpose: this is VEC-01's user-visible half. The architecture risk is not the drawing math — it is
placing a new interactive layer beside the existing one without giving it bake authority, and
committing through the single seam that already guarantees one revision bump per stroke.

Output: the handle geometry module, the overlay with its draw gesture, the mount in
`AquarelleCanvasLayer`, and the tests that pin hit priority, counter-scaling, adjacency and the
one-entry commit.
</objective>
