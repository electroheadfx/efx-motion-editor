<objective>
Edit a committed vector path end-to-end: grab an anchor, drag a handle, insert and delete anchors, set
a width across a multi-selection, and have every completed gesture land as exactly one undo entry that
persists.

Purpose: VEC-02's second half. The drawing code already exists; the risk here is undo granularity and
data integrity — a path edited on screen but left stale in the recorded stroke replays at the old
place, and a commit looped per anchor floods the history. Both are pinned by test, not by review.

Output: the edit helpers, the edit gesture, the path-update seam with its one-entry wrapper, the
anchors-aware whole-stroke move/transform, and the refusal surface for an unreadable path.
</objective>

Project law for this plan: grabbing an auto-smooth anchor promotes it to Bézier permanently, with the
derived handles frozen (D-03) — there is no auto-with-override state. Width edits go through the
numeric stepper's commit, never a canvas drag of the envelope (D-08 defers on-canvas width handles).
`efx-preact-reactivity` — the overlay reads signals in its body and uses `.peek()` in handlers. The
replace-never-mutate snapshot law in `aquarelleRecordState.ts` is load-bearing for undo: a stroke
object is REPLACED and its entry is written at the SAME timeline index. The overlay still owns gesture
only; the layer and the Studio own commit authority.
