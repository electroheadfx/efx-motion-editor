<objective>
Make the Studio's three silent refusals say and do the truth (WR-01, WR-02, WR-03).

Purpose: each of the three seams currently discards a boolean that the user can see the consequence of —
Shift+A writes an invisible selection under the wireframe, a failed path-edit re-bake claims a restore the
revision guard refused, and a vector stroke committed during an in-flight bake keeps no pixels and no
retry. None is a vector-model bug; all three are refusal paths that lie by omission.

Output: three guard clauses in three existing handlers, each pinned by source text in the Studio suite.

Project law for this plan:
- 61-17 (G-6 / D-16): the wireframe view is a no-capture view and `setAquarelleSelectMode(true)` refuses
  entry outright while it is on (`aquarelleStrokeSelection.ts:341`). The rail's Select button is already
  `disabled` under wireframe; Shift+A is the only path that bypasses that gate, which is exactly WR-01.
- 261029-lsr / :6139 precedent: a re-seat of the attempted side is the shipped way to make a
  revision-authoritative restore survive a revision bump — `reanchorAquarelleEditFromLiveContent` is
  content-checked, so a foreign mutation still fails closed and the honest copy fires.
- 261101-o2m: `draftPixelsDirty` is the ONE "sheet is stale, one settle will fix it" invariant; the save
  gate already defers while it is set, so arming it is containment, not a new state.
- 61-15: a vector stroke paints no engine dabs — its ONLY pixels come from a re-bake. A discarded false
  therefore means the stroke is in the script and nowhere on screen until some later settle.
</objective>
