<objective>
Close the three INFO/round-two findings that let the sheet and the settle lie by silence (WR-04, IN-02, IN-03).

Purpose: a path edit anchored to a stroke the user no longer has selected, a track switch that silently does
nothing, and an Anchor width stepper that snaps back with no explanation are all the same defect — a refusal
with no consequence and no words.

Output: a target-aware exit predicate with a working effect dependency, one bounded busy-settle line, and an
Anchor width commit that reports its refusal through the shared capsule.

Project law for this plan:
- 61-11 (T-61-37): the path-edit exit is a render-body MARKER (`pathEditExitRequested`) consumed by the ONE
  shipped lifecycle effect. The marker only reaches that effect when a dependency changes — the current deps
  `[open, bundle, pathEditGateEnabled]` do not change when a different single stroke is selected, which is
  precisely why WR-04 survived.
- 61-11 / 61-19: `resolvePathEditGate.enabled` answers "may the Edit path button be pressed", so it must stay
  true for a single vector stroke with NO edit open. Target awareness belongs to the EXIT predicate, not the
  gate.
- 261101-o2m (D-04/D-05): `settleDraftScript` is the ONE recompute; its callers fail closed on false. The
  wireframe branch already publishes `WIREFRAME_SETTLE_REFUSED_MESSAGE`; the busy branch must publish in the
  same shape.
- 261101-o2m (`armDraft` precedent): the bundle method owns the reason and the dialog branches on the result —
  the dialog never imports the Studio's capsule.

Retargeted shipped assertions (the ONLY existing assertions this plan edits; each is enumerated in its task):
1. `PhysicsPaintStrokeSettingsDialog.test.ts` — the lifecycle region's END marker literal becomes the new
   dependency tail.
2. `strokeSettingsModel.test.ts` — the three `shouldExitPathEdit` calls gain the two new arguments.
3. `PhysicsPaintStudio.test.ts` — none; the settle and bundle seams are new groups only.

Out of this gap-closure scope — deferred, never planned here: the path-edit drag lifecycle (61-28), the G-17
replay law (61-29) and every paint re-bake concern.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| selection -> open path edit | The edit holds anchor indices for one stroke; a selection change that does not close it lets the sheet write to a stroke the user is no longer looking at. |
| settle -> navigation | The settle is the only gate before a frame or track switch; a silent false aborts the navigation with no trace. |
| dialog -> Studio capsule | The dialog is engine-free; a refusal it cannot publish is a refusal the user never sees. |
