<objective>
Give the edit path an entrance and its per-vertex width control: the `Edit path` header button in the
Stroke settings sheet and the `Anchor width` stepper in the Paint tab.

Purpose: VEC-02 needs a way in that cannot strand the user in a mode pointing at nothing, and VEC-03
needs the width control the whole feature exists for — including the readout that must reflect the
real per-vertex radius rather than the `scriptScale` value that clamps at 1.0.

Output: the pure model helpers, the two mounts, the bundle members that read anchors and apply a
width, and the tests that pin the disabled reasons, the empty caption, the mixed state and the
one-edit commit.
</objective>

AND shown on canvas as a per-vertex envelope (D-08), and the value is a multiplier of the stroke's
brush size, never a pixel radius (D-09). `efx-preact-reactivity` — the dialog reads signals in its body
and writes them only from handlers. The Paint tab's shipped watercolor fields stay byte-identical: the
new block is inserted under `Size` and adds nothing to the existing field list. `MULTIPLIER_MIN` is not
touched (UI-SPEC: the anchor band is deliberately wider at the bottom).
