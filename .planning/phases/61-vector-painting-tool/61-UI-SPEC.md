## Interaction Contract

### 1. Tool rail — the 5th entry (D-05 / C-01)

Mount point: `WATERCOLOR_RAIL_TOOLS` (`app/src/components/physic-paint/view/PhysicsPaintToolRail.tsx:53-63`), rendered by the map at `:114-139`.

- **Icon** `PenTool` size 18 (the map's `<Icon size={18} />`). `PenTool` already appears as a stroke-row action in `components/sidebar/StrokeList.tsx:228` at size 11 — the rail's 18px + label disambiguates; do not pick a second icon for the rail.
- **Label** `Vector pen`. **Shortcut** `V`. `V` is free: the keymap binds it only with `meta` (`physicsPaintStudioKeyboard.ts:196`); bare `V` is unbound. Add it beside the `b/w/e/p` arm at `:365-374`, gated by `isPaintEditMode()` and the existing text-field guards.
- **Separator** above it: the derived 1px `#5a5e63` rule, `aria-hidden`, 21px wide, `margin: 1px 0`. This is the only new rail element; it is what makes "visually separated" true at the existing 7px gap.
- **Button grammar**: identical to the paint row — `class={physics-paint-icon-button${isActive ? ' active' : ''}}`, 35×35, `aria-label`, `aria-pressed`, `title`, plus `data-testid="aquarelle-vector-pen-toggle"`.
- **Host tool, not a paint tool.** Like the Picker (`:140-143`), the vector pen sits **outside** `WATERCOLOR_RAIL_TOOLS` and outside the `AquarelleTool` union. Latching it must not change `aquarelleActiveTool`. This is the shipped precedent and it keeps the record path unaware of a non-depositing tool.

| `Move/Select` (amber) + spline-pointer pressed (blue) | spline-pointer `aria-pressed="true"` | the selected vector stroke's spine, anchors, handles and envelope, editable |

- Pressing `Vector pen` clears Select, the picker and path-edit, and enters **draw**.
- Pressing any paint tool or the vector pen while path-editing clears path-edit.
- Closing the sheet clears path-edit (it already leaves Move/Select and clears the selection — `PhysicsPaintStrokeSettingsDialog.tsx:512-526`).
- **Draw-mode input law:** click places an anchor (auto-smooth); **Alt+click** places a corner (Bézier with zero-length handles); **Enter** or **double-click** finishes; **clicking the first anchor** finishes at that anchor without closing the path; **Escape** cancels the whole in-progress path (zero strokes committed, zero undo entries).
- **Exactly one undo entry per finished path**, and one per completed edit gesture thereafter (insert, delete, handle drag, anchor drag, width commit). A no-op gesture produces zero.

### 6. Wireframe rendering law (D-15)

Draw order inside the existing overlay (bottom → top):

1. **Envelope** — for every stroke on the sheet. Vector: the width profile swept along the spine. Hand-painted: the existing band from `buildStrokeBand` (`aquarelleStrokeBand.ts`) — import it, never rebuild it. Fill = stroke colour @0.14 selected / @0.07 unselected; edge 3.5px selected / 1.5px unselected, `vector-effect="non-scaling-stroke"`.
2. **Spine** — `#38bdf8` 2px when selected; `#111111` @0.7 2px under `#ffffff` @0.9 1px otherwise (the shipped polyline law).
3. **Rungs** — a 1px (non-scaling) perpendicular tick at each anchor that carries an **explicit** sparse width factor, length = that anchor's envelope width. Two-pass outline. **No rung for an absent factor.**
4. **Anchors** — auto-smooth: circle r 3.5, fill `#38bdf8`; Bézier: square 9×9 (`SCRIPT_TRANSFORM_HANDLE_SIZE_PX`), fill `#f59e0b`. Both with a `#111111` 1px stroke.
5. **Handles** — drawn **only** for Bézier anchors: two circles r 3.5 fill `#f59e0b`, joined to the anchor by a 1px `#f59e0b` @0.6 line. An auto-smooth anchor draws none — grabbing its derived tangent promotes it (D-03) and the dots appear. **The promotion is legible as a shape change (circle → square) and a colour change (sky → amber).**
6. **Existing transform box / serial badge / lift ribbon** — unchanged, on top.

**Zoom law.** Spine and envelope are doc-space and scale with zoom. Anchors, handles and rungs are screen-space fixed: 9px square, r 3.5, 1px non-scaling strokes, 8px hit pad — the same law as `scriptStrokeTransform.ts:67-73`. Hit-testing priority: handle → anchor → spine → stroke (VEC-02 pins this at 8px pad at any zoom).
