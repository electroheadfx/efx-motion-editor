<objective>
Answer the five ROADMAP spike questions with measured numbers before a single line of the vector
data model is written: segment-runs versus payload-extension seam quality, the sampling law at
1x/4x/16x tick density, the seam step metric across segment joins, dab-count cost against stroke
count at the three target canvas sizes, and byte-identity across runs.

Purpose: the renderer — not the pen tool — is this phase's scope risk. Every later plan inherits a
decision (which seam strategy, which sampling density, what reference stroke count the wireframe
must stay responsive at, which width channel) that is expensive to reverse once the payload is
persisted. This plan buys those numbers first.

Output: `probe/vector-spine/` (probe.ts, index.html, run.mjs) plus the committed `result.json`
evidence and a single verdict string that the executor copies into this plan's SUMMARY. No product
file is created or modified by this plan.
</objective>
