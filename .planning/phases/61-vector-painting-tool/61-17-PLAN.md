<objective>
Make the four input surfaces mutually exclusive by construction: entering Select or the color picker
releases the vector pen and closes an open path edit, at the one choke point each surface already owns.

Purpose: G-6. `61-VERIFICATION.md` and CR-06 found that `setAquarelleSelectMode` disarms the picker and the
rail-motion mode but never the vector pen, and that the pen overlay draws at a higher z-index than the
Select overlay — so with the pen latched, turning Select on produces a Select surface that cannot receive
a single click, and the latch has no visible way out. The picker has the same hole. Fixing it per caller
would leave the next entry route broken; fixing it at the two choke points closes every route at once.

The obstruction is architectural: `vectorPathSession.ts` already imports `setAquarelleSelectMode`, so a
reverse import is a cycle, and `aquarelleColorPicker.ts` documents a one-way edge for exactly this reason.
The plan therefore lifts the pen / path-edit / anchor-selection latches into a dependency-free leaf that
both entry modules may import. Every shipped import path keeps working through a re-export.

Output: the leaf and its tests, the two choke-point gates, the re-exported session surface, and the
replaced import-list pin.
</objective>
