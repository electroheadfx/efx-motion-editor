<objective>
Stop the colour picker surface from rendering during an open vector path edit (G-19).

Purpose: `enterPathEdit` already disarms the picker, but Alt is the path edit's handle-break modifier and
the Alt keydown re-arms the temporary picker (`setAquarellePickerAltHeld(true)`), so the Pipette visor
reappears over the canvas the moment the user breaks a tangent. The user's report: "Just need to hide the
color picker for vector edit."

Output: the one armed verdict and the dispatch-time probe both stop at an open edit, and an Alt keydown
inside the edit writes nothing.

The picker never becomes a document concept: this is session state only, and no stroke, script or `.mce`
field changes.
</objective>
