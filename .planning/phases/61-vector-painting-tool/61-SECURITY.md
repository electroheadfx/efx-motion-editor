# Phase 61 — Security

> Per-phase security contract: threat register, accepted risks, and audit trail.

---

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| pointer/keyboard input -> session tool state | Untrusted pointer clicks and key events latch a drawing or editing mode | Anchor coordinates, modifier chords |
| session state -> document | The vector tool must never write into the saved document | Render mode, width factors, anchors |
| AQTL binary payload -> engine block | Disk bytes are parsed into the opaque engine slot | Anchors, sparse widths, `renderMode` |
| TypeScript types <-> Rust models | A `.mce` field must exist in both languages | `MceAquarelleAnchor`, `MceAquarelleVectorPath` |
| engine -> raster | Per-sample width factor feeds the deposit path | Width factors above the 1.0 footprint ceiling |
| session view flags -> cache key | Wireframe / path-edit flags are view-only | Booleans that must never reach the flattened cache key |
| package installs | Dependency surface | npm packages |
