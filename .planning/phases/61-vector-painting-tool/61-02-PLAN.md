<objective>
Land the pure geometry module the whole phase indexes into: anchor kinds, the auto-handle law,
arc-length path evaluation, and the sparse per-anchor width law — proven by golden numbers before
any engine, payload or UI code depends on it.

Purpose: every later plan calls into this module (the adapter for width factors, the overlay for
the spine and handles, the codec for the anchor shape). Getting the handle law and the station
ordering wrong here means re-deriving them in four places later, and the width law is the one place
C-03 can silently regress to a clamp.

Output: `src/vector/spine.ts` with its test suite, plus the determinism contract's source scan
widened to the new `src/vector` root in the same commit.
</objective>
