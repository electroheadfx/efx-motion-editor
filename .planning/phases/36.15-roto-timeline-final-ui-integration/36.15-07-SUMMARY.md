## Decisions Made

- **Discard availability is derived state inside the existing availability computed** — busy/disposal-pending takes precedence over clipboard presence, exactly mirroring how copy/apply reasons treat `unavailable`; no new signal was added (D-12).
- **The Discard button does not route through the panel's `IconButton` helper** — that helper uses native `disabled`, which the guarded contract forbids; the button renders as its own element replicating the Plan 01 row pattern with the panel's `physics-paint-script-icon-button` visual class for toolbar consistency.
- **The positioned tooltip anchor reuses `.physics-paint-roto-key-icon-action`** (position: relative, inline-flex) so the absolutely positioned styled tooltip anchors correctly with zero CSS changes — the plan's file list excludes the stylesheet and the existing `repeat(6, ...)` toolbar grid contract test stays green.
- **The strip suite's stale positive assertion was flipped to a negative lock** (`not.toContain('onDiscardRotoScript')`) rather than deleted, keeping the D-11 test meaningful as a guard against reintroduction.
