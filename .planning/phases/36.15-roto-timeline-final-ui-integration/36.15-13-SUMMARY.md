## Accomplishments

- **Task 1 — Action-row padding + sidebar default proportions (Gap I):**
  - **I-1 (action-row padding):** `.physics-paint-roto-action-row` gains `padding-bottom: 6px`. Because the stylesheet sets `box-sizing: border-box` globally, the padding shrinks the band's content box (34px → 28px around the 26px groups) instead of growing the band — the 34px band, the 161px strip shell, and the studio grid third track are untouched, so no Gap H-6-style band-sum relaxation was needed.
  - **I-2 (sidebar default proportions):** the Plan 12 equal-thirds defaults (`useState(100 / 3)` twice) are replaced by named constants derived from the user's spec — `DEFAULT_SHARE_SUM = 425 + 213 + 340`, `DEFAULT_BRUSH_SPLIT = (425 / DEFAULT_SHARE_SUM) * 100`, `DEFAULT_TOOL_SPLIT = (213 / DEFAULT_SHARE_SUM) * 100` — so brush color, tool, and scripts/onion/motion open at 425:213:340 of the content height (sidebar height minus the two fixed handles). The fixed grab-handle bands move 28px → 32px to match the spec's "32px drag handle"; grab-resize behavior (each handle resizes only its neighbors, 15% minimum share, pointer capture + ArrowUp/ArrowDown) is unchanged from Plan 12.
  - **I-3 (color-section dead space):** the shared `.physics-paint-options-tab-panel` rule keeps its `padding: 20px 14px 14px` (the tabbed Onion/Motion panels still need the 20px separation under the tab strip); a new `.physics-paint-single-tab-panel { padding-top: 0 }` override — placed after the shared rule so it wins at equal specificity — removes the dead space at the top of the chrome-less brush color section, which now starts directly with the color picker.

## Decisions Made

- **Ratios, not absolute pixels.** The user's absolute example (425+32+213+32+340 = 1042) exceeds the 976px sidebar, so the defaults are proportional shares of the content height — exactly the plan's key_links reading. The ratio math lives in named constants so the spec numbers (425, 213, 340) stay visible in source.
- **The handle band is 32px, per the spec.** The plan's must-have truth and objective both fix the handles at 32px ("the two fixed 32px handles"), so the Plan 12 28px band moved to 32px; the resize interaction contract (neighbors only, 15% minimum, keyboard parity) is untouched.
- **Gap I-1 needed no band-sum relaxation.** Global border-box sizing means `padding-bottom: 6px` re-weights the existing clearance inside the 34px band (1px top / 7px bottom around the 26px groups) instead of growing it; the Gap I contract test locks the intact 34px/161px geometry so a future regression to content-box or a height bump fails loudly.
- **The dead-space fix is an override, not a shared-rule edit.** `.physics-paint-options-tab-panel`'s 20px top padding still serves the tabbed Onion/Motion panels; the chrome-less color panel opts out via `.physics-paint-single-tab-panel { padding-top: 0 }`, source-ordered after the shared rule.
