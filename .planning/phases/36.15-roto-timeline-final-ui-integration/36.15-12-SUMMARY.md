# Phase 36.15 Plan 12: UAT Gap H Closure — Chrome-less Sidebar Thirds, Selection Offset, Taller Bottom Band Summary

## Accomplishments

- **Task 1 — Sidebar thirds with grab resize + selection offset + taller bottom band (Gap H):**
  - **H-1/H-2 (tab chrome removal):** the `physics-paint-options-tabs physics-paint-single-tab` tablists and their always-active tab buttons are removed from both single-tab sections; each section renders its tab-panel content directly. Exactly one tablist with three tabs remains — the lower [Scripts, Onion, Motion] group, untouched. The `.physics-paint-tab-brush` / `.physics-paint-tab-tool` CSS selectors are retired in the same commit.
  - **H-3/H-4 (three resizable thirds):** the 50/50 two-pane split became a five-row grid — `minmax(0, brushSplit fr) 28px minmax(0, toolSplit fr) 28px minmax(0, remainder fr)` — with `useState(100 / 3)` defaults so Brush color, Tool, and Scripts/Onion/Motion share the sidebar height in equal thirds. Each section owns its `SidebarScrollArea` (three interactive scroll areas). A second 28px `GripHorizontal` grab handle (same look, pointer-capture drag, and ArrowUp/ArrowDown keyboard step as the existing one) sits between the brush and tool sections; handle 1 keeps brush+tool constant (scripts untouched), handle 2 keeps brush fixed (scripts absorbs), and every section keeps a 15% minimum share via `MIN_PANE_SPLIT` clamps on both pointer and keyboard paths. Distinct aria-labels ('Resize brush color and tool sections' / 'Resize tool and scripts sections') with dynamic aria-valuemax/valuenow.
  - **H-5 (selection offset):** `padding-left: 4px` on `.physics-paint-timeline-scroll` — the shared container of ruler, lane, and action row — so the selected frame-0 cell's ring (2px outline + 1px offset + 1px shadow) is no longer clipped at the scroll edge. The derived 2160px widths, 18px abutting cells, and 54px ruler ticks are untouched, so ruler-to-cell alignment stays exact.
  - **H-6 (taller bottom band, user-approved relaxation):** the action-row band grows 28px → 34px — the smallest height giving the 26px groups (identity pill, bare tools group, Key spacing pill) a clear 4px of top and bottom padding under the row's existing `align-items: center`. The band sum becomes 46+1+28+38+34+14 = **161px**; the strip shell and the studio grid third track move 155px → 161px in the same commit, and every other band keeps its Plan 06 height. The band-sum contract test is updated in the same commit per the plan's key_links.

## Decisions Made

- **34px is the smallest band with clear padding.** The three bottom-row groups stay 26px (icon buttons, identity pill, Key spacing pill), so 34px yields exactly 4px of visible padding above and below each centered group; the total becomes 161px, documented in the band-sum contract test and the strip/studio CSS comments.
- **Each handle resizes only its neighbors.** Handle 1 holds brush+tool constant so dragging it never disturbs the scripts section; handle 2 holds brushSplit constant so scripts takes the slack. This matches the user's per-section resize model and keeps drags local.
- **The selection offset lives on the shared scroll container, not the lane.** A per-lane offset would have required compensating the ruler to preserve tick alignment; padding on the common parent shifts all three bands together, leaving the derived 2160px geometry untouched.
- **Tab roles are removed with the chrome.** Orphaned `role="tabpanel"` wrappers without a tablist would be invalid ARIA; the content divs keep their styling class hooks only.
