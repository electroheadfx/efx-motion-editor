- Dead text-button machinery (`runRotoKeyUtilityAction`, press-props helpers, pressed-state) removed with the cutover.

## Decisions Made

- **aria-describedby targets a persistent sr-only reason span**, not the transient tooltip element, so the accessible description resolves whenever a reason exists while the visual tooltip mounts only when visible.
- **Escape listener registered only while visible** (not for the component lifetime), mirroring the strip drag-session listener discipline; unmount cleanup is idempotent and mountedRef-guarded.
- **Reasons flow through `getRotoKeyUtilityDisabledMessage`** (which already defers to physicalActions insert/delete reasons and sessionKeyAvailability paste/disabled reasons) and `scriptAvailability.copyDisabledReason`/`applyDisabledReason` directly — the view never shortens or re-derives (D-12).
- **Tracer feedback gate run in autonomous style**: the tracer `<verify>` is fully automated (vitest), project mode is `yolo`, and native visual UAT is the phase-level human gate per the UI-SPEC — the tracer verify was re-run end-to-end after commit (14/14 green) before expansion.
