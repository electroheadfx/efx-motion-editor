## Decisions Made

- **One coverage source honored:** the three surfaces never recompute `out..N`. Timeline reads `fxTrack.skipRange` (built from the helper in `fxTrackLayouts`), exportEngine and SidebarProperties call `getOverlaySkipRange` directly. The only `outFrame ?? N` outside the helper is SidebarProperties' *display* range label (what end to print), not the gap range.
- **Authoritative out only:** `fxTrackLayouts.skipRange` is computed from `seq.outFrame` (absent = untrimmed = no gap), NOT from the roto-extended effective out that drives `barW`. A roto-extended bar therefore never hatches inside its own content — matching D-08's gap-tail pin.
- **Warnings vs errors:** `errorMessage` keeps SND-02 fail-closed abort semantics; `warnings` never throw and never set error status. A gap is a valid compositional state (clip ends, paper/other layers continue) — blocking would withhold a deliverable by design.
- **Warning message shape:** `${layerType} "${seq.name}" does not cover frames ${start}..${last}` (singular `frame N` for a one-frame gap) — clip name and exact inclusive range always present, copy the SND-02 naming discipline without the abort.
- **Hatch visual (Claude's Discretion):** muted track-colored bed (`alpha 0x18`) + 6px diagonal stripes (`alpha 0x55`) + faint outline — reads as "clip ends, composition continues", not content and not a hard error. No new timeline lane.
