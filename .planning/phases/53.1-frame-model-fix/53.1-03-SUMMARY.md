## Decisions Made

- **D-07 clip grain honored:** extrapolation lives on the Sequence (the clip the user resizes), not per-layer. One setter, one undo action, one .mce field.
- **D-09 HOLD-everywhere clean break:** pre-53.1 projects that relied on silent modulo-loop open as HOLD. The user re-chooses LOOP once; that write is always persisted (`buildMceProject` writes the field unconditionally) so save → close → reopen keeps it. No migration, no shim, no version branch.
- **D-08 inspector surface:** two-state control beside the clip range in the existing `isContentOverlay` branch. Labels "Hold last frame" / "Loop" (physics-paint naming style). Active state reflects `sequence.extrapolation`; clicking the inactive state calls the setter once. No context menu, no second surface.
- **Video source length at the export gate:** `VideoAsset.sourceFrameCount` (optional) is the 53.1-03 handoff 53.1-02 deferred. `previewRenderer` caches the probed `video.duration * fps` count onto the asset so the next export applies the same past-source law; when unknown the export gate treats the source as unlimited (today's behavior).
- **Preact discipline:** no useState in SidebarProperties; the control reads the passed Sequence prop and calls a store setter from click handlers only (efx-preact-reactivity).
