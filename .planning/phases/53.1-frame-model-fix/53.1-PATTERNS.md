**Core resolver pattern to copy** (lines 288-297) — one pure function, `seq.outFrame ?? fallback`, no store writes:
```typescript
export function getTimelineOverlaySequenceOutFrame(seq: Sequence, fallbackOutFrame: number): number {
  let outFrame = seq.outFrame ?? fallbackOutFrame;
  const startFrame = seq.inFrame ?? 0;
  for (const layer of seq.layers) {
    if (layer.type !== 'physic-paint') continue;
    const rotoEnd = getPhysicPaintRotoDisplayEndFrame(layer, seq);
    if (rotoEnd !== null) outFrame = Math.max(outFrame, startFrame + rotoEnd);
  }
  return outFrame;
}
```

**New signature (D-03 — decided, do not re-arbitrate):**
```typescript
resolveOverlaySample(clip, globalFrame, N) →
  {kind:'sample', localFrame} | {kind:'skip'} | {kind:'hold-last'} | {kind:'loop', localFrame}
```
Reads `clip.extrapolation` as the I-5 input. Export and preview NEVER branch on HOLD/LOOP themselves. The `skip` region is the single coverage source for the hatched tail (D-05), the export warning (D-06), and the inspector tail-state line (D-12).

**Validation/error pattern:** fail-closed returns (`null` / skip), no throws — matches `resolveSequenceTimelineRange` (frameMap.ts:168-205) which returns `null` on malformed input.

```typescript
const missing = mixEntries.filter(t => !t.muted && !audioEngine.getBuffer(t.id));
if (missing.length > 0) {
  throw new Error(
    `missing decoded audio buffer for ${missing.map(t => `"${t.name}"`).join(', ')} — export stopped rather than silently dropping the clip (SND-02). Re-import the audio file or export with include audio off.`,
  );
}
```
For gaps (D-06): **do not throw**. Push a named warning per uncovered visible clip, e.g. `video "nebula.mov" does not cover frames 16..17` — clip name and exact range always in the message. Export still runs and writes 0..N-1. Range = the resolver's skip region (same source as the timeline tail and the inspector line). Surfaced in the existing export UI — no new notification system.
