## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| child webview -> main realm bridge | Studio document edits, gallery requests, launch payloads cross as typed messages (untrusted input) | typed messages: documentAudio sections, launch keys, gallery requests |
| .mce package filesystem | sound reference paths resolve inside the package (untrusted path strings from parsed JSON) | package-relative `audio/` paths, sound records |
| efxasset:// media fetch | child decodes clip bytes fetched from main-built URLs only | main-built asset URLs, clip bytes |
| pointer gesture -> document sound commit | user-dragged frame values land in the document through one setter and one push guard | gesture frame values, fade/gain field commits |
| main playback engine -> audioEngine output | the clip dispatch joins the main window's audio output path under persisted gates | clip buffers, persisted gate state |
| export render -> exported audio_mix.wav | clip entries join the exported mix; inclusion decides what ships | mix entries, exported wav bytes |
