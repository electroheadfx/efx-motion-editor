## Shared Patterns

### Signals-only / Preact reactivity (every new component, hook, store, setter)
**Source:** project law + `efx-preact-reactivity` skill (mandatory read before writing components).
- `useSignal`/`useComputed` only — NO `useState` (harness fallback: signal in `useRef`).
- Idempotent setters (see `setAudioPreviewEnabled` in `efxPaintAudioPreviewStore.ts:44-49`: same-value → return, zero engine calls).
- Selection applied in the click handler, never via `useEffect`.
- No render-body signal writes; identity-stable effect deps; store reads via `.peek()` inside callbacks.
- `paintVersion`: bump on mutations, subscribe in render `useEffect`s.

### Fail-closed / clean-break (parsers, transport, persistence)
**Source:** `efxPaintDocumentParsers.ts:40-42` (`hasOnlyKeys`), `physicsPaintLaunchContext.ts:58` (return `null`), bridge catch (`physicPaintBridge.ts` — `console.warn('[physicPaintBridge] Rejected …')`).
```ts
function hasOnlyKeys(value: Record<string, unknown>, allowed: ReadonlySet<string>): boolean {
  return Object.keys(value).every((key) => allowed.has(key));
}
```
Missing media → explicit recoverable UI (CMP-05), never a silent blank; decode failure logs + skips (monitor `prepare` pattern).

### Ownership = mix, don't contend
**Source:** `efxPaintAudioOwnership.ts:68-70` + CONTEXT established pattern. The first-player-wins guard suppresses doubled MAIN audio only; the document clip dispatches regardless. Never let the guard mute the clip; never let the clip's claim suppress main audio beyond the existing symmetric behavior.

### Drag law
**Source:** memory + Phase 51. During any drag (stain reposition, trim): playhead + throttled audio peek only (`EFX_PAINT_AUDIO_SCRUB_THROTTLE_MS = 120`, snippet 4 frames); full settle (peaks re-render, fingerprint push, main propagation) on release only. Arm thresholds: 4px stain, 2px trim; gesture identity fixed at pointer-down.

### Icons / styling tokens
**Source:** UI-SPEC. `lucide-preact` `AudioWaveform` (15px launcher + modal header), `X` close; stain/trim fill `--color-audio-stain: #2D5BE3` (alias of `--color-accent`); band bg `#47494b`; frame numbers `#eceff2` 12/700 tabular-nums; toggles `.physics-paint-photo-reference-toggle` on-style; modal surface = photo-ref liquid-glass `rgba(28,30,34,0.66)` + blur, 1px `rgba(255,255,255,0.09)`, 10px radius, 300px wide.
