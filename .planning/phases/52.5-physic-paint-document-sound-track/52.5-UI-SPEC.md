## Interaction Contracts

### Frame-number band (the Studio timeline strip) — layout law

| Element | Contract |
|---------|----------|
| Band height | 28px → **36px** (D-07). Frame numbers move lower; wave gets vertical room. Layout constant, single source of truth in the strip renderer. |
| Frame numbers | Stay **on top**, filled `#eceff2`, **no outline** (D-07). 12px/700 tabular-nums. |
| Tick marks + cuts | Stay at the **bottom**, unchanged (1px × 7px `#8b9096` ticks). |
| Stain | Dark-blue filled path drawn **behind** the frame numbers, **full band height** (max extent = 36px − 8px, symmetric about the band's vertical center). Shape = peaks from `audioPeaksCache` with the same tier-selection rule as `TimelineRenderer.drawAudioTrack` (pixels-per-peak → tier1/2/3). Reuse `audioWaveform.ts` / `audioPeaksCache.ts` — no new decode path (D-04). |
| Stain span | Exactly the clip's timeline range: `[start, start + (out − in)]` frames, in content space (rides horizontal scroll with the ruler). |
| Center line / fade gradients / edge handles on the stain | **None.** Phase 15 row presentation does NOT carry over (D-06, D-10: "keep the timeline lean"). Fades are modal values only. Do not "fix" this toward an audio rail. |
| 2 px trim bar | Top edge of the band (`top: 0`), spans the same range as the stain, fill `--color-audio-stain`. Drawn 2px; hit-zone extends **8px downward**. |
| Launcher icon | `AudioWaveform` (lucide, 15px) in the **left header column's ruler-spacer slot** — the fixed, non-scrolling top-left cell of the band row, so it never scrolls away and never overlaps the scrub surface. 24×26 button (`.physics-paint-nav-button` metrics). Accent tint when a clip exists, default `#f2f5f7` when none. Opens the audio modal (D-02 — the ONLY new entry point; no Add-Audio button, no Tools-popover entry, no drag-and-drop path). |
| Playhead | Unchanged: 2px `#A6D334`, full height, `pointer-events: none`, z 30 — draws above the stain. |

### Gesture truth table (strip)

Gesture identity is decided at pointer-down / arm time and **never switches mid-gesture**.

| Pointer-down lands on | Sub-threshold release (<4px) | Armed drag (>4px horizontal) |
|---|---|---|
| Trim bar end zone (±6px from a clip end, top 8px) | No-op (bar never seeks) | Trim start (left end) or end (right end); `ew-resize` cursor; live bar/stain redraw; throttled audio peek; full settle + sync push on release |
| Trim bar middle | Passes through to stain law below | Passes through to stain law below |
| Stain body | One seek (same as ruler click — scrub unchanged) | **Reposition clip** (D-08): stain translates live with pointer, playhead follows pointer, throttled audio peek; full settle (peaks re-render, two-window sync push, main-editor propagation) **on release only** |
| Plain band (no stain under x) | One seek (existing behavior) | Existing ruler seek-scrub via `usePhysicsPaintRulerScrub` — **unchanged** (Plan 1 UAT row) |
| Launcher icon | Open/close audio modal | n/a |

- Arm threshold: **4px** for stain reposition and scrub (existing `RULER_SCRUB_THRESHOLD_PX`); **2px** for trim (bar is precision chrome; it never seeks so no 4px seek threshold applies).
- Drag law (memory + D-08): during any drag — playhead + audio snippet only, throttled peek, **full settle on release**. The live stain translation during reposition is the drag preview itself, not a settle.
- Trim clamps: `in < out` enforced, minimum span **1 frame**; `start ≥ 0`; both ends clamp to the parent end.
- Ruler seek, cell clicks, rail gestures, and scroll-snap behavior are untouched outside the stain/bar x-ranges.

### Audio modal (D-05 — the single control surface)

Pattern: `PhysicsPaintPhotoReferenceDialog` / Play Script floating dialog — **no backdrop, no Tab trap**, ESC closes, close button, focus captured on open and restored to the launcher on close.

Field order (top → bottom):

1. Header: `AudioWaveform` 15px + `Document sound` + close X (`aria-label="Close"`, drag-to-move header optional, photo-ref precedent)
2. File row: truncated filename + `Replace…`, or the empty-state block with `Import sound`
3. `Remove` — two-step inline confirm (armed label `Confirm remove?`, destructive styling; reverts on any other action)
4. `Volume` — range slider 0–100 step 1 + `NN%` readout (AudioProperties precedent)
5. `Fade in` — NumericInput (frames, step 1, min 0) + curve select
6. `Fade out` — NumericInput (frames, step 1, min 0) + curve select
7. Toggle row: `Sound in output` | `Preview main app too` — two-state `aria-pressed` buttons in the existing photo-ref toggle style (Claude's discretion resolved: toggle buttons, not checkboxes — matches every other Studio modal control)

Rules:

- **`pickerOpen` step-aside (260923-fhn, mandatory):** while the shared gallery picker is open, the audio modal is hidden (`!pickerOpen` guard in `PhysicsPaintStudioView`, same condition as the reference/PlayScript dialogs) and returns with prior state on picker close.
- Import/replace/remove go through **`BackgroundAssetPickerView` opened for audio** (D-03) — same full-area region-swap, same Import-top/Confirm-Bottom layout (260923-fhn locked), audio filter (WAV/MP3/AAC/FLAC). No second picker, no new file dialog path.
- Toggles gate **audio only**: neither toggle ever changes the stain, the bar, or any pixels. `Sound in output` OFF removes the clip from export + main playback; Studio preview still audibles it (D-12). `Preview main app too` OFF isolates the Studio clip in preview only (D-11).
- Volume + fades are the level **everywhere** (D-14): one set of values, no main-side fader, no per-surface override.

### Cross-surface states

| Surface | Contract |
|---------|----------|
| Studio playback | Clip mixes with main-app monitoring by default; `Preview main app too` toggles the monitoring leg. First-player-wins ownership guard must not suppress the clip (mix, don't contend). |
| Main editor | **No new UI in this phase** (Plan 2 is playback-only). Clip audible gated by `Sound in output` AND layer hide/solo (D-12 + D-13). Existing hide/solo controls are the only surface. |
| Save/reopen | Stain, bar, modal values restore from the `.mce` reference (52.2). Missing reference → no stain + modal error copy; explicit and recoverable (CMP-05 / fail-closed), never a silent blank. |
| Two-window sync | Every release-settled edit (position, in/out, volume, fades, toggles) pushes over the existing revisioned bridge — no new channel. Main editor reflects edits without reload. |
