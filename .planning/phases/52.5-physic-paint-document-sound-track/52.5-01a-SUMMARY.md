## Decisions Made

- **fps chain (open decision resolved):** clip dispatch uses `current?.fps ?? efxPaintDocumentAudioStore.getFps()`; store fps seeded at hydration from `context.fps ?? 12`. audioPreview fps remains authoritative when a main section exists.
- **Persistent revision watermark:** stronger than the audioPreview funnel — survives null-clears so stale replays cannot resurrect a removed clip.
- **Ownership mix rule:** only a dispatched main leg calls `claimAudio()`; a failed claim suppresses main only, the clip still dispatches (D-05/D-06 preserved).
- **Toggle-Off re-entry:** `setPreviewEnabled(false)` re-enters `playAtCursor` so a muted session silences main while an ungated clip keeps sounding; no-clip path is baseline-identical.
