## Accomplishments
- `move-group` intent joins the closed operation-kind union: strict parser branch, canonical serializer case, operation-kind validator entry, and `createAuthorizedPhysicalEditPayload` authorization case (GDRAG-01)
- Resolver source-attached branch rigidly translates every source key and the Group lifecycle fields (phaseOrigin, originalEndExclusive, every visibleRanges entry, every frameOverrides appFrame) by the same signed delta, with fail-closed rejection for non-empty-segment destinations (GDRAG-03)

## Decisions Made
- `GROUP_RAIL_DRAG_THRESHOLD_PX = 4` is horizontal-only; the 6px Euclidean `ROTO_DRAG_THRESHOLD_PX` belongs to the locked physical-cell drag path and stays untouched (43.3 PATTERNS)
- The rail target always stops pointerdown propagation so the physical-cell handlers below never see it (43 D-42 isolation)
- Modifier presses never arm a drag session: Cmd/Ctrl/Shift clicks remain selection gestures handled by the rail click machinery (Pitfall 6)
- `beginDrag` does not prepare: the move handler that crossed the threshold calls `prepareAt()` right after, so the publication is prepared exactly once per destination change
- Ghost geometry is session-only and consumed for paint only; commit consumes the immutable retained publication (D-01)
- Injectable `windowLike`/source-element surfaces keep the session state machine unit-testable in the node vitest environment

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Double-prepare on threshold-crossing move**
- **Found during:** Task 3 (rail drag session hook)
- **Issue:** `beginDrag` called `prepareAt()` AND the move handler called it again, so `prepareRotoGroupDrag` fired twice on the threshold-crossing move
- **Fix:** Removed `prepareAt()` from `beginDrag`; the move handler that crossed the threshold calls it right after, so the publication is prepared exactly once per destination change
- **Files modified:** app/src/components/physic-paint/hooks/usePhysicsPaintGroupRailDrag.ts
- **Verification:** threshold-crossing test asserts `prepareRotoGroupDrag` called once with `('group-a', 11)`
- **Committed in:** 23b1b041 (Task 3 commit)

**2. [Rule 1 - Bug] Ghost re-render hook-cursor index drift**
- **Found during:** Task 3 (ghost presentation tests)
- **Issue:** Re-rendering without resetting the test harness advanced the hook cursor, so the ghost `useState` read a fresh (undefined) index and the ghost was not found
- **Fix:** Added `hooks.rewind()` to the test harness (resets cursor without clearing refs/values) and called it before re-renders in the Escape and ghost tests
- **Files modified:** app/src/components/physic-paint/view/PhysicsPaintLoopClipRail.test.tsx
- **Verification:** Escape-cancel and ghost-geometry tests pass
- **Committed in:** 23b1b041 (Task 3 commit)

**3. [Rule 1 - Bug] Test fixture visibleRanges violated the lifecycle validator**
- **Found during:** Task 1 and Task 2 (GREEN test runs)
- **Issue:** Fixture visibleRanges were contiguous (`[{start:1,endExclusive:4},{start:4,...}]`), but the Loop Clip lifecycle validator requires strictly increasing ranges with GAPS, so GREEN tests failed
- **Fix:** Corrected fixtures to gap-enforcing ranges (`[{start:1,endExclusive:4},{start:5,endExclusive:9}]`) and narrowed `operationKind: 'move-key-group' as const`
- **Files modified:** app/src/components/physic-paint/roto/physicsPaintRotoPhysicalResolver.test.ts, app/src/components/physic-paint/hooks/useRotoTimelineActions.test.ts
- **Verification:** all 114 plan verification tests pass
- **Committed in:** 9fe0ed6f (Task 1), 2d50982b (Task 2)

**4. [Rule 3 - Blocking] TypeScript listener/type-narrowing errors in the session hook**
- **Found during:** Task 3 (hook module typecheck)
- **Issue:** `(event: PointerEvent) => void` not assignable to `EventListenerOrEventListenerObject`; `event.currentTarget as GroupRailDragSourceElement` failed (no type overlap); mock `ok: true` widened to `boolean`
- **Fix:** Typed window-like/source-element listener params as `(event: any) => void`; used `as unknown as GroupRailDragSourceElement`; added explicit `: RotoGroupDragPreparationResult` return types to mock implementations
- **Files modified:** app/src/components/physic-paint/hooks/usePhysicsPaintGroupRailDrag.ts, app/src/components/physic-paint/view/PhysicsPaintLoopClipRail.test.tsx
- **Verification:** typecheck exits 0
- **Committed in:** 23b1b041 (Task 3 commit)
