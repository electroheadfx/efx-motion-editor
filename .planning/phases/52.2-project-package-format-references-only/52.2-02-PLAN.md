<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| On-disk JSON → parser | A layer sub-file or manifest read from disk is untrusted input |
| Runtime state → persisted JSON | A path produced at runtime could be machine-local and must not reach the package |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-52.2-05 | Tampering | `isSafePackageRelativePath` / `parseFrameMediaReference` | high | mitigate | Segment-wise allow-set (no leading `/` or `\\`, no `\`, no NUL, no empty/`.`/`..` segment, no drive letter, no UNC) plus a required `frames/` prefix for media references; every media reference is rejected before any filesystem call is made. |
| T-52.2-06 | Information Disclosure | machine-local paths leaking into the package | medium | mitigate | `isSafeMachineCacheRelativePath` requires the `efx-paint/` prefix and forbids absolute/drive-letter/UNC forms; `collectPackageCacheRefs` is the single place the invariant is checked, and `resolveMachineCachePath` is the only constructor of an absolute machine path (at read time only). |
| T-52.2-07 | Spoofing | `projectId` reuse across packages | low | accept | The id is a per-package identity for a disposable cache; a collision only mixes regenerable derived frames, never authoritative content (D-14 keeps cache re-derivable). |
</threat_model>
