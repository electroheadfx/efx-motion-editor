Create the TS contract layer for the package: relative-path primitives, the `frames/<layerId>/<keyId>.webp` media reference (D-02), the machine-local cache reference scheme that keeps machine-local paths out of the package (D-05), the single `formatVersion` constant, and the document-model/parser changes that make a media reference the only legal way for a PERSISTED roto record to carry pixels — enforced at the on-disk door, in BOTH persisted collections, `realKeyRecords` and `groupOverrideRecords` (D-06, D-07), while the shared runtime payload guard keeps admitting the bytes-carrying runtime record every pre-save record still is.

Output: `app/src/lib/efxPaintPackage.ts` with its test suite, an extended `EfxPaintDocument` real-key record carrying `media: FrameMediaReference` (the record type the two roto collections share), a shared content encoding that is total over both record shapes, a persisted-shape payload validator that refuses inline raster payloads in either collection at the on-disk door, and a runtime payload guard left admitting bytes so no runtime consumer regresses.
</objective>
