Ground truth on the real project: cache/ = 0 files, tracks[].frames = {}, 46 inline real keys (~36.3 MB). Found and flagged: the loader comment `efxPaintPersistence.ts:430-433` overpromises ("fetches the WebP sidecar on demand") — no such code exists.
