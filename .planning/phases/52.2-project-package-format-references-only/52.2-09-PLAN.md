<objective>
Build the phase's genuinely new construction (D-13, spec §8): opening a package reads the manifest and the layer sub-files, recomputes each derived-frame cache location from its machine-relative reference (D-05), and every real-key raster is decoded lazily from `frames/<layerId>/<keyId>.webp` through the existing bytes/ImageBitmap + LRU path, with digest verification, missing-file slate behavior and no silent fallback. This plan also carries the phase's on-disk round-trip contract — the only leg that can reopen what the save funnel wrote — including the D-06 Law-1 identity case for loop clips and photo references.

Purpose: nothing in the repo reads frame files back today — the loader is refs-only and the only pixels on reopen come from inline payloads, which this phase deletes. Without this leg a saved project would reopen empty.

Output: `efxPaintMediaRead.ts` with its tests, a package loader that produces reference-only documents, a compositor seam that resolves references on demand, and `packageFixture.ts` + the round-trip contract test.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Package files on disk → decoder | Files can be missing, replaced, or corrupted between save and open |
| Manifest index entry → filesystem read | A manifest is untrusted input at open time |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-52.2-29 | Tampering | digest mismatch silently substituted | high | mitigate | The on-disk digest is recomputed by the native read command and compared with the recorded digest BEFORE decoding; a mismatch produces no bitmap, writes nothing to the LRU, and never falls back to a previous frame — asserted by test. |
| T-52.2-30 | Tampering | manifest index entry escaping `layers/` | high | mitigate | Every index path passes `isSafePackageRelativePath` plus a `layers/` prefix check before any read, and the test asserts zero read calls on a rejected entry. |
| T-52.2-31 | Denial of Service | decode storms on reopen | medium | mitigate | The LRU is keyed by persisted digest, so the same raster referenced by several keys decodes once; the 52.1 byte-budgeted LRU still governs eviction. |
| T-52.2-32 | Information Disclosure | missing media silently rendering as content | low | accept | A missing file draws the Phase 49 slate — the user sees a missing frame, which is the honest outcome; content is never invented. |
| T-52.2-57 | Tampering | a persisted cache reference that is not machine-relative | high | mitigate | The loader validates every persisted cache reference with `isSafeMachineCacheRelativePath` before recomputing a location and refuses the load otherwise; the machine-local root is an input, never reconstructed here, and nothing reads a cache file (D-14), so a crafted reference cannot steer a read. |
</threat_model>
