<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Package files on disk → decoder | Files can be missing, replaced, or corrupted between save and open |
| Manifest index entry → filesystem read | A manifest is untrusted input at open time |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-52.2-29 | Tampering | digest mismatch silently substituted | high | mitigate | The on-disk digest is recomputed by the native read command and compared with the recorded digest BEFORE decoding; a mismatch produces no bitmap, writes nothing to the LRU, and never falls back to a previous frame — asserted by test. |
| T-52.2-30 | Tampering | manifest index entry escaping `layers/` | high | mitigate | Every index path passes `isSafePackageRelativePath` plus a `layers/` prefix check before any read, and the test asserts zero read calls on a rejected entry. |
| T-52.2-31 | Denial of Service | decode storms on reopen | medium | mitigate | The LRU is keyed by persisted digest, so the same raster referenced by several keys decodes once; the 52.1 byte-budgeted LRU still governs eviction. |
| T-52.2-32 | Information Disclosure | missing media silently rendering as content | low | accept | A missing file draws the Phase 49 slate — the user sees a missing frame, which is the honest outcome; content is never invented. |
</threat_model>
