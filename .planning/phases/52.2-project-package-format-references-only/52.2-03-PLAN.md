## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User input → numeric field | Typed/pasted text crosses into a numeric state and reaches the document |
| Sweep contract test → source tree | The test reads repository files at test time |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-52.2-08 | Tampering | `NumericStepper` value path | medium | mitigate | Single commit path reused from `NumericInput.commitValue` (clamp to min/max + round to step + `stopCoalescing`), so pasted or typed out-of-range values are clamped identically to button steps; hold-to-repeat cannot emit an out-of-range value because every emission passes the same clamp. |
| T-52.2-09 | Denial of Service | hold-to-repeat interval leak | low | mitigate | `pointerup`/`pointercancel`/`pointerleave` all clear the delay timer and the interval; a component unmount clears both, so a stuck pointer cannot spin an interval after the surface is gone. |
| T-52.2-10 | Repudiation | sweep contract silently narrowing | low | accept | The scan list is asserted by length in the test itself; a future narrowing shows up as a changed assertion rather than a silent pass. |
</threat_model>
