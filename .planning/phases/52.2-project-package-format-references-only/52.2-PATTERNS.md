### `app/src-tauri/src/services/physic_paint_cache.rs` (service, file-I/O) — EXTEND, do not rewrite

**Analog:** itself. This is the machinery D-10 extends to a file set.

**Transaction marker — the shape to extend to a multi-file set** (lines 45-54):
```rust

struct CacheTransactionMarker {
    version: u32,
    transaction_id: String,
    staging_basename: String,
    replaced_existing: bool,

    expected_project_digest: Option<String>,

```
`project_file_path` + `expected_project_digest` are the single-file binding RESEARCH Pattern 1 replaces with a canonical concatenation (`path\0sha256`, path-sorted) of every file the transaction touches. Recommendation stands: option (a) aggregate digest.

**Binding + idempotent re-bind** (lines 147-180) — the shape the aggregate binding must keep (bind once, tolerate an identical re-bind, reject a different one):
```rust
match (&marker.project_file_path, &marker.expected_project_digest) {
    (None, None) => { marker.project_file_path = Some(normalized_project_path); marker.expected_project_digest = Some(digest); write_marker(&cache_parent, &marker)?; }
    (Some(existing_path), Some(existing_digest)) if existing_path == &normalized_project_path && existing_digest == &digest => {}
    _ => return Err("Physics Paint cache transaction is already bound to a different project write".to_string()),
}
```

**Digest helpers — reuse verbatim for media files** (lines 626-646):
```rust
fn digest_bytes(bytes: &[u8]) -> String { format!("{:x}", Sha256::digest(bytes)) }

fn digest_file(path: &Path) -> Result<String, String> {
    let mut file = File::open(path)...?;
    let mut digest = Sha256::new();
    let mut buffer = [0_u8; 64 * 1024];
    loop { let read = file.read(&mut buffer)...?; if read == 0 { break; } digest.update(&buffer[..read]); }
    Ok(format!("{:x}", digest.finalize()))
}
```
**64-hex digest validation already exists** (lines 564-568) — extend it to every digest in the set:
```rust
if digest.len() != 64 || !digest.bytes().all(|byte| byte.is_ascii_hexdigit()) {
    return Err("Physics Paint cache transaction project digest is invalid".to_string());
}
```

**Path guards to mirror on the write side** (lines 466-489) — `normalize_project_file_path` (parent canonicalize + `resolved_parent != project_root` → reject) and `ensure_direct_child_directory`. Media writes must apply the same law or a hostile ref path escapes the staging root.

**Durability primitives — reuse, never re-implement** (lines 648-704): `write_synced_file`, `sync_directory`, `sync_directory_tree` (rejects symlinks), `cleanup_stale_staging_generations`, `collect_cleanup_error` / `cleanup_settlement` (deferred cleanup is a diagnostic, not a failure).

**Platform gate idiom** (lines 60-65, 731-775): `#[cfg(target_os = "macos")]` real body + `#[cfg(not(target_os = "macos"))]` returning `Err(... "supported only on macOS")`. The atomic directory swap is `libc::renameatx_np(..., RENAME_SWAP)`. Any new package-level atomic step must follow the same two-arm shape.

## Shared Patterns

### Path safety (ASVS V12) — apply to EVERY media read/write and every ref consumed from a package
**Sources:** `app/src/lib/efxPaintPersistence.ts:134-143` (TS guard), `app/src-tauri/src/lib.rs:434-450` (Rust canonicalize + `starts_with`), `app/src-tauri/src/services/physic_paint_cache.rs:466-489` (`normalize_project_file_path`, `ensure_direct_child_directory`), `:593-605` (`validate_unchanged_path`).
```ts
export function isSafeEfxPaintCachePath(cachePath: unknown): cachePath is string {
  if (typeof cachePath !== 'string' || !cachePath.startsWith(`${EFX_PAINT_CACHE_DIR}/`)) return false;
  if (cachePath.includes('\\') || cachePath.startsWith('/') || cachePath.includes('\0')) return false;
  return cachePath.split('/').every((segment) => segment.length > 0 && segment !== '.' && segment !== '..');
}
```
Reject at parse (segment check) AND at read (canonicalize + prefix-check the package root) — defense in depth. Never add a second bespoke validator shape.

### Content digests
**Source:** `app/src-tauri/src/services/physic_paint_cache.rs:626-646` + validation at `:564-568`.
Hash in Rust (`sha2` already a dependency), on the exact persisted bytes. Keep `buildFrameBytesToken` (`app/src/lib/webpBytes.ts:95-103`) for the O(1) in-memory dirtiness check — two mechanisms, two purposes. Never `crypto.subtle` (Assumption A1 unresolved in WKWebView).

### Fail-closed validation at boundaries
**Sources:** `efxPaintDocumentParsers.ts` (allowed-key sets + throw), `efxPaintCleanBreak.ts` (non-throwing scan, typed reasons), `efxPaintPersistence.ts:263-268` (unsafe deletion path → throw), `lib.rs` (rejection kinds). Every boundary either throws with a `RecordName: field expectation` message or returns a typed rejection — no silent normalization, no fallback value.

### Error envelope for IPC
**Source:** `app/src/lib/ipc.ts:16-28`. Rust returns `Result<T, String>`; TS wraps in `{ok}` / `{ok:false,error}` via `safeInvoke`. Callers branch on `result.ok` and throw at the store boundary (`projectStore.ts:757-761`).

### Transaction shape (stage → bind → commit/rollback)
**Sources:** `efxPaintPersistence.ts:243-423`, `physic_paint_cache.rs:56-210`, `project_io.rs:37-74`, `commands/project.rs:99-127`. Extend this one mechanism (D-10); do not introduce a journal or a second marker format.

### Version bump + idempotence discipline
**Sources:** `physicPaintStore.ts:1153` (bump after decode, in `finally`), `installRuntimeStateFromDocument` (revision bumps without dirty callback when the caller owns dirty signaling), `efxPaintStore.ts:1633-1673` (`reset` early-returns when already empty; `serializeRuntimeIntoDocument` bumps only on a real revision change). Any new setter/revision signal in the package path must be compare-then-write (efx-preact-reactivity rule 3).

- No Preact/signals in pure model/parser modules (`efxPaintDocument.ts:1-9`).
- Comment style: a block header naming the phase + the decision IDs the module implements, then WHY comments at every non-obvious guard.
