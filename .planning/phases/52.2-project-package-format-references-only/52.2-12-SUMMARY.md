**1. [Rule 3 - Blocking] The memo wrappers are `memo(Component)` boundaries, not plain components**

- **Found during:** Task 2 (right panel + canvas instrumentation)
- **Issue:** The plan said to add one `countRender(` call at the render body of each surface. `MemoizedPhysicsPaintRightPanel.ts` / `MemoizedPhysicsPaintCanvasMount.ts` are 7/34-line `memo(PhysicsPaintX)` export boundaries — there is no function body to put a statement in, and counting at the boundary is what makes the number measure churn rather than parent renders.
