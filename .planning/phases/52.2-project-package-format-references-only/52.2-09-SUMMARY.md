# Phase 52.2 Plan 09: Package read-back — references-only open, on-demand media decode, on-disk round trip Summary

## Accomplishments

- `efxPaintMediaRead.ts`: `resolveFrameMediaBitmap({ packageDir, reference, lru, decode })` → `bitmap | missing | refused`; the LRU is keyed by the persisted digest, digest mismatch is refused before decode and before any LRU write, and the resolver takes a reference — never a collection — so real keys and group overrides cannot diverge.
- `loadEfxPaintPackage`: opens only the `layers/<layerId>.json` sub-files the manifest index names, through the fail-closed parser; every index path passes `isSafePackageRelativePath` + `layers/` before the first fs call; machine-relative cache refs are recomputed via `resolveMachineCachePath` and never read (D-05/D-14); the misleading sidecar-fetch comment and the dead `efx_paint_documents` carrier are gone.
- The compositor seam resolves a reference-only record on demand through the 52.1 two-format sniff and version bump; both `realKeyRecords` and `_rotoGroupOverrideRecords` reach the same seam, missing files draw the Phase 49 slate with the reference named, and mismatches are refused without reusing another frame's raster.
- The phase's on-disk round-trip contract: a 2-layer fixture package on a temp dir, payload scan over every emitted JSON (both collections), changed-files-only saves, refusal byte-equality, group-override media round trip and digest-mismatch refusal, and D-06 Law-1 `sourceFrameRefs` element-for-element identity through the `images/` index.
- The dead plan-05 → plan-07 leftover closed: `physicPaintCacheTransactionId` deleted from both project-save IPC wrappers.

## Decisions Made

- LRU key = persisted digest (not path, not keyId) so duplicate references decode once; a mismatch never writes the LRU.
- Terminal verdicts keyed by digest (`missing` / refusal reason) so a failed read is not re-issued on every compositor tick, while `_frameMediaResolutionPromises` keeps in-flight reads deduplicated and `awaitPendingDecodes` covers them.
- The package dir reaches the store by provider injection (`_setPhysicPaintPackageDirProvider`) rather than a store→projectStore import, avoiding a module cycle the same way the compositor-size provider does.
- The seam branch condition is `bytes === undefined && media !== undefined`, so every pre-existing inline-bytes path is untouched.
