<objective>
Close G-63-5: the per-track Studio snapshot wire learns the texture axis, so a Roto script saved from a project with an imported tip carries each stroke's `engine.textureId` and paints that footprint when applied into a project that never imported it.

Purpose: the UAT checkpoint failed because the AQTL body inside every SNP1 `.snap` never encoded or decoded `engine.textureId`. On any Studio boot, layer switch or track reseed, `studioScriptSnapshotController.restore()` decodes the snapshot and `restoreAquarelleRecordTimeline` replaces `payloadTimeline` wholesale — silently stripping every recorded stroke's texture before Save Script ever runs. The capture, serializer, Rust write, parse and bake legs are all faithful and must not be edited. Adding the field to AQTL encode/decode (and only that) restores the whole chain.

Output: AQTL v3 with a presence-prefixed `engine.textureId` in the stroke engine slot; a regression test of the real record → SNP1 → restore → save chain; boundary pins (lift, absence, unknown id, built-in with no imports); play-routing pins for motion, static and both reveal seams.

Deferred, with justification: the secondary defect — `aquarelleSelectedTextureId` is realm-session state that resets on a Studio realm boot. It resets exactly like `aquarelleSelectedTipId` (which returns to its 'filbert' default), so the texture pick's lifetime already matches the response pick's lifetime by design. Restoring it is a separate Studio-remember-my-brush UX decision with no locked decision behind it, the gap marks it optional, and the failing checkpoint does not depend on it: the saved script must carry the ids each recorded stroke already has, not re-invent a pick.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| snapshot bytes on disk → AQTL decoder | A per-track `.snap` written by an older build or altered on disk supplies the stroke ids |
| decoded event → mask registry | A texture id is only ever a registry map key; the codec resolves nothing and touches no IO |
| saved script JSON → play/bake | A script's stroke ids reach the brush bridge, which resolves the footprint |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-63-33 | Tampering | AQTL `decodeStroke` / every reader of `engine.textureId` | medium | mitigate | The presence marker is validated as exactly 0 or 1 (`BinaryReader.presence`), the string is length-checked against the declared body before allocation, an empty value is refused, and the id is used only as a mask-registry map key — never a file path — so a crafted snapshot or script cannot reach package or cache IO. Pins cover the corrupt marker, the empty value and the truncated string. |
| T-63-34 | Denial of service | AQTL version gate on a stale or crafted `.snap` | low | accept | An AQTL v1/v2 body is refused whole with `unsupported-version`; the controller reports one restore failure and leaves a known-empty timeline instead of a partial decode, so a stale cache degrades to one notice, never a crash or half-restored strokes. Accepted because the project law forbids migration readers. |
| T-63-SC | Tampering | npm/pip/cargo installs | high | mitigate | This plan adds no dependency; the package-legitimacy gate blocks any [ASSUMED]/[SUS] addition. |
