<objective>
Give the mask a durable home: an optional `.mce` root `brushPack` whose entries carry package-relative asset refs, staged through the existing atomic save transaction, byte-identical on an untouched reopen.

Purpose: TIP-11, TIP-15 and TIP-16 are the persistence half of the phase law. The two-language declaration is the tripwire that prevents a field from being silently dropped by serde, and the save transaction is where "copies the stored bytes, never re-encodes" is either true or false.
Output: the entry shape and both language declarations under the field-diff pin, the project-scoped catalog store (custom entries + the unavailable set), a session brush-asset cache, and the save-staging legs for `brushes/`.

Two persistence proofs live in the sibling plan 63-09, which runs one wave earlier (wave 2, against 63-02's native write/read pair only): the fresh-profile directory copy and the `create_project_dir` provisioning assertion. They need nothing from this plan, so they are kept out of this plan's file budget.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| project entry → package path | An entry-supplied asset string could point outside the package |
| manifest → save transaction | A ref-only carrier could smuggle inline bytes or an external path |
| save → stored asset | Re-encoding would break byte identity |

| T-63-06 | Tampering | `pack.ts` entry shape | high | mitigate | Package mode refuses `mask` and `maskDataUrl`; the retired D-23 exception comment is rewritten on both models so no future reader re-introduces inline bytes. Pinned by a negative test. |
