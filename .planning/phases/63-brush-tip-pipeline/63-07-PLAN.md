<objective>
Make the project open tell the truth about its brushes: decode once, register before the first replay, degrade per tip, replace across projects, reset on close.

Purpose: TIP-12, TIP-17 and success criterion 4 are ordering and lifecycle contracts. The existing open already has the right shape — read the whole media set before closing, then hydrate — and this plan slots the brush set into exactly those seams (D-17, D-20).
Output: a fail-closed brush-set loader, the open/close wiring, the replace-semantics catalog mutation, and the degradation path that feeds the single warning state.
</objective>
