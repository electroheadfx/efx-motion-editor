<objective>
Close WR-02 and WR-03: the script save law refuses only what genuinely cannot travel, and an empty catalog can no longer masquerade as "nothing to carry".

Purpose: `buildScriptBrushEntries` walks every custom tip, so one tip the open already degraded makes every script save fail (WR-02) — a direct violation of the D-18 per-tip degradation law. In the other direction, an empty catalog (CR-01 refusal, failed pull, failed push) makes the function return an empty successful carrier, and the save writes a script whose custom strokes have no masks (WR-03) — the omission its own docstring forbids. The fix needs one realm-local fact the Studio never recorded (did a catalog payload ever arrive?) and one coverage check (does every custom id the capture paints have a carried entry?).

Output: a `brushCatalogSynced` signal set by the one applier, per-entry skip of unavailable tips with a log, and a save refusal that names the first custom id whose mask cannot travel.
</objective>
