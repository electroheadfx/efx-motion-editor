<objective>
Turn the catalog into a truthful surface: sectioned grid, per-tip painted previews, the import row, and one aggregate warning for degraded tips.

Purpose: D-01/D-03/D-05/D-19 and success criteria 1 and 4 are all UI contracts. The current library forbids an import affordance and paints one shared thumbnail per preset; both must change without forking the paint path or resurrecting the unmounted docker.
Output: the sectioned library with its import row, a per-tip thumbnail cache keyed on mask generation, the aggregate warning rendering, and an extended tip selection that leaves the lift branch alone.

Both `WatercolorBrushLibrary` mounts render only in the Studio child webview. The data they show comes from the CHILD realm's `aquarelleBrushCatalog` instance, populated by plan 63-05's `applyBrushCatalogPayload` (mount pull + every push). This plan therefore CONSUMES the catalog and the unavailable set — it creates neither, and it must never read the main realm's state directly or re-implement a fetch of its own.
</objective>
