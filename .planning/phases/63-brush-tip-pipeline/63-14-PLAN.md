<objective>
Close WR-06: a hostile or corrupted stored brush asset is bounded before the digest and dimension guards allocate it, and the batch still degrades per entry.

Purpose: `read_brush_asset` validates the path shape, canonicalizes the leaf, refuses a symlink and a missing file, then `fs::read`s the ENTIRE file before computing the digest and before `decode_mask_webp`'s pre-decode dimension guard. A multi-GB regular file at `brushes/<64hex>.webp` is fully resident before the check that would reject it, so the single batch read an open performs can exhaust memory — the dimension guard the phase added is downstream of the allocation it was meant to protect (WR-06).

Output: a metadata length check against a 16 MiB cap before the read, the refusal mapped to the existing `unreadable` per-entry reason, and pins that the boundary is exact and the batch is never aborted.
</objective>
