<objective>
Build the only door through which a mask reaches disk: a content-addressed lossless WebP at `brushes/<sha256>.webp`, encoded once at import, decoded on open in one call.

Purpose: TIP-08's byte-identity law and TIP-09's no-external-path law both live or die at this boundary. The renderer never touches a tip path; every brush asset write and read passes the same bound-path guard that already protects `frames/`, without widening that lock (D-12).
Output: four native commands (encode mask, write asset, batch read, decode one mask), a sibling `brushes/` branch in the bound-path guard, and fail-closed TypeScript path helpers.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| package → native reader | WebP bytes inside a user-supplied `.mce` are untrusted |
| renderer → package writer | A renderer-supplied relative path could escape the package |
| catalog entry → disk | A content-addressed name could disagree with its bytes |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-63-03 | Denial of Service | `decode_brush_mask` / batch read | high | mitigate | Decode only through the existing codec, refuse any non-192×192 result, map every decode error to `unreadable`, and never abort the batch. |
