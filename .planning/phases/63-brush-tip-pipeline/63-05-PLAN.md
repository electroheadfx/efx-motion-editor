<objective>
Make the import real across both realms: the Studio reads the file and derives the mask, the main realm — which owns the project — encodes it, registers it, adds the catalog entry and marks the project dirty.

Purpose: the import surface lives in the Studio webview while `projectStore` lives in the main window (D-01, D-15). The existing image-import request/result bridge is the proven pattern for "child asks, main realm performs the project mutation"; this plan reuses it rather than duplicating project state into the child.
Output: a reshaped `importTip` with caps and the shared derivation, the main-realm import handler, the catalog mutation API, and the four brush bridge events with their guards.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Studio webview → main webview | A child-originated event asks the project owner to mutate state |
| user file → decoder | Untrusted image bytes and declared dimensions |
| asset cache → package | Encoded bytes held in memory ahead of save |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-63-04 | Spoofing | brush import request event | medium | mitigate | The main realm validates payload shape, requires an operationId, enforces the exact 36,864-byte mask length, and only ever answers the Studio window label; an origin-checked message fallback covers the non-Tauri path. |
| T-63-02 | Denial of Service | `importTip` / request handler | high | mitigate | 64 MB and 64 MP caps before read/decode; fixed-length mask validation before encode; a corrupt header returns a named failure instead of throwing. |
| T-63-11 | Tampering | single-flight import chain | low | mitigate | The queue serializes imports and contains rejections, so two concurrent imports cannot interleave catalog mutations. |
| T-63-SC | Tampering | npm/pip/cargo installs | high | mitigate | No dependency is added; magic sniffing and header parsing are hand-written and bounded. |
</threat_model>
