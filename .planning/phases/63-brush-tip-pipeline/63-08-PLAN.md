<objective>
Make a script self-contained in the one way a script can be: carry each imported tip's mask inline as a WebP data URL, rehydrate it into the engine registry on load, and let it paint in a project that never saw the import.

Purpose: TIP-14 and success criterion 5 are the last mile of the phase law. A script cannot reference another project's package asset, so the mask must travel inline — the handler already stores its thumbnail the same way (D-14) — while the package carrier stays refs-only.
Output: the script entry carrier, its parse-time validation, the save leg that reuses stored bytes, and the load leg that registers session-only masks.
</objective>
