<objective>
Close WR-05: the three compile-time built-in textures become unshadowable at the registry, the one module every mask write must pass through.

Purpose: `registerMask` overwrites whatever id it is given, and `replaceMaskRegistry` sets every writable entry after clearing. Neither excludes the three built-in ids, so a Roto script whose `brushPack` names `wc/builtin-chalk` with a foreign 36,864-byte mask replaces the shipped chalk texture for the rest of the session (`registerScriptBrushMasks` → `registerScriptMask` → `registerMask`), and a foreign package entry pushed through `applyProjectBrushSet`/`applyBrushCatalogPayload` wins over the built-in it duplicates (`resetMaskRegistry` only runs on close, D-20). Both seams converge on this module, so the reservation law belongs here rather than as an exclusion list at each caller.

Output: reserved built-in ids in `registerMask`, identity-only admission for built-in ids in `replaceMaskRegistry`, and pins that the reset path still seeds exactly the three constants.
</objective>
