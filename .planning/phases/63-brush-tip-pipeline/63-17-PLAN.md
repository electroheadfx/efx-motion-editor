CR-03 (truth 22, blocker): PhysicsPaintStudio.tsx acknowledges the withheld-close refusal with a per-WINDOW boolean (declared once, set true on the first refusal, never reset). The first latch episode is safe, but within the same Studio window a later refused track — one whose own restore also refused and which holds its own withheld script — closes silently, withholds its save and destroys its script. This is the exact data loss CR-01 was filed for, re-armed by the acknowledgement's scope.

WR-15 (truth 25, blocker): hasWithheldContent() treats the whole launch-scoped durable-base map as this binding's content. The map deliberately spans tracks, so another track's durable base makes a latched-but-empty binding report withheld content, refuse the close and name the destructive whole-track clear as the remedy for content the binding does not hold.

Purpose: a refused close is a disclosure moment tied to a latch episode, never to a window, and the gate that decides whether to disclose counts only content this bound track owns.

Output: a controller-exposed latch episode with a behaviourally tested close gate, a per-episode acknowledgement in the Studio whose refusal states the discard consequence, and an own-key scoped durable-base arm on hasWithheldContent() with red-first pins for the own, foreign, anchor-owned and unknown-identity cases. No new dependency, no Rust, IPC, format, manifest or save-path change; the CR-02 latch, the save withholding law and the two human-judgment items (ROADMAP SC2 wording, 4K import responsiveness) are untouched.
