<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| held fit -> draw surface | The fitted anchors are session state derived from untrusted persisted points; the overlay turns them into paths and hit targets. |
| recorded points -> ghost | The original spine is projected straight into SVG path data; a malformed sample could break the render. |
| recorded points -> band | The pressure band is computed from persisted samples and cached across renders; a stale or misframed polygon misrepresents the paint. |
| gesture -> Studio | Every edit leaves the overlay as one callback; the overlay must never reach the record store or a bake itself. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-62-10 | Information disclosure / Tampering (session state reaching the document) | overlay held-fit fallback | high | mitigate | The overlay reads the session and writes nothing; no record-write, codec or bake import is added, and the tests assert an unchanged revision and no ledger entry across draw and gesture. |
| T-62-11 | Denial of service (malformed recorded points) | ghost projection / `drawnPathOf` | medium | mitigate | Non-finite projections are filtered, fewer than two survivors draw nothing, anchors go through `normaliseVectorAnchors`, and no branch throws into the render. |
| T-62-12 | Integrity (misleading footprint) | `buildStrokeBandCached` | high | mitigate | The cache is keyed by revision, width and height and cleared on any stamp change; an equality pin against `buildStrokeBand` proves the drawn ring is the real band for the current samples. |
| T-62-SC | Tampering (supply chain) | package installs | high | mitigate | REL-01: no dependency is added; every module is shipped and git-tracked. |
