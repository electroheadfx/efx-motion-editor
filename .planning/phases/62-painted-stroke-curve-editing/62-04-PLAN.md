## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| undo key -> in-flight bake | The undo arrives asynchronously while the host is mid-apply; a wrong decision publishes a ledger entry or reverts the wrong edit. |
| cancellation epoch -> session | The token is session state; a stale token must never suppress a newer bake. |
| undo -> history stacks | The stacks move only through the authoritative replay; a blind pop would consume an unrelated edit. |
| bake -> sheet | A cancelled apply may already have painted; the restore must republish the pre-edit script as the single authority. |
