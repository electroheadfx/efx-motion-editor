## Decisions Made

- **Add-alongside (D-01..D-05):** the rail set is a NEW session scope; single-rail selection remains the primary degenerate path — plain click collapses the set into it. No change to single-rail behavior.
- **Union-first routing (Pitfall 1):** Cmd+Shift+click is checked before plain Shift so the union combination cannot collapse into the range branch.
- **Anchor tick is paint-only CSS:** 2x8px #F2F5F7 at 0.7 opacity, top 4px, aria-hidden, pointer-events none — no geometry change to the 3px rail line.
- **Pitfall 6 (no default collapse):** resolveRailSetPostAcceptance has explicit operationKind branches; unlisted kinds return the current set unchanged so reconcile-on-revision remains the stale authority.
- **No set-aware focus fork:** the existing shared 43.4 roving machinery already orders every rail target by data-rail-first-frame, so set members are visited in canonical order by construction (matrix row 8).
