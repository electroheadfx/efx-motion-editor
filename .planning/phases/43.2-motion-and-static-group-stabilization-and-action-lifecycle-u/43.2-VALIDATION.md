## Sampling Rate

- **After every task commit:** Run the task's focused `pnpm --dir app exec vitest run <owned files>` command.
- **After every plan wave:** Run the cross-boundary focused suite for that wave plus `pnpm --dir app run typecheck`.
- **Before `/gsd-verify-work`:** Full Vitest, typecheck, and build must exit 0.
- **Before native UAT:** Fully restart the frozen-code parent and Physics Paint child session.
- **Max focused feedback latency:** 120 seconds.
