## Decisions Made

- Kept reference ownership in the controller: the panel consumes one immutable presentation snapshot and cannot recalculate Group ownership or coordinate Rust settlement.
- Used the accepted physical document revision captured with the disclosure to reject stale confirmation activation and refresh newly discovered references.
- Derived Group occurrence disclosure exclusively from canonical `visibleRanges`; product-facing `Fstart–Fend` labels are the only conversion from half-open ranges.
- Used one Signals-derived `actionMutationDisabledReason` for Save, Load/Apply, Play, Delete, Refresh, rename, row activation, Copy, Apply, Clear, confirmation choices, Escape, and Cancel.
- Kept the existing focused `useEffect` because DOM focus is an external lifecycle concern; no transaction state is mirrored into component-local hooks.
