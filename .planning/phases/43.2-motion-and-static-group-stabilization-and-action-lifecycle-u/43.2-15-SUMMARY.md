## Decisions Made

- Retained internal `scriptId`, `loopId`, `progressive`/`static`, controller names, and persisted wire vocabulary. D-34 is a product-copy contract, not a schema migration.
- Used one session Signal, `activeLinkedLoopClipId`, for passive linked-current context rather than copying Action or Group props into component state.
- Derived linked Groups from `rotoLoopClips`, whose canonical read remains subscribed to `physicPaintVersion.value`; no second range or fragment authority was added.
- Preserved orange selection as the explicit Group operation scope. Action activation updates only Action selection, linked current, and passive halo inputs.
- Kept timeline seeking exclusively in `navigateLinkedGroup`; Action activation and cursor-relative current initialization perform no navigation.
- Kept the internal right-panel state key named `scripts` to avoid unrelated state migration while changing only the visible tab label to Actions.
