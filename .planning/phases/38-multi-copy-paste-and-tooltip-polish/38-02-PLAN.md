<objective>
Propagate the `paste-key-group` literal through the five owners of the 36.14-20 semantic-operation seam — shared types, the pure physical resolver, the edit coordinator, the parent bridge, and (verify-only) accepted-only history — so a group of copied real Roto keys can be pasted as one atomic, thrice-validated, accepted-only transaction per D-04..D-07. Requirement: 38-GROUP-PASTE.

Purpose: group paste is a semantic (record-carrying) operation exactly like `paste-key`; extending the existing five-owner protocol — rather than adding any new route — is what keeps one transaction authority, one history entry, and split-authority regressions impossible by construction.
Output: the full literal chain compiles; the pure resolver accepts a well-formed group intent onto all-empty destinations producing complete frozen nextRecords + semanticDelta, and rejects atomically on any occupied, out-of-range, or over-capacity computed destination; coordinator and bridge revalidate the same delta.
