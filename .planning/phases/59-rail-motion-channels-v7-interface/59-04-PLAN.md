<objective>
Mirror the rail-motion canonical term in Rust and extend the cross-language golden fixture so the
two encoders are proven byte-identical for a motion-bearing document and fail closed on malformed
input.

Purpose: the physical-edit guard recomputes the hash from the caller's document and rejects a
mismatch. A TS-only motion term would make every motion-bearing reveal/playscript apply fail at
runtime, exactly like the `railKind` divergence this phase already repaired.
</objective>

  <behavior>
    - Absent or empty `railMotions` appends nothing.
    - Non-empty appends `rail-motions:` + the exact byte format in `<interfaces>`.
    - Validation mirrors TS: array cap 512; railId/anchorKeyId bounded non-empty strings; channels 1..5; ids in the five-value union; keys 1..4096; frame strict ascending integer 0..1,000,000; value finite and channel-domain valid; easing `hold|ease`; wiggle finite ≥ 0.
    - Grouped Position pairing is enforced (position-x and position-y frame sets identical).
    - Any violation returns Err with a message naming the field; the function never panics and never skips the term.
  </behavior>
  <action>
    Implement `fn canonical_rail_motions(rail_motions: &[Value]) -> Result<String, String>` beside `canonical_loop_clips`. Sort a borrowed vector by `railId` (`as_str().unwrap_or("")` like the loop encoder, then `cmp`). Extract every field with `.ok_or("<field> is malformed")?`. Reuse `canonical_string` and `canonical_number`; do not hand-format numbers.

    Validate the channel union with a `match` over the five ids; an unknown id returns Err. Validate keys are objects and each frame is an integer that strictly increases. Validate value domains with a helper that takes the channel id: position ±1,000,000; scale > 0; rotation finite; opacity 0..1. Validate `easing` by exact string equality. Validate `wiggle` finite and non-negative.

    Add a grouped-Position check after parsing each record: if exactly one of position-x/position-y exists, or their frame vectors differ, return Err. Do this before writing any bytes for that record, so the error is deterministic.

    Wire the term into `canonical_physical_source`: `if !rail_motions.is_empty() { source.push_str(&format!("rail-motions:{}", canonical_rail_motions(rail_motions)?)); }` immediately after the `loops:` block and before `incoming-breaks:`. Read `rail_motions` from `object.get("railMotions").and_then(Value::as_array)` with `None` mapping to an empty slice (absent means empty).

    Tests first (RED) in the existing `#[cfg(test)] mod tests`: empty/absent adds nothing; a valid two-channel record produces the expected substring; each malformed case returns Err (assert on the message fragment); a channel list in non-canonical order produces the SAME bytes as the canonical order (the writer canonicalizes, so Rust must sort channels into the fixed order rather than trusting input order).
  </action>
