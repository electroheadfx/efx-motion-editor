<objective>
Make Scale, Rotation and Opacity reachable: give the expanded motion block a real add-channel row, a
session-owned menu that lists only the channels the rail does not carry, and a production command path
that seeds the channel through the existing reducer.

Purpose: today no production code writes `motionChannelMenuOpen`, no code dispatches an add-channel
command, and `TimelineMotionBlock` hard-codes `onClose={() => {}}`. Only the Position pair seeded by
Animate can ever carry motion, so three of the four advertised channels are unreachable and MOTN-03 is
false in the shipped product.

Gap closed: G1 — CR-03 (add-channel affordance unreachable; only Position can carry motion). The
IN-02 inspector-honesty half of G1 is plan 59-21, which depends on this plan. That split keeps this
plan at 11 files and moves the four inspector files out of the measured-row work.

Scope disposition (revision INFO, deliberately unchanged): the 11-file set sits above the advisory
10-file band and below the 15-file blocker band, and the estimate is 70k / 100k with
`over_budget: false`. The command, the row, the overlay and both hosts are one indivisible slice —
splitting them would ship an affordance that cannot add a channel — so the file set stays at 11.
</objective>
