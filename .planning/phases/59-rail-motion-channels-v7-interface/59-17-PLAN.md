<objective>
Make Scale, Rotation and Opacity reachable: give the expanded motion block a real add-channel row, a
session-owned menu that lists only the channels the rail does not carry, and a production command path
that seeds the channel through the existing reducer — then make the inspector honest about channels the
rail does not carry.

Purpose: today no production code writes `motionChannelMenuOpen`, no code dispatches an add-channel
command, and `TimelineMotionBlock` hard-codes `onClose={() => {}}`. Only the Position pair seeded by
Animate can ever carry motion, so three of the four advertised channels are unreachable and MOTN-03 is
false in the shipped product. The same surface must never look actionable for a channel that does not
exist (MUI-06, IN-02).

Gap closed: G1 — CR-03 (add-channel affordance unreachable; only Position can carry motion) plus the
IN-02 honesty half the gap names.
</objective>
