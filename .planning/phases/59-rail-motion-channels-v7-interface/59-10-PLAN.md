<objective>
Build the v7 motion lane surface: one 18px lane per populated DISPLAY lane (Position is one lane
backed by two model channels), header cluster, cell grid, evaluator-sampled curves, 6×6 keys, and
the block outline primitive.

Purpose: this is the only place a user sees motion. It must be a pure function of props so the whole
surface is provable without a DOM, and it must read its geometry from the design tokens so the row
host (59-11) and the outline agree to the pixel. Any interpolation here would be a second evaluator.
</objective>
