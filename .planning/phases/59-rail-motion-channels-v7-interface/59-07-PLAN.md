<objective>
Make motion a first-class store mutation: the apply payload carries it, the child store owns it, the
parent bridge forwards it, the coordinator stages it, and undo/redo restores it — without any motion
edit invalidating cached content rasters.

Purpose: 59-02 and 59-03 gave motion a model, a canonical encoding and a store map. Without this plan
the map is write-only: no edit can reach it, no undo can restore it, and no parent document can carry
it. The raster-revision split is load-bearing — `buildPhysicPaintRotoPhysicalRevision` now includes a
term that changes on every motion key drag, and every frame cache key currently interpolates that
same string.
</objective>
