<objective>
Implement Gate B: a durable rail identity that survives splits, first-key deletion, merges, re-anchors
and rail moves, plus the reconciliation that decides which stored record belongs to which live rail.

Purpose: rail identity today is drawing-key-derived. Without this plan, deleting the first key or
removing a break makes motion jump to another rail, vanish, or animate a rail the user never
animated — the exact silent-mutation class the project forbids.
</objective>
