# Phase 36.14 Plan 03: Clean Physical Cutover Summary

Physical timeline projection seam, store records, atomic hydration, identity-based Signals selection, and direct physical workflow/session/editing ports cut over from the removed source/display model.

## What Was Built

### Task 1: Physical store-to-Signals slice
- Extracted `projectPhysicPaintRotoPhysicalTimeline` shared read-only projection seam from the resolver; the edit resolver's `finalizeProposal` now calls this seam instead of duplicating cell derivation.
- Added validated per-layer `PhysicPaintRotoRealKeyRecord` collections and enabled-only `PhysicPaintRotoInterpolationState` to `physicPaintStore` with complete replacement, identity/frame lookups, and derived projection.
- Created `rotoPhysicalTimelinePorts.ts` as the stable read-only port bundle interface for Studio and later action plans.
- Added `selectRotoPhysicalTimelineView` identity-based physical selector with semantic current-cell state, selectedKeyId, selectedRealKey, and ordered real records.
- Deleted `rotoSourceDisplayModel.ts` and inlined legacy helpers in modules pending later plan migration (`physicsPaintRotoKeyController.ts`, `rotoKeyTransactions.ts`).

### Task 2: Atomic physical launch hydration
- Added `hydrateRotoPhysicalLaunch` atomic hydration contract that validates the complete record collection, interpolation state, Script Motion settings, and derived projection before any store mutation.
- Added `initializeEmptyRotoPhysicalLayer` for new empty layers with no placeholder real key.
- Simplified `useRotoInterpolationController` to send only an enabled-state action to the physical store; no records, navigation, selection, or Script Motion are rewritten.
- Wired `selectedKeyId` signal and `rotoKeyRecords`/`rotoInterpolationState` in `PhysicsPaintStudio.tsx`.

### Task 3: Session, editing, and timeline actions cutover
- Added physical input fields (`rotoKeyRecords`, `rotoInterpolationState`, `currentCell`, `selectedKeyId`) to the session contract.
- Added `selectedKeyId`, `selectedRealKey`, and `currentCell` to the frame editing controller input.
- Added physical view (`physicalView`, `currentCell`, `selectedRealKey`, `orderedRealKeyRecords`, `generatedCells`, `physicalCells`) as computed Signals in the timeline model.
- Added physical input getters to timeline actions.
- Wired `PhysicsPaintStudio.tsx` to pass physical state to all hooks.
