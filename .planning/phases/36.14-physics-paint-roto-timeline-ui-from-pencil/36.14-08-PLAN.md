## Phase Goal

**As a** stop-motion animator, **I want to** have every real Roto key, generated in-between, timeline edit, persisted frame, and rendered output use one deterministic physical-frame authority, followed by a polished timeline UI that exposes the approved behavior without duplicating business logic, **so that** editing, reopening, previewing, and exporting the same Roto work cannot disagree about frame identity.

<objective>
Deliver Force Spacing through the same physical resolver, acknowledged coordinator, and accepted-only history path for every fitting canonical nonnegative integer N per D-01, D-02, D-03, D-08, D-09, D-11, D-12, and D-17 through D-20. Anchor the first ordered real key, preserve stable identity order and identity-owned payload, produce exactly N physical interior slots, accept zero, reject invalid or over-capacity work before publication, and record exactly one accepted changed operation.

Purpose: Give users one explicit deterministic way to normalize the complete physical spacing of real Roto keys without reviving the removed live interpolation-count authority or creating a separate reliability protocol.

Output: A canonical session-local Force Spacing input, one semantic action over the existing complete-proposal runner, Studio composition, a minimum accessible input plus Apply control, exact no-op/rejection behavior, one accepted history handoff, and removal of the active legacy live-count route while final geometry remains assigned to Plan 15.
</objective>
