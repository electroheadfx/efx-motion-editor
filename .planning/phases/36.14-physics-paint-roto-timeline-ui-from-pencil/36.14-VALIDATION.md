## Mandatory Sequence

1. Implement the production physical schema/model and remove legacy timing fields and readers.
2. Implement the shared acknowledged transaction, physical edit operations, and downstream parity.
3. Run `pnpm --dir app typecheck` and `pnpm --dir app build`.
4. Stop for user-owned native physical-model UAT and require the exact Plan 12 approval token.
5. Only after that exact human response, create and byte-verify `36.14-12-APPROVAL.txt`; Plan 13 remains blocked until this deterministic evidence command passes.
6. Do not create, modify, or run regression tests before the recorded Plan 12 approval evidence passes.
7. After recorded approval, Plan 13 transfers valid behavior from six obsolete wrapper tests to final-owner tests, deletes those six files, rewrites `useRotoInterpolationController.test.ts`, and passes its focused eight-file matrix.
8. Only after Plan 13 cleanup succeeds, Plan 14 runs downstream-focused regressions and the unchanged full `pnpm --dir app exec vitest run` last.
9. Integrate the final UI, complete user-owned native visual and interaction validation, and require the exact Plan 18 approval token.
10. Only after that exact human response, create and byte-verify `36.14-18-APPROVAL.txt`; phase acceptance remains blocked until both approval evidence commands pass.

---

## Sampling Rate

- **After each pre-UAT production task:** Run `pnpm --dir app typecheck` when the bounded change can compile independently; do not run Vitest.
- **After each pre-UAT production wave:** Run `pnpm --dir app typecheck`.
- **At the physical-model gate:** Run `pnpm --dir app typecheck` and `pnpm --dir app build`, then stop for human-only native UAT. After the exact response, verify the recorded token with `printf '%s\n' 'APPROVED 36.14-12: native physical-model UAT passed' | cmp -s - .planning/phases/36.14-physics-paint-roto-timeline-ui-from-pencil/36.14-12-APPROVAL.txt` before Plan 13 can start.
- **After each approved post-UAT regression task:** Recheck canonical Plan 12 approval bytes, then run the focused `pnpm --dir app exec vitest run <files>` command.
- **Between Plans 13 and 14:** Require all six stale tests absent, the rewritten interpolation-controller test present, and the exact Plan 13 cleanup marker after its eight-file matrix; summary text supplements repository-state checks and never supplies native-UAT approval.
- **Before final native UI validation:** Plan 14 runs full `pnpm --dir app exec vitest run` only after the cleanup gate, then typecheck and build.
- **At final phase acceptance:** Stop for human-only native UAT. After the exact response, verify `36.14-12-APPROVAL.txt` and `36.14-18-APPROVAL.txt` byte-for-byte before accepting the phase.
- **Max feedback latency:** Keep focused checks bounded to the files changed by the active plan.
