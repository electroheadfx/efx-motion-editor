- **Fix:** dropped the binding, kept `await Promise.race([livePromise, sleep(1500).then(() => null)])` as the capture-wait bound (live plane is captured synchronously inside the publication listener during the flush; the race only matters if that capture never fired).
- **Files modified:** app/src/components/physic-paint/performance/depositSpeckleCapture.ts
- **Commit:** c54680bf

**2. [Plan deviation - ordering] flush BEFORE awaiting the live plane promise**
- **Found during:** Task 3 implementation (engine phase-machine read)
- **Issue:** plan step 3 says "await the live plane promise, then flushPendingStrokeFinalizations()". Awaiting first deadlocks whenever the publication has not fired yet: the only other driver is the scheduled rAF drain behind a 400 ms idle gate (STROKE_FINALIZATION_IDLE_MS), unreliable headless and a hang if the listener never runs.
- **Fix:** `drawScriptedStroke` → `flushPendingStrokeFinalizations()` FIRST (publication fires synchronously inside the flush: live plane captured, then the finalize transfer records post-raster for the same tag) → `expectRaster = false` → race the live promise with a 1500 ms bound → settle sleep → snapshot row. Both D-08 artifacts still come from the real two-pass settle.
- **Files modified:** app/src/components/physic-paint/performance/depositSpeckleCapture.ts
