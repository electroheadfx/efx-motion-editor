## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] Plan-literal dart-throwing (RSA) replaced with seeded two-band stratified jitter**
- **Found during:** Task 2 (pre-emptive analysis before writing the placement pass)
- **Issue:** RSA provably cannot satisfy both pins: the car-parking jam limit (~0.748 x span/minGap) caps placement at ~36 < 40 required count, and RSA body-band density lands ~15 < 20 lanes needed for ratio >= 1.5 (plus the FP equality trap: 25/16.666666666666668 = 1.4999999999999998 < 1.5 at the symmetric split).
- **Fix:** stratified positions across each band with seeded jitter bounded so gaps stay in [minGap, maxReach] by construction; 24 attempts then unjittered-stratum fallback. Still one seeded placement pass keyed by `seededDraw` slots (`${key}#${k}#${attempt}`, drawKeys `poisson`/`width`) — D-13/D-02 laws hold, mutationId reproducibility holds. Documented in the footprintLanes.ts header.
- **Files modified:** packages/efx-physic-paint/src/brush/footprintLanes.ts
- **Commit:** 1934db0b
- Not a Rule 4 stop: same module, same contract, both pin laws satisfied by construction; the plan's must_have states the laws, not the sampling algorithm.

**2. [Rule 1 - Bug] Gauge keyed on raw arc aliased to edge chatter — NW_ARC_SCALE = 0.1**
- **Found during:** Task 2 GREEN gate (legacy 'shape noise' distant-vs-adjacent failed: 0.0394 < 0.0409)
- **Issue:** `traceShapeNoise` keys fbm on `arc * 0.05`; at 10 px sampling that is a 0.5-unit step — exactly Nyquist for wavelength-1 value noise — so the "low-frequency" gauge was near-white per-sample jitter (the D-12(a) defect itself). The 52.4-01 tracer passed only because its 10-lane layout happened to avoid the aliased lanes; the new count = floor(radius) layout exposes them.
- **Fix:** scale the arc key by `NW_ARC_SCALE = 0.1` in production (paint.ts gauge line). Amplitude bound unchanged; every pin re-verified green. The pin threshold was never adjusted.
- **Files modified:** packages/efx-physic-paint/src/brush/footprintLanes.ts, packages/efx-physic-paint/src/brush/paint.ts
- **Commit:** 1934db0b

**3. [Plan-sanctioned] Legacy 'shape noise' assertions rewritten**
- **Found during:** Task 2 (tracer's unclamped-width assertions cannot hold under the new clamp)
- **Issue:** `spread()` is scale-invariant, so the pressure-growth ordering can never hold under a pure width lever; rim lanes at p=0.2 sit on WIDTH_FLOOR and their clamp transitions pollute adjacent deltas.
- **Fix:** pressure growth measured in absolute `stdev` (heavy > light); distant-vs-adjacent ordering scoped to body lanes (never floor-clamped at p=0.2: raw >= 1.3 x 0.7 x 0.8 > 0.5). Per-sample write counts and single-constant-alpha assertions kept verbatim.
- **Files modified:** packages/efx-physic-paint/src/brush/paint.bristleSeed.test.ts
- **Commit:** 1934db0b

**4. [Deviation - tooling] RED/verify command substitution**
- **Found during:** Task 1 RED run
- **Issue:** `pnpm --filter efx-physic-paint exec vitest` fails with `ERR_PNPM_RECURSIVE_EXEC_FIRST_FAIL Command "vitest" not found`.
- **Fix:** same substitution as 52.4-01: `cd packages/efx-physic-paint && ../../app/node_modules/.bin/vitest run ...`. Evidence command records the exact invocation.
