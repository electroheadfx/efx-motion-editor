## Body vs streaks

### Q1 — What is the stroke mark made of after this phase?

| Option | Description | Selected |

**Notes:** fillFlat goes away as a mark-maker; overlapping streaks build the body (R1's "build-up by overlap"). PIN 0 and thick==thin tier parity are held by DiVerdi §4.1 thickness scaling (count down → thickness up), not by a fill safety net. If UAT shows the live ¼ tier going patchy, we fall back to option 3 explicitly as a named change — not silently.

### Q2 — Without a fillFlat floor, how does the stroke body reach PIN 0 body opacity 1.0000?

| Option | Description | Selected |
|--------|-------------|----------|
| Saturation by overlap | N streaks with enough lateral density that the ribbon center composites toward alpha 1. Pure R1 "build-up by overlap". | |
| Lateral density profile | One routine, but streak density/alpha follows a lateral profile: dense and more opaque in the body, sparser/thinner toward the rim. | ✓ |
| Tune after first look | Accept that body opacity may read slightly under 1.0 at first and let UAT judge. | |
| You decide | Claude picks the profile that keeps PIN 0 == 1.0000 and isolatedPx == 0. | |

**User's choice:** Lateral density profile — with the profile driving geometry only.
**Notes:** A uniform lateral distribution gives the rim the same coverage as the center, so it cannot deliver translucent edges. A static lateral profile — dense/wide body lanes, sparse/thin rim lanes — is footprint shape (lane placement + bristle width + overlap count), one routine, not a second fill. PIN 0 is then earned deterministically: body lanes are specified to saturate to 1.0000 by overlap; rim lanes stay translucent. Hard constraint on "more opaque": density, width, and overlap count only — not a per-streak alpha ramp. Per-streak alpha stays a single constant; rm2 forbids alpha modulation as an envelope mechanism and PIN 0 semantics are "pressure affects SIZE only". The lateral profile is baked lane geometry, identical at every water and every gesture. Option 3 is not available: PIN 0 must stay green at existing bounds (1.0000 at every water) — it is a locked invariant, not a post-UAT tune target.

## Streak value character

### Q1 — Do the streaks carry value modulation (dark/light) or stay uniform-color?

| Option | Description | Selected |
|--------|-------------|----------|
| Keep dark/light lanes | Keep per-lane dark ×0.7 / light ×1.4 over the base color. | |
| Uniform base color | All streaks use the base color; only alpha and geometry vary. | ✓ |
| Subtle modulation | Same dark/light structure, tighter band (e.g. ×0.9 / ×1.1). | |
| You decide | Claude picks the band that makes the mark read as bristle at zoom 4. | |

**User's choice:** Uniform base color.
**Notes:** All streaks use the base color; the per-lane ×0.7 / ×1.4 value modulation is the pepper and dies. Transparency carries the bristle character, but through coverage geometry, not a per-lane alpha parameter: each streak has one constant low alpha ("continuous low alpha", R1), and translucency emerges from the lateral density profile (dense/wide body → sparse/thin rim), DiVerdi §4.1 widths, and the shared skip stream. Thin and sparse reads more transparent optically without touching alpha — in DiVerdi's model bristle thickness is geometry, and that is what carries bristle character. Today's per-point alpha noise is the alpha half of the salt-and-pepper and dies with it. A per-lane alpha profile is deliberately out of 52.4: (a) PIN 0 saturation stays deterministic (1−(1−α)^k → 1.0000 by overlap) — a dipping per-lane alpha makes body saturation a per-lane gamble and the pin flaky; (b) it would be a second load-model, stealing R2's and R3's named roles; (c) rm2 stays clean. Named fallback, same pattern as the soft-fill fallback: if UAT at zoom 4 reads the rim as too hard-edged, the iteration is a baked lateral alpha profile — deterministic, gesture-independent — never a per-brin random alpha. UAT row: at zoom 4 no light/dark striping; the body reads flat base color at saturation; rim translucency and bristle character come from coverage (thin/sparse lanes), not from value noise.

### Q2 — Is the streak alpha constant tier-independent?

| Option | Description | Selected |
|--------|-------------|----------|
| One alpha, both tiers | Same single alpha constant at tier=live and tier=final. Coverage parity rides §4.1 thickness alone. | ✓ |
| Per-tier alpha | Live uses a different constant alpha to compensate for fewer brins. | |
| You decide | Claude keeps alpha tier-independent and asserts body mass in a tight band across tiers. | |

**User's choice:** One alpha, both tiers.
**Notes:** A single constant streak alpha at tier=live and tier=final. Coverage parity rides DiVerdi §4.1 thickness alone (count down → width up, area preserved); the capture-pin's thickness allowance is the only tier difference. If live ever reads denser or lighter than final, the lever is the §4.1 width constant (geometry), measured at UAT — never a second alpha. Per-tier alpha is out: compensating coverage with alpha is exactly the modulation rm2 forbids, and two alphas would be two looks to keep in sync, weakening "finalize refines, never rewrites."

### Q3 — What happens to nA alpha noise and pressureMod in the footprint routine?

| Option | Description | Selected |
|--------|-------------|----------|
| Strip all alpha mods | nA alpha noise and pressureMod both die. One constant alpha per streak. Pressure keeps its width lever only. | ✓ |
| Keep pressureMod | nA dies, but pressureMod stays so light pressure reads lighter. | |
| You decide | Claude strips every non-constant alpha term and pins the source shape. | |

**User's choice:** Strip all alpha mods.
**Notes:** Both die: nA per-sample alpha noise (the seeded salt-and-pepper's alpha half) and pressureMod (gesture translucency = R2, out of scope, and it fights PIN 0 "pressure affects SIZE only"). One constant alpha per streak; pressure keeps its width lever only (pMod / SIZE). Geometry carries everything else: lateral density profile, §4.1 widths, shared skips. Acceptance pin (source-shape, same pattern as the Math.random and getImageData gates): no non-constant alpha term in the deposit path — alpha is a literal or a single named constant, never a function of pressure, velocity, arc length, or per-sample noise. Any future light-pressure translucency is R2's named role in 53.1+, not a hidden term here.

### Q4 — Does per-sample width noise (nW) survive as bristle thickness character?

| Option | Description | Selected |
|--------|-------------|----------|
| Keep width noise | nW stays: per-sample width variation along a streak is bristle thickness geometry (DiVerdi "thin bristles" / §4.1). | ✓ |
| Strip width noise | nW dies too. Each lane has one width (plus §4.1 tier scaling and pMod). | |
| You decide | Claude keeps whatever width variation makes the streaks read as bristles. | |

**User's choice:** Keep width noise.
**Notes:** nW survives as bristle thickness geometry — DiVerdi §4.1 "thin bristles" is a thickness story, and per-streak thickness variation is what makes a lane read as a bristle instead of tape. Value noise is fake pigment, alpha noise is fake load, width variation is real bristle geometry. Two bounds so it cannot smuggle the speckle back in: (a) nW is low-frequency bristle gauge along the arc (arc-keyed, seeded, coherent) — a bristle thickens and thins slowly — not high-frequency per-sample jitter, which would ragged-edge the streak back into salt-and-pepper; (b) a width floor keeps every streak above the sub-pixel hairline that would alias into edge speckle (trace width stays inside the spec's sub-2 px bound, with a real minimum). Same shared seeded stream at both tiers, so the silhouette parity pin holds. If UAT at zoom 4 reads edge chatter, the lever is the nW amplitude bound — never a second noise class, never back to per-point skips.
