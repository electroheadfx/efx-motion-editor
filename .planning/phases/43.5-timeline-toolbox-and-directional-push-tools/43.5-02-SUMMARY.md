## Accomplishments

## Decisions Made
- Relocated controls enter the memoized static chrome as flat props + useCallback'd handlers rather than the whole `physicalActions` object, preserving `memo(PhysicsPaintWorkflowStaticChromeImpl)` while keeping rendered markup byte-identical (D-03)
- The Key Spacing heading always renders; the form renders only when `forceSpacingControlsPresent` (mirror of the original `physicalActions ? ... : null` guard), so the popover never shows a partial second section
- The Blend badge is a pure projection of `props.interpolationEnabled` — absent when off, no button paint change, never interactive (D-04)
- The popover panel uses the app liquid-glass language instead of the UI-SPEC flat card, with the blur/saturate on an empty `::before` so the panel never becomes a containing block for the relocated `position:fixed` tooltip (smoke fix 3)
- Dismissal is self-contained: window capture-phase outside-pointerdown + Escape listeners registered only while open; one Escape handles at most one layer (D-01, D-02, Pitfall 2)
