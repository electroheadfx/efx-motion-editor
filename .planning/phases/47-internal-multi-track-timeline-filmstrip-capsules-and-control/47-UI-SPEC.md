# Phase 47 — UI Design Contract

> Visual and interaction contract for the internal multi-track timeline, filmstrip capsules, and track controls inside EFX Physic Paint Studio. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Primary authority:** `47-CONTEXT.md` D-01..D-18 (gathered 2026-08-24), the locked `SPECS/milestone-v1.0.0-plan.md` §Phase 3 + §"Timeline visualization" + §"Required truth tables", and the carried-forward `43-UI-SPEC.md` filmstrip/rail contract. Supporting authority: `.planning/REQUIREMENTS.md` §TML (TML-01..TML-08), Phase 46 store/data decisions (D-08/D-09 cross-track move, D-14 acknowledge-and-delete), and the existing EFX Physic Paint Studio implementation.

**Copy-language correction (user, overrides spec):** all user-facing copy in this phase is **English**. The spec's French copy gate (`clip suivant — interrompt la boucle` / `Boucle raccourcie par le clip suivant`) is a recorded v0.9 divergence, not shipped copy. Shipped labels: **"Loop shortened by next clip"** and **"next clip — interrupts the loop"**. Never implement French labels.

**Naming contract (locked, carried from Phases 45/46):** "EFX Paint" = the inline main-editor Basic/FX layer (out of scope, unchanged). "EFX Physic Paint" = the independent module + Studio window — the sole target of v1.0.0 and this phase.

**Phase boundary:** this phase is the UI + gesture layer. The data/state layer (track-local addressing, track-aware undo, cross-track copy/paste/move data ops, Hold linked-source semantics, deletion laws) was built in Phase 46. The internal compositor (opacity/blend application, flattened parent raster) is Phase 48; Phase 47 only reflects hide/solo in the Studio preview. Background clip import/repeat/fallback-config UI is Phase 49; Phase 47 renders the Bg row and clips when present.

## Geometry and Layering Contract

### Strip structure (multi-row generalization)

The single 38px lane of the current strip becomes N Paint rows + one Background row. The existing chrome bands stay:

| Band | Height | Phase 47 rule |
|------|--------|---------------|
| Workflow header (global toolbar) | 46px | unchanged, stays on top (D-01) |
| Timeline top border | 1px | unchanged |
| Ruler | 28px | unchanged |
| **Rows region** | **141px** | **vertically scrollable; N Paint rows + 1 Background row** |
| Roto action row (global, routes to active track) | 34px | unchanged, stays at the bottom |
| Horizontal scrollbar | 14px | unchanged |
| **Strip total** | **264px** | **grows from 161px; multiple of 4** |

- **Row height: 48px** per Paint row and per Background row (multiple of 4; accommodates the filmstrip capsule source-cycle cells + badges). The rows region shows ~2.9 rows at 48px; vertical scrolling reveals the rest (D-05).
- **Header column: 140px default, user-resizable** via a drag handle on its right edge (D-01). The frame area never depends on name length (D-02).
- **Frame pitch: 18px** (`ROTO_CELL_WIDTH_PX`, unchanged). Ruler, cells, and capsules share the same horizontal scroller and one horizontal scrollbar.
- **Vertical scrollbar:** a slim vertical scrollbar on the right of the rows region. The header column stays pinned while rows scroll beneath it (D-05). The active row auto-scrolls into view when the active track changes (track switch, undo auto-activation per Phase 46 D-04, keyboard navigation).
- The strip must not change `grid-template-rows` of `.physics-paint-studio` beyond the strip's own height; the canvas region (`minmax(0, 1fr)`) flexes to absorb the strip growth.

### Header column layout (per row)

Each Paint row header contains, left to right: **reorder grab area** (distinct grip + cursor, D-08), **track name** (truncated with ellipsis, full name on hover tooltip, D-02), **hide toggle** (eye icon), **solo toggle** (solo icon), and **hover actions** (duplicate, delete icon buttons, revealed on row hover, D-07). The Background row header shows the lock indicator instead of reorder/hover actions (D-06).

### Active-track marking (D-04)

- **Accent-colored left border** (3px, blue accent family — see Color) on the active row header.
- **Subtle row background tint** across the active row's full width.
- **Bold track name** in the header column.
- This is distinct from rail selection colors (orange `#F59E0B` selection line, purple `#8B5CF6` / cyan `#06B6D4` loop rails) and from the orange current-frame cell outline.

### Filmstrip capsule geometry (D-11, D-12, D-13)

The capsule evolves the Phase 43 rail inside the 48px row. The locked Phase 43 rail semantics stay: selection, drag, spacing, playback, purple/cyan rails, passive markers, white endpoint cuts. The capsule adds the spec elements around the rail:

- **Source-cycle cells** at the capsule head: one cell per source-frame reference, showing the source-frame mapping (thumbnail or source-frame cell).
- **Compact repetition band** for linked repetitions: a perforated/hatched band below a zoom threshold; above the threshold, each repeated occurrence expands into lighter linked cells (same source-frame mapping, lighter tone). The threshold is derived from cell width so expansion is gradual and predictable (D-13).
- **Badge** on the capsule: requested duration (`Cycle 5f × 3 = 15f`, `Cycle 1f × 20`, `Cycle 5f × ∞`). When a next clip shortens the loop, the badge switches to the distinct shortened visual + **"Loop shortened by next clip"** label (D-12).
- **Diagonal cut** on a partial final cycle.
- **Following-clip label:** **"next clip — interrupts the loop"** (D-14).
- Full detail (repeat instance, source-frame index, source asset, provenance) stays in the tooltip (D-12).
- The capsule is absent from the DOM when the canonical Loop Clip collection is empty (Phase 43 contract).

## Color

### 60/30/10 contract

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#37393A` with surrounding `#3E3F41` | existing timeline, strip, and sidebar surfaces |
| Secondary (30%) | `#20262D`, `#343638`, `#62666D` | header column, inspector card, existing tooltip |
| Accent (10%) | Progressive `#8B5CF6`; Static/Hold `#06B6D4`; selected `#F59E0B`; **active track `#365ED6` bg / `#6F90FF` border** | Mode-specific Loop Rail line, selected rail, active-track marking |
| Focus | `#F2F5F7` | 2px focus-visible ring only |
| Warning | `#FFB020` | truncated end treatment and shortened status only |
| Error | `#FF6B6B` | unresolved rail/marker, missing-source status, status-capsule rejection triangle |
| Destructive | existing EFX red treatment (`#FF9999` text / red border family) | `Delete track` action only |

**Accent reserved for:** normal and selected Loop Rail paint, selected-loop inspector accent, the active-track marking (left border + row tint + bold name), and the existing linked-frame inset border/dot. It is not used for every sidebar fact, ordinary text, or destructive/warning states.

**Active-track marking (D-04):** the active row uses the physics-paint active language already established in the Studio — `#365ED6` background tint with `#6F90FF` border (the same family as `.physics-paint-segmented-button.active`). This is deliberately distinct from the orange `#F59E0B` rail-selection line and the purple/cyan loop rails, so the active track never reads as a selected rail.

**Background row (D-06):** muted tone — darker/desaturated vs Paint rows (e.g., `#2A2C2E` row background with `#9CA3AF` label text) — plus a lock indicator. Gaps show the transparent checkerboard or the solid fallback swatch.

**Hide/solo state:** hidden rows render at reduced opacity (e.g., 45%) with the eye icon in its off state; soloed rows keep full opacity with the solo icon in its armed state (reuse the `physicsPaintSoloArm` pattern). Hide wins over solo (locked truth table).

### State precedence

Highest visible state wins:

1. Unresolved/error red
2. Keyboard focus ring
3. Selected accent/glow
4. Truncated amber terminal treatment
5. Hover color
6. Normal accent

Focus never hides error. Selection never replaces the amber end treatment. State changes alter paint only, never geometry.

### Empty states

- **No Paint tracks:** impossible — the last Paint track delete is refused (Phase 46 D-17). A fresh document always has exactly one Paint track + one Background row.
- **Empty frames on a track:** transparent cells (existing cell semantics); lower contributing tracks remain visible through empty upper tracks (locked truth table).
- **Empty Background row:** the fallback display — transparent checkerboard or solid fallback swatch (D-06). No clip-import UI in Phase 47 (Phase 49).
- **No Loop Clips:** the filmstrip capsule is absent from the DOM (Phase 43 contract).

### Error states

- **Cross-track drag rejection:** status capsule with red warning triangle (existing Phase 46 paste UX, D-17).
- **Last-track delete refusal:** `A document must always have at least one Paint track.` — surfaced without a destructive dialog.
- **Missing source:** existing `Source missing` status (Phase 43 contract).

### Destructive actions

| Action | Confirmation approach |
|--------|----------------------|
| Delete track | Acknowledge-and-delete dialog (Phase 46 D-14): states how many accepted frames will be removed; confirming removes the track AND its cached PNG sidecars in the same transaction (D-15). Hold references are severed first (D-16). |

## Interaction Contract

### Track CRUD (TML-02, TML-08)

| Input | Result |
|-------|--------|
| Click '+' at header-column bottom | Add a new Paint track below the existing Paint rows; auto-name `Paint {N}`; make it the active track |
| Double-click track name | Edit-in-place rename (D-03); Enter commits, Escape cancels |
| Hover a Paint row header | Reveal duplicate + delete icon buttons (D-07) |
| Click duplicate | Full deep copy with fresh identities (Phase 46 D-05): Paint frames, Roto keys, Loop Clips all copied self-contained, editable with zero effect on the source; name gets the ` Copy` suffix (D-09) |
| Click delete | Open the acknowledge-and-delete dialog (Phase 46 D-14); confirm removes track + cached sidecars; last Paint track delete is refused (D-17) |
| Drag the row header grab area | Reorder with a live insertion indicator; distinct grab area + cursor from content drag (D-08) |

- Track CRUD survives save/reopen; reorder changes compositor order but never track identity (stable UUIDs, D-10).
- Keyboard shortcuts for track CRUD are guarded against conflicts per the existing `isPaintEditMode()` shortcut-guard pattern (Pitfall m4).

### Active-track routing (TML-03, TML-05)

- Clicking a Paint row header (or the row body) selects it as the active track.
- Paint/Roto/PlayScript/Cut/Copy/Paste/drag operations route to the active track.
- When the active track is deleted, the nearest adjacent Paint track becomes the new active track (Phase 46 D-18).
- Undo of a cross-track entry auto-selects the target track (Phase 46 D-04), and the active row auto-scrolls into view (D-05).

### Hide/solo/opacity/blend (TML-04)

- **Hide/solo** live in the header column per-row (eye + solo toggles). The hide/solo truth table is applied to the Studio preview in Phase 47 (no solo → all visible; solo → visible+soloed only; hide wins over solo). Opacity/blend application is Phase 48 (CMP-03).
- **Opacity/blend** for the active track live in the right panel (a Track section): an opacity slider and a blend-mode select (`normal | screen | multiply | overlay | add`). These mutate the track's `opacity`/`blendMode` fields and bump the track revision.

### Cross-track drag (D-15, D-16, D-17, D-18)

- **All existing draggables can cross track rows**: real keys, Key Rails, Loop Clip Rails, rail sets. The drag starts on the source row and crosses into the destination row.
- **Plain drag crosses rows** — no modifier key. Crossing a row boundary automatically becomes a cross-track move: the destination row highlights as the drop target and a **live insertion preview** shows exactly where the dragged content will land in the destination row (frame position).
- On release, the move commits with the Phase 46 D-09 semantics (exactly copy-paste-delete: fresh identities in the destination, source items removed, Hold refs re-pointed fail-closed). Rejections surface through the **existing status capsule with the red warning triangle** — identical to the Phase 46 paste rejection UX.
- The row-reorder drag (header grab) and the content cross-track drag are **distinct interactions**: different grab areas and cursors, so timeline interactions never mutate another row accidentally (TML-05 acceptance).

### Filmstrip capsule (D-11, D-12, D-13)

- The Phase 43 rail interaction contract stays locked: selection (plain/range/toggle), drag, spacing, playback, double-click/Enter edit, keyboard roving, focus restoration.
- The capsule adds: source-cycle cells at the head, ×N/∞ + requested/effective badges, diagonal partial-cycle cut, high-zoom expansion (D-13).
- The badge always shows the requested duration; the shortened state is a distinct visual + `Loop shortened by next clip` label (D-12).
- Full detail stays in the tooltip (repeat instance, source-frame index, source asset, provenance).

### Busy and rejected-operation behavior

- During controller preparation/commit, selected rails and the sidebar inspector remain visible; rail targets expose `aria-busy="true"`; mutation actions use `aria-disabled="true"` with the current controller reason.
- No optimistic rail width, status, Cycle math, or sidebar fact changes. Update only from accepted canonical authority state.
- On rejection, preserve prior geometry, selection, focus, modal inputs, and source references. Announce the reason through the existing status capsule / sidebar status channel.

## Accessibility Contract

### Roles and names

- Multi-row timeline: `role="rowgroup"` / `aria-label="Paint timeline"`; each row `role="row"` with an accessible name from the track name.
- Active track: `aria-current="true"` on the active row.
- Header-column track name: text button for selection; `aria-label="Select track {name}"`.
- Rename input: `aria-label="Rename track {name}"`.
- Hide toggle: `aria-pressed` reflecting the hidden state; `aria-label="Hide track {name}"`.
- Solo toggle: `aria-pressed` reflecting the soloed state; `aria-label="Solo track {name}"`.
- Duplicate/delete hover actions: `aria-label="Duplicate track {name}"` / `aria-label="Delete track {name}"`.
- Add-track button: `aria-label="Add track"`.
- Filmstrip capsule: `role="group"`, `aria-label="Loop Clips"`; rail targets keep the Phase 43 accessible-name form.
- Status capsule: existing `aria-live="polite"`; rejected operations additionally use `role="alert"`.

### Focus visibility and target size

- Row headers and header-column controls keep the existing 2px `#F2F5F7` focus ring with 1px offset.
- Icon-only controls (hide/solo/duplicate/delete) use a minimum 24px hit target (existing icon-button geometry); the 12px rail target remains the explicit compact-editor exception.
- The active row auto-scrolls into view on focus/selection change (D-05).

### Reduced motion

- Row selection, hide/solo, capsule state, and geometry changes are immediate paint changes; no slide, scale, shimmer, pulse, width tween, or spring animation.
- Under `prefers-reduced-motion: reduce`, disable the existing 120ms color/background transitions for any newly touched controls.

### Contrast and non-color cues

- Active track uses both the accent left border and the row tint plus bold name — never color alone.
- Hidden rows use reduced opacity plus the eye-icon off state.
- Soloed rows use the solo-icon armed state plus full opacity.
- Shortened loops use the distinct shortened visual plus the `Loop shortened by next clip` label.
- No status relies on color alone.
