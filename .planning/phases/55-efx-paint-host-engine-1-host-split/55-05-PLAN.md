    - playFrame ← the engine-1 optional play-frame field or null — host-owned shared play anchor (not engine payload; schedules need it without reading P)
    - engine ← tool/color/params/hasPenInput/physicsMode (+ timestamp/playFrame engine-private copies if engine-1 still wants them, and a diffusionFrames mirror) as opaque P. Host never reads any of it
    Envelope-level mapping:
    - strokes[] ← brushes[{primary, continuations}] flattened in order: each group's primary then its continuations
    - parse reconstructs groups by the existing schema law: a stroke with cuisson > 0 is a continuation of the previous primary; cuisson === 0 starts a new group
    - brushPack ← a deterministic empty BrushPackSnapshot ({ kind: 'efx-physic-paint', brushes: [] }) — zero pack producers exist today, the field is required and pinned; Phase 56 engines fill real packs (D-22 snapshot travels inline, never a disk reference)
