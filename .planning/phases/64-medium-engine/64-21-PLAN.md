<objective>
Establish the extension's non-negotiable foundation: a recorded, pinned paper seed and a deterministic per-bristle state, with ZERO visual change.

This is the first slice of the acrylic bristle re-opening of Phase 64 (D-26..D-29). Spike 002 proved three things that this plan converts into shipped contract: the current engine already fails replay equality because `paperSeed` is rolled from `Math.random()` in the constructor and `setPaper` never re-seeds it (so a determinism gate would be meaningless without the pin); the bristle set is a pure function of one seeded RNG in a fixed call order; and the carrier's per-bristle reservoirs are three tiny 1×256 targets that cost nothing until the gather reads them.

Purpose: everything the next three plans measure rests on these two contracts. 64-22 cannot claim the gather is deterministic until the seed is in the record; 64-24 cannot add a last-touch layer to the undo atlas until the reservoir targets are already allocated and disposed with the sheet. And because the deposit stays exactly the shipping `brushInk` / `coverageDeposit`, this plan's acceptance is the STRONGEST kind the phase has: every committed baseline is byte-identical, so any movement is a defect in the plumbing rather than a look the reviewer has to judge.
Output: `bristles.ts` with its pinned test suite, the `paperSeed` field declared end to end in both languages with its derivation, the `setPaperSeed`/`getPaperSeed` engine seam, the `paperSeed` adapter option and every construction site that feeds it, the three reservoir attachments plus the static shape target, the `bristleCarrierFS` pass wired before the deposit, and the `determinismContract.test.ts` rewrite that retires the `withSeededMathRandom` workaround.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| stroke record → deterministic replay | An RNG draw or a seed the record does not pin makes a replay diverge from the live raster |
| TypeScript record → Rust record | A field declared in one language is silently dropped (or silently accepted) by the other at the `.mce` boundary |
| document record → engine sheet | An unpinned paper seed is re-rolled per session, so the same project renders two different sheets |
| bristle response → canvas sampling | The carrier must read the underlayer before the dab deposits, or it picks up its own output |
