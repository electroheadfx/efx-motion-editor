## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| light rows → layer document | A user-editable triple enters the persisted document record |
| document → live engine | A per-frame read decides the sheet's shading |
| document → bake adapter | A render-time read decides every baked and re-baked pixel |
| content signature → caches | A stale signature would serve pixels lit by an old light |
| render path → stroke payload | The light must never leak into the paint |
