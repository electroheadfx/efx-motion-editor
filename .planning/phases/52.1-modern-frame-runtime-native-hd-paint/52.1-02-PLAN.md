## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| JS (invoke) → Rust command | Untrusted frame bytes and dimensions cross the IPC boundary |
| Rust command → libwebp | Malformed WebP bytes are handed to the decoder |
