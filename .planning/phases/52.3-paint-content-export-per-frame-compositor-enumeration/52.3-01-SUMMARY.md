## Decisions Made

- FrameEntry union member names/shape: ContentFrameEntry (kind: 'content' + every legacy field unchanged), PaintFrameEntry (kind: 'paint', globalFrame, sequenceId = owning fx id, layerId = first physic-paint layer via the existing getLayerId helper, NO keyPhotoId/imageId), GapFrameEntry (kind: 'gap', globalFrame, sequenceId: string always '') — Claude's Discretion within D-01/D-02, per RESEARCH Open Question 2 (sequenceId: '' adopted).
- Paint enumeration branch placement: immediately after the tail pad inside the same computed, gated on entries.length === 0 (Finding F1) — with any content the tail pad already fills [0, N), so the branch fires only in content-empty projects and D-02/D-03 hold structurally.
- Coverage predicate: `f >= (seq.inFrame ?? 0) && f < getTimelineOverlaySequenceOutFrame(seq, targetLength)` — the identical function the overlay leg gates on (anti-drift lock, D-04).
- `void efxPaintVersion.value;` beside `void physicPaintVersion.value;` in the frameMap computed — conscious Pitfall-2 inclusion (enumeration reads getActiveTrackId -> getEfxPaintDocument; document-only mutations bump only efxPaintVersion).
- Case D motion-blur variant pins Pitfall 6: motionBlurEnabled -> status 'complete', renderFrameWithMotionBlur x5 (sub-frames floor to the same dense entry; the clear stays gated).
