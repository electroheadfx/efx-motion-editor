## Accomplishments

- Added dedicated `preact/compat` memo wrappers for `PhysicsPaintTopBar` and `PhysicsPaintPlayScriptDialog` without importing compat into either plain implementation module.

- Extracted the complete collapsed/expanded right-panel branch into `PhysicsPaintRightPanelRegion`, preserved its exact markup/copy/glyph/order, retained `MemoizedPhysicsPaintRightPanel` as the inner child, and moved the counter to the region implementation.
- Diagnosed the exact `render.toolRailImpl = 2` baseline as the navigation controller's `mutationLocked` true/false pulse. Static region identities now exclude that pulse through `staticControlsLocked`, while engine actions and canvas input continue using the original mutation lock.
- Preserved the dialog's internal `confirmationOpen.value` subscription, focus restoration, Escape/Enter/Tab behavior, controller identity, and return-focus ref identity.
