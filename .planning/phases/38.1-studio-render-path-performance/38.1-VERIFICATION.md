### Plan-Truth Deviation Noted (accepted via user UAT)

Plan 38.1-03 must_have truth 4 literally stated that a pure frame change re-runs **neither** per-render O(N) derivation. The shipped `projectRotoOnionPreviewFrames` useMemo (PhysicsPaintStudio.tsx:982-990) includes `currentFrame` in its dependency array — it is a genuine input (onion skins are playhead-relative), so a pure frame change still re-runs the onion projection. Recorded here for auditability; no override needed since the roadmap defines no formal success criteria and the goal-level bar was human-approved.
