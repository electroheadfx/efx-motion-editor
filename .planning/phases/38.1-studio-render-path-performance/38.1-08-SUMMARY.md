## Recorder API

`app/src/components/physic-paint/performance/physicsPaintPerformanceTrace.ts` provides:

- `PHYSICS_PAINT_PERFORMANCE_COUNTER_NAMES` — readonly canonical tuple containing all 26 counter names.
- `recordPhysicsPaintPerformanceCounter(name, amount?)` — increments only when the existing development plus `efx.physicsPaint.profile` localStorage gate is enabled.
- `snapshotPhysicsPaintPerformance()` — returns a detached snapshot containing the timing summary and every canonical counter with an explicit integer value, including zero.
- `diffPhysicsPaintPerformanceSnapshots(before, after)` — returns a detached full-registry delta, retains zeros, and treats malformed external missing values as zero.
- `clearPhysicsPaintPerformance()` — clears both bounded timing samples and counters while preserving the existing native profiler object.
- `window.__EFX_PHYSICS_PAINT_PROFILE__` — retains `clear` and `summary`, and now exposes `snapshot` and `delta` over the same recorder state.
