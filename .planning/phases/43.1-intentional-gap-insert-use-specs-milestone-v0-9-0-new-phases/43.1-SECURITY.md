# Phase 43.1 — Security

> Per-phase security contract: threat register, accepted risks, and audit trail.

---

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| child resolver/transport → parent bridge | Untrusted or stale complete physical-edit payload crosses into parent-authoritative mutation code. | Complete physical document + operation claims |
| persisted/runtime-shaped document → strict model parser | Unknown records and break owner IDs must be reconstructed and referentially validated before use. | Serialized project JSON |
| parent bridge → store replacement | Validated staged state becomes accepted canonical runtime state in one mutation. | Canonical document + revision |
| coordinator staged state → accepted acknowledgement | Rejection, timeout, or mismatch must not leave partial child state. | Staged proposal + revision |
| accepted command → Undo/Redo replay | Replay must restore the exact complete document, not reconstruct ownership by frame. | Accepted command ledger + snapshots |
| TypeScript invoke → narrow native command | Frontend supplies project authority plus one basename; Rust must prevent path selection/traversal from becoming general filesystem authority. | Project dir + staging basename |
| Safe Rust service → macOS FFI | Validated, synchronized directory paths cross one contained `unsafe` boundary to `renameatx_np`. | Canonical + staging dir paths |
| UI action state → coordinator command | Render/event state becomes a stable command request. | Resolver input + operation kind |
