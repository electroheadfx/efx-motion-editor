## Trust Boundaries

| Boundary | Description |
|---|---|
| current Signals state → action eligibility | Cursor/frame resolution and pending operation state may change between hover and activation. |
| action activation → resolver/coordinator | Preflight can become stale; resolver and parent remain authoritative. |
| internal failure → user-visible feedback | Raw resolver/bridge diagnostics must not leak through tooltip/status copy. |
| accepted acknowledgement → visible canvas/selection/status | UI must not claim acceptance before exact settlement. |
