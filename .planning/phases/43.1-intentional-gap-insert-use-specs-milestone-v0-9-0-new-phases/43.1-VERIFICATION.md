## Blocking Gaps

### GAP-03-A: Cache and project-file persistence are not one atomic authority transition

**Classification:** BLOCKER  
**Files:**
- `app/src/lib/physicPaintPersistence.ts:163-168,246-273`
- `app/src/stores/projectStore.ts:684-692,725-752`

`savePhysicPaintData()` publishes or removes the fixed-path canonical cache before `ipcProjectSave()` commits the corresponding `.mce` document. If project-file persistence fails, the last durable project can reference replaced or deleted sidecars.

**Required closure:**
- Introduce immutable generation-qualified cache paths.
- Persist the `.mce` document referencing the new generation before old-generation cleanup.
- On project-save failure, remove only the unpublished generation and preserve the prior project/cache pair.
- Add a behavioral test for project-save failure after successful cache generation publication.

### GAP-03-B: Native cache publication lacks containing-directory durability

**Classification:** BLOCKER  
**Files:**
- `app/src-tauri/src/services/physic_paint_cache.rs:45-69,88-120`
- `app/src-tauri/src/commands/physic_paint_cache.rs:23-52`

The Rust service synchronizes staged files and directories but does not synchronize `cache_parent` after the initial `fs::rename()` or replacement `RENAME_SWAP`. It can report success without proving that the canonical namespace entry is crash-durable.

**Required closure:**
- `sync_all()` the cache parent after every successful rename/exchange and before reporting success.
- Define explicit semantics for parent-directory sync failure after namespace mutation.
- Add a test seam proving parent-directory synchronization is requested.

### GAP-06-A: Provenance-only Loop Clip updates are treated as no-ops

**Classification:** BLOCKER  
**Files:**
- `app/src/stores/physicPaintStore.ts:1495-1511`
- `app/src/components/physic-paint/roto/physicsPaintRotoPhysicalModel.ts:878-897`

The store comparator omits `scriptId`, motion deformation/position, and `overrideColor`, while the canonical Loop Clip fingerprint includes them. Provenance-only changes can report success without installing state, advancing revision, marking dirty, or notifying rendering.

**Required closure:**
- Use one shared canonical Loop Clip equality helper covering every persisted field.
- Preserve the distinction between absent provenance and explicit null color.
- Add provenance-only replacement regression tests.

### Security: Browser frame-sync trusts arbitrary postMessage senders

**Classification:** CRITICAL SECURITY BLOCKER  
**Files:**
- `app/src/lib/physicPaintBridge.ts:1448-1467,1786-1797`
- `app/src/main.tsx:37-41`
- `app/src/lib/physicPaintBridge.test.ts:1994-2011`

The browser fallback listener validates payload shape but not `event.origin`, `event.source`, the active child window, or launch identity. A forged message can seek the editor timeline.

**Required closure:**
- Retain and verify the active Physics Paint child-window reference.
- Require the expected origin and exact source window.
- Include and validate the active launch operation ID so stale sessions cannot control the timeline.
- Create `43.1-SECURITY.md` through `/gsd-secure-phase 43.1` after remediation.
