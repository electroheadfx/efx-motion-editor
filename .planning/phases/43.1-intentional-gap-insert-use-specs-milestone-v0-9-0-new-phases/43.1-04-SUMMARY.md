## Decisions Made

- One target classifier is authoritative for both view state and activation; activation always re-reads live state instead of trusting previously rendered eligibility.
- Occupied selected real keys remain the only `insert-slot` target. A real key under an unselected empty intent fails with the dedicated occupied product reason rather than silently changing operation semantics.
- Linked/generated render-only frames are rejected before coordinator execution, while resolver and parent validation remain the final fail-closed authorities.
- Empty insertion uses a fresh stable key ID and `toEmptyKeyPayload` from a transparent blank frame; predecessor raster data is never copied.
- Empty insertion joins the coordinator's deferred-publication class so the child cannot spoof acceptance through optimistic markers, selection, cursor, canvas, status, or history.
