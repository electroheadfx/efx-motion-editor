<objective>
Make the async PlayScript commit authority three-dimensional: every `PhysicPaintRotoAuthorityRequest`/Result carries `trackId` plus the deterministic `trackRevision` and `documentRevision`, `getPhysicPaintRotoAuthority` revalidates parent → document → track in order with fail-closed per-track capacity, and the commit gate in `applyPhysicPaintPayload` checks the captured trackId/trackRevision/documentRevision — never the live `activeTrackId` — so a mid-flight track switch or a foreign-track edit can never be written to the wrong track.

Purpose: TRK-05 (async 3-dimension revalidation) and TRK-06 (track-isolation + stale-async law) are impossible while the authority request carries only `layerId` + `rotoRevision`. The 46-01 per-track maps and per-track revision signals are the data the authority now fingerprints; this plan adds the track dimension to the authority envelope, the strict validator, and the commit gate without a second authority manager.
</objective>
