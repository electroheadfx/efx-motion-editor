<objective>
Relax the Phase 45 single-track projection guards so the v1.0 document's track-shaped persistence actually round-trips multi-track runtime state: `serializeRuntimeIntoDocument`/`hydrateRuntimeFromDocument` iterate tracks by id and project per-track payloads, `buildEfxPaintFrameCachePath` embeds `trackId`, and the save/load frame carrier becomes per-track (`trackId → appFrame → frame`) so two tracks can own frames at the same appFrame.

Purpose: TRK-01/TRK-03 require the persisted boundary to address tracks, not the default track. The Phase 45 serializer throws on any second track — the hard blocker RESEARCH identifies (`efxPaintStore.ts:82,118`). This plan relaxes it in the same wave as the 46-01 store re-key, so a half-track-scoped runtime never lands against a single-track serializer.

Output: multi-track projection proven by a new round-trip test file; save/reopen identity across tracks; cache paths with trackId.
</objective>
