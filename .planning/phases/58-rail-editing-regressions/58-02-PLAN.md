## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| dialog repeat input -> loop clip record | User-entered Cycle / Infinity becomes persisted loop state |
| stale Key Rail selection -> controller confirm | The rail snapshot can age while the modal is open; keys can move, disappear, or become loop-owned |
| controller -> parent publication commit | One authoritative transaction; a second commit would create a phantom undo step |
