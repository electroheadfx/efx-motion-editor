<decisions>
## Implementation Decisions

### Group Layout & Membership (strip header)
- **D-01:** Header composition, left to right: mode label | **navigation pill** [first/prev/play-stop/frame#/next/last] | **elastic status capsule** (flex-1 middle) | **interpolation pill** [lucide `blend` icon toggle + mode select — NO count input; count authority is retired by the physical contract] | **playback pill** [loop + fps] | **apply-spacing pill** [lucide `align-horizontal-space-around` icon + N input + Apply].
- **D-02:** "key space group" and "apply key spacing group" are the SAME group (user terminology); four control groups total.
- **D-03:** Only the top control groups get the pill/island treatment; the mode label and the bottom key-action row keep their current structural appearance (bottom row stays a contextual pill near the cells).
- **D-04:** `SPECS/36.x-phases/timeline-ui/TimelineBottomWindow.tsx` is the reference for **color and design ONLY** — pill islands with ~10px gaps (no `|` glyphs), dark palette (#3E3F41 strip, #34383C/#2D3741/#323A43 pill backgrounds, #F5A623 primary orange), 155px total height, 46px header / 28px ruler / 38px cells / 28px action row / 14px scrollbar. Its structure is NOT authoritative (no +Key/Duplicate header buttons; its interpolation count input is retired).
- **D-05:** Interpolation toggle has NO border (user explicit, complement C-01) and uses the lucide `blend` icon instead of the INTERPOLATION text.

### EFX Motion Key Markers (C-04)
- **D-06:** One small diamond per real Roto key, drawn on the physic-paint layer row in the main EFX Motion canvas timeline (`TimelineRenderer.ts`) at the key's physical frame — reuses existing keyframe-diamond geometry (~9px, `drawKeyframeDiamonds`) but always visible on physic-paint layers, not selection-gated.
- **D-07:** Real keys only — generated in-betweens get no marker.
- **D-08:** Markers are visual-only — no click target, no new interaction surface.
- **D-09:** Diamond color: physics-paint orange #F5A623.

### Icon Row & Guarded States (C-05)
- **D-10:** Bottom action row is icon-only with these lucide icons/tooltips: Insert `between-vertical-start` "Insert key before"; Dup `copy-plus` "Duplicate key"; Copy `clipboard-copy` "Copy key"; Paste `clipboard-paste` "Paste key"; Delete `trash-2` "Delete key"; Copy Script `clipboard` "Copy Script"; Apply Script `clipboard-pen` "Apply Script".
- **D-11:** Discard Script (`clipboard-x`, "Discard Script") moves to the right-panel Scripts toolbar (36.14 UI-SPEC relocation); Copy/Apply Script stay in the bottom row.
- **D-12:** Guarded/unavailable actions stay visible, in order, focusable; the styled tooltip carries BOTH the action name and the controller-supplied reason, e.g. "Paste key — unavailable: no copied key". Existing controller availability/reason ports are the only source.
- **D-13:** The "Key {n}" label chip stays at the start of the icon row (reference's "Key 0" anchor).
- **D-14:** Styled custom tooltip component (dark pill matching the reference palette) replaces native title for the new controls; aria-labels remain for accessibility regardless.

### Status Capsule & Legend Aftermath
- **D-15:** Capsule content model: a single prioritized line — pending operation > saving indicator > guard/action feedback > ambient info (e.g. "Missing frames play transparent/background") — with the amber Info icon from the reference. Replaces the multi-line `physics-paint-roto-status-stack`.
- **D-16:** The bottom cell-states legend (`physics-paint-roto-cell-legend`) is removed entirely (C-06). Cell states stay discoverable via styled per-cell tooltips: "Real key", "Generated — render-only", "Cached", "Background only", "Empty".
- **D-17:** Styled tooltips appear after a **1-second hover delay**, never instantly — this is a global contract for the new tooltip component (icon row, cells, capsule).
- **D-18:** Capsule truncates with ellipsis at narrow widths and shows its full text in the styled tooltip; all other groups keep fixed width; below minimum host width the strip scrolls horizontally rather than crushing controls (matches 36.14 UI-SPEC responsive contract).
- **D-19:** Capsule = the single current status line; the right-panel LOG tab remains the running history/diagnostic surface, unchanged — the capsule just stops duplicating it.

### Claude's Discretion
- Exact gray tone steps, pill radii, and spacing values inside the reference palette family (planner/researcher extracts from TimelineBottomWindow.tsx and physicsPaintStudio.css).
- Tooltip component implementation shape (single shared component vs. CSS-driven), as long as D-14/D-17 hold.

</decisions>

## Existing Code Insights

### Reusable Assets
- `app/src/components/physic-paint/view/PhysicsPaintWorkflowStrip.tsx` (962 lines) — THE surface to recompose; already has navigation/playback/interpolation/force-spacing groups, cell row, key-utility row, legend. No competing timeline implementation.
- `app/src/components/physic-paint/physicsPaintStudio.css` — extend; contains `.physics-paint-roto-status-stack` (to retire) and `.physics-paint-roto-cell-legend` (to remove).
- `app/src/components/timeline/TimelineRenderer.ts` — `drawKeyframeDiamonds` (9px diamond geometry) and `drawPhysicPaintPlayScriptMarkers` (physic-paint layer drawing seam) are the reuse points for D-06 key markers.
- `lucide-preact` 0.577.0 — already the icon library; all 9 icons in D-10/D-11 plus `blend` and `align-horizontal-space-around` exist there.
- Controller availability/reason ports (`scriptAvailability`, `can*RotoKey` flags, `forceSpacingDisabledReason`) — already supply every guarded-state reason D-12 needs; view only re-surfaces them.

### Established Patterns
- Standalone strip controls are plain Preact buttons with `aria-label` + `title`; guard reasons currently route through props and the status stack.
- The main EFX Motion timeline is canvas-rendered — key markers are drawing code, not DOM.
- Physical contract: interpolation is enabled-only + mode select; there is NO count input anywhere in the new UI.

### Integration Points
- `PhysicsPaintStudio.tsx` — feeds strip props; capsule priority model consumes existing status/saving/guard signals.
- `PhysicsPaintScriptsPanel.tsx` (right panel) — receives the Discard Script icon action (D-11).
- `app/index.html` — application selection guard target (36.14 UI-SPEC §Application Selection Guard).
- Timeline layout code threading physic-paint layer data into `TimelineRenderer` — marker data (real key frames per physic-paint layer) flows through the existing FxTrackLayout path.
