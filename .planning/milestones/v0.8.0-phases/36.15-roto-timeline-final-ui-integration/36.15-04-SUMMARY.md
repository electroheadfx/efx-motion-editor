**D-01 header rebuilt as four gray pill islands in one non-wrapping 46px flex row — navigation / interpolation (borderless Blend toggle) / playback / apply-spacing (icon + text Apply) — with a flex-1 capsule slot for Plan 05 and a header Close button routed through the guarded close-flush path.**

## Accomplishments

- Header recomposed from a 42px 3-column grid into a single non-wrapping 46px flex row in locked D-01 order: mode label (pill-free, `flex: 0 0 auto`), navigation pill, `.physics-paint-header-capsule-slot` flex-1 spacer (Plan 05 fills with the status capsule), interpolation pill, playback pill, apply-spacing pill — playback and interpolation groups swapped versus prior production.
- New `.physics-paint-pill` base (rounded-full, 32px outer height, `flex: 0 0 auto`, 8px container gap on the header) plus tonal variants: navigation `#34383C`/`#575E66`, interpolation `#323A43`/`#596775`, playback `#34383C`/`#59616A`, apply-spacing reusing the navigation variant. The old playback `border-left` divider is gone; no divider glyphs anywhere (D-04/C-03).
- Interpolation pill: bordered text toggle replaced by a borderless lucide `Blend` icon toggle (size 15, `#b8c7ff` glyph, `aria-pressed` bound to enabled state, `aria-busy` + the mutation-lock guard kept verbatim); active state conveyed by `rgba(184,199,255,0.2)` surface + `#dbe4ff` glyph emphasis only. Every trace of the old bordered/green treatment deleted (wrapper borders, `#2f7258` fill, `#79ddb0` border, toggle-state spans). Mode select kept beside the toggle; no count input anywhere.
- Apply-spacing pill: `AlignHorizontalSpaceAround` (size 15) rendered before the existing N input (`min="0" step="1"`, accessible name unchanged), Check-icon submit replaced by a text `Apply` button, and `handleForceSpacingSubmit`'s guard line preserved verbatim — canonical parsing stays controller-owned (T-36.15-07).
- Header Close: `onClose?: () => void` prop; X icon button with the Plan 01 neutral icon-button treatment + styled tooltip (`Close`) inside `.physics-paint-state-actions` (placeholder `aria-hidden` removed). Studio handler calls `getCurrentWindow().close()` via dynamic Tauri import with a `window.close()` browser-bridge fallback, so the existing `onCloseRequested` flush always runs (T-36.15-06). Strip view stays Tauri-free (source-contract locked).

## Decisions Made

- **Apply-spacing reuses the navigation tonal variant** (`#34383C` / `#575E66`) — the plan explicitly permits this; keeps the four-group palette at three distinct tones matching the reference.
- **Active blend toggle emphasis is surface + glyph only**: `rgba(184,199,255,0.2)` background with `#dbe4ff` glyph over the always-`#b8c7ff` base glyph; never an added border (D-05/C-01).
- **The capsule slot is a plain unstyled flex-1 spacer** (`.physics-paint-header-capsule-slot`, `aria-hidden`) — Plan 05 replaces it with the status capsule; this plan's assertions deliberately avoid any capsule-adjacency lock (key_links).
- **Close handler mirrors the established bridge dynamic-import pattern** rather than a static Tauri import, keeping browser-bridge fallback behavior identical to the other Studio bridge seams.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Mode-label slice boundary included the pill base class**
- **Found during:** Task 1 (GREEN verification)
- **Issue:** Test 1 sliced the mode-label block up to `physics-paint-pill--navigation`, but the navigation div's class attribute starts with the base `physics-paint-pill` class before the variant, so the slice still contained the base class string and the pill-free assertion failed.
- **Fix:** Slice up to the navigation pill's opening `<div` (`header.lastIndexOf('<div', navigationIndex)`) instead of the variant index.
- **Files modified:** app/src/components/physic-paint/view/PhysicsPaintWorkflowStrip.test.ts
- **Committed in:** `2a18a0cc` (part of Task 1 GREEN commit)

**2. [Rule 1 - Bug] aria-hidden negative assertion caught the X icon's legitimate attribute**
- **Found during:** Task 2 (verification)
- **Issue:** The state-actions block assertion `not.toContain('aria-hidden="true"')` matched the lucide `<X size={15} aria-hidden="true" />` icon, which correctly hides a decorative glyph inside a labeled button.
- **Fix:** Scoped the negative assertion to the state-actions wrapper's opening tag only; the block-level `aria-label="Close"` positive assertion is unchanged.
- **Files modified:** app/src/components/physic-paint/view/PhysicsPaintWorkflowStrip.test.ts
- **Committed in:** `865b3106` (part of Task 2 commit)
