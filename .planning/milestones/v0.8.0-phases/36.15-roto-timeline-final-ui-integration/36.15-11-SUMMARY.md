## Accomplishments

- **Task 1 — Sidebar tab restructure + strip/sidebar polish (Gap G):**
  - **G-1 (full sidebar labels):** the Scripts toolbar grid moved from `repeat(6, minmax(0, 1fr))` fixed-fraction cells (which ellipsized the labeled second-row buttons down to 'C…' / 'A…' / 'Cl…') to `repeat(6, auto)` content-sized cells with `justify-content: start`; the second-row label rule now keeps `white-space: nowrap` with no ellipsis, and the `width: 100%` cell-fill rules are gone. Button padding grew to `0 6px` with a 4px icon-label gap.
  - **G-2 (bare tools group):** `.physics-paint-roto-key-utilities` renders transparent — border, background, and padding removed; the identity group keeps its own pill so the row still reads as separated groups.
  - **G-3 (vertical centering):** the off-center row traced to the retired pill's 1px padding + 1px borders around 26px buttons (30px inside the 28px band). The bare group is exactly `height: 26px`, centered by the row's existing `align-items: center`; the 28px band and 155px strip geometry are untouched.
  - **G-4 (Scripts first + default-open):** the lower tab group is now [Scripts, Onion, Motion] with `useState<...>('scripts')`; a mount effect runs the same `scripts.library.enterScripts()` scan the tab click performs so the default-visible list is live.
  - **G-5 (row separation):** `row-gap: 8px` on `.physics-paint-scripts-toolbar` separates the two icon rows.
  - **G-6 (three tab groups):** the upper pane splits into two independent single-tab groups — [Brush color] and [Tool] — and the lower pane holds [Scripts, Onion, Motion]. The LOG tab (and its log messages, dev-export button, and primaryTab state machinery) is removed as obsolete; the Tool tab's 'Save state' / 'Load state' buttons and the `getPhysicsPaintSessionControlState` view helper are removed with them.
  - **Selection-guard sync (Plan 03 contract):** `.physics-paint-log-messages` was removed from the `user-select: text` exception list in `app/index.html` and from `applicationSelectionGuard.test.ts` (now three exception selectors) in the same commit, since its only target no longer exists.

## Decisions Made

- **Truncation was a layout contract, not text.** Content-sized grid cells (`repeat(6, auto)`) let the labeled buttons take the width their icon + full short label need; no source label changed.
- **Off-centering was a height overflow.** The tools-group pill was 30px tall inside the 28px band; the transparent 26px group centers under the row's existing `align-items: center` — no new alignment machinery.
- **Store logic preserved.** The session save/load persistence API (`usePhysicsPaintSessionController.saveEditableState` / `loadEditableState`) and the dev-export proof path are now unreferenced by the view but deliberately not deleted, per the plan's key_links; the props remain on the panel interface so `PhysicsPaintStudio.tsx` needed no change.
- **Single-tab groups keep tab chrome.** [Brush color] and [Tool] render as a tablist with one always-active tab each, preserving the approved mixed-case tab visual language without a new header component.
