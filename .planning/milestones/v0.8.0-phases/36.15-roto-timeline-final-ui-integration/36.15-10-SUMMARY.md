## Accomplishments

- **Task 1 — Gap F grouping and casing polish:**
  - **F-2/F-4 (three separated groups):** the bottom action row was one fused `.physics-paint-roto-key-utilities` pill containing the identity chip, all six tools, and the spacing form. It is now three sibling groups under the 28px band — `.physics-paint-roto-key-identity` (Layer name + Key {n}, its own tonal pill), `.physics-paint-roto-key-utilities` (the six tools), and the Key spacing form — separated by `gap: 8px`, the same pill-island spacing language as the top bar (Plan 04).
  - **F-3/F-5/F-1 casing (lowercase labels):** the source text was already lowercase — the CAPS rendering came from the global studio-chrome rule `button { text-transform: uppercase }`, inherited by every label inside the icon buttons and by the Apply submit. `.physics-paint-roto-key-icon-button`, `.physics-paint-script-icon-button`, and `.physics-paint-roto-force-spacing-apply` now carry `text-transform: none`.
  - **F-1 (sidebar icon size):** both toolbar rows already used `size={16}` Lucide icons; the labeled second-row buttons overflow their `repeat(6, 1fr)` grid cells, so the svg flex item shrank below 16px ("ridiculous small"). `.physics-paint-scripts-toolbar .physics-paint-script-icon-button svg` now has `flex: 0 0 auto`; the label absorbs the shortage with an ellipsis.
  - **Geometry intact:** the 28px action-row band, 155px strip, 18px cell pitch, and drag machinery are untouched — all Plan 06 guardrail tests stay green.

## Decisions Made

- **The CAPS labels were inheritance, not source.** Every Gap F casing item traced to the single global `button { text-transform: uppercase }` rule; the fix is a targeted opt-out per affected button class rather than touching the global rule (other studio chrome relies on it).
- **The small icons were flex shrink, not icon size.** Pinning the svg with `flex: 0 0 auto` restores true 16px parity with the first row; the label ellipsizes in narrow sidebars instead of crushing the icon.
- **Separation copies the top bar verbatim.** `gap: 8px` plus a tonal identity pill (same border/background tokens as the tools group) makes the bottom row read as three pill islands exactly like the header.
