## Decisions Made

- **Native select for the interpolation dropdown.** An OS-rendered select popup is structurally immune to the strip's `overflow-y: hidden` clipping and canvas masking (Gap B); only the option labels changed to 'Frame duplicate' / 'Frame blend'.
- **Header tooltips flip below the anchor.** The strip shell must keep `overflow-y: hidden` for the D-18 horizontal scroll, so tooltips above header controls were clipped at the strip's top edge (the user's 'masked by the canvas' report). `placement="below"` keeps them inside the 155px band stack; bottom-row tooltips keep the original above placement.
- **The Set Key Space form joined the guarded row contract.** Native `disabled`/`title` were dropped for aria-disabled + guarded onInput on a controlled input (guarded input simply snaps back) plus the verbatim submit guard, preserving the 'zero native disabled in the row' D-12 invariant with the form now living in that row.
- **No new controller state.** The Scripts panel already owns the `rotoScript` controller; Copy/Apply availability reads `canCopy`/`copyDisabledReason`/`canApply`/`applyDisabledReason` directly, and the Studio handlers moved verbatim (Rule: presentation-only re-composition, no business-logic changes).
- **De-prefix grammar lives in one shared builder.** `buildGuardedActionTooltipCopy` is the single seam for the strip; the three Scripts-toolbar guarded actions use the same grammar inline (their tooltips were new/renamed in this plan anyway).
