## Decisions Made

- **Ambient fallback is the static baseline, not the per-frame missing-frame label.** Must-have truth 1 locks "baseline when nothing higher-priority exists"; the retired `rotoMissingStatusLabel ?? currentRotoCell.label` line was therefore dropped with the stack rather than routed as ambient content (the removal map classified it as a *candidate*). Per-frame missing/background detail remains discoverable via per-cell tooltips. The selector still accepts an `ambient` input for future callers, and the `rotoMissingFrameStatusKind` prop stays in the strip interface so Studio wiring is untouched.
- **Feedback recency is static wiring metadata** (playback 2 > script 1 > generated guard 0): the strip has no per-line timestamps, and the pure selector owns the arbitration grammar itself.
- **The interpolation pill adopts the styled tooltip** per Pitfall 4's explicit adoption list (icon row, cells, capsule, interpolation pill) and the removal map's disposition for `interpolationStatus`.
- **Cell tooltips show the five-state semantic copy only**; drag feedback copy lives on the capsule's aria-live line and in cell aria-labels (unchanged), never duplicated into the tooltip.
