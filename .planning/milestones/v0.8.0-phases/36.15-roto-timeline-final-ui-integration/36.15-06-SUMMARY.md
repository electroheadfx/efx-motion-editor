## Decisions Made

- **+ Key reuses paste-to-empty instead of a new operation kind.** The script-target promotion path (`prepareRotoScriptTargetRef`) already creates real keys on empty frames via `pasteKey(appFrame, blankPayload, null)`; duplicating that proven machinery keeps the resolver, coordinator, settlement, rollback, and snapshot-based history untouched. The action carries its own success copy and availability ports so the UI never presents it as a paste.
- **The Tools dropdown keeps the pill groups byte-identical.** All Plan 04 guards, aria wiring, and tooltip behavior survive unchanged inside the dropdown; only the container and a compacting descendant height rule are new.
- **The scrollbar band is permanent.** The 14px band is a fixed member of the 155px sum, so the band renders unconditionally and only the thumb is visibility-gated.
- **The 1px divider is the timeline wrapper's border-top.** Under the global border-box this keeps the 46px header band exact while the divider contributes its own 1px to the 46+1+28+38+28+14 sum.
- **Topbar responsiveness is growth + wrap, not a density breakpoint.** `minmax(58px, auto)` lets the top row grow when controls wrap; fixed side-column reserves (170px/120px) are gone at every width.
