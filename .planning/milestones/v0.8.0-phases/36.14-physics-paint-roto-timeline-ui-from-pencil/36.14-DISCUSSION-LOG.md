## Responsive Header

### Minimum-width composition

| Option | Description | Selected |
|--------|-------------|----------|
| One compact row | Keep every group visible; let the central status capsule shrink and truncate first while controls retain compact fixed sizes. | ✓ |
| Wrap to two rows | Move lower-priority groups onto a second header row; easier to fit, but increases timeline height and departs from the reference. | |
| Horizontal header scroll | Keep exact group widths and allow the header itself to scroll; preserves proportions but separates controls from the visible timeline region. | |

**User's choice:** One compact row.

### Wide-window space

| Option | Description | Selected |
|--------|-------------|----------|
| Expand status only | Keep control groups tightly related; the status capsule absorbs remaining width. | ✓ |
| Spread all groups | Distribute groups across the header for an airier layout. | |
| Center timeline controls | Center the control cluster and leave balanced whitespace. | |

**User's choice:** Expand status only.

### Vertical footprint

| Option | Description | Selected |
|--------|-------------|----------|
| Fixed compact height | Keep all five visual bands in the corrected reference-like footprint; truncate long status text. | ✓ |
| Small adaptive range | Allow slight growth for platform/font differences. | |
| Content-driven height | Let rows grow when content needs space. | |

**User's choice:** Fixed compact height.

### Cell density

| Option | Description | Selected |
|--------|-------------|----------|
| Fixed cells + timeline scroll | Preserve corrected cell/ruler proportions and use the synchronized horizontal scrollbar. | ✓ |
| Scale cells to viewport | Stretch or shrink cells continuously with the viewport. | |
| Density breakpoints | Use a few discrete cell widths by window size. | |

**User's choice:** Fixed cells + timeline scroll.

## Force Spacing Control

### Placement and trigger

| Option | Description | Selected |
|--------|-------------|----------|
| Input + Apply button | Show a compact nonnegative `N` field and explicit action inside the interpolation group. | ✓ |
| Input + Enter only | Apply only on Enter; smaller but less discoverable. | |
| Separate header group | Give Force Spacing its own pill beside interpolation. | |

**User's choice:** Input + Apply button.

### Action label

| Option | Description | Selected |
|--------|-------------|----------|
| Apply | Matches the one-shot transaction model without implying live synchronization. | ✓ |
| Space | Short and specific but less explicit about whole-timeline impact. | |
| Force | Matches the roadmap term but sounds more technical/destructive. | |

**User's choice:** Apply.

### Input retention

| Option | Description | Selected |
|--------|-------------|----------|
| Keep last session value | Retain the last entered value while the window is open without persisting it as project truth. | ✓ |
| Reset to zero | Clear the field after every application. | |
| Reflect current spacing | Recalculate from the current timeline when uniform. | |

**User's choice:** Keep last session value.

### Confirmation

| Option | Description | Selected |
|--------|-------------|----------|
| Immediate + Undo | Validate and apply directly as one acknowledged Undo/Redo action. | ✓ |
| Confirm every time | Show a dialog before each application. | |
| Confirm large moves only | Prompt only above a key-count or shift threshold. | |

**User's choice:** Immediate + Undo.

## Ripple Drag Feedback

### Occupied-key boundaries

| Option | Description | Selected |
|--------|-------------|----------|

| Split cell halves | Use the left/right half of the 18px cell as separate targets. | |

**User's choice:** Edge insertion caret.

### Preview depth

| Option | Description | Selected |
|--------|-------------|----------|

| Moved key + caret | Show only the dragged key ghost and insertion marker. | |
| Caret + status text | Keep cells static and describe the result in the status capsule. | |

**User's choice:** Full mapped preview.

### Empty/generated targets

| Option | Description | Selected |
|--------|-------------|----------|

| Use the same caret | Use insertion carets for all target types. | |

**User's choice:** Whole-cell target highlight.

### Post-commit focus

| Option | Description | Selected |
|--------|-------------|----------|

## Status and Script Routing

### Success-message lifetime

| Option | Description | Selected |
|--------|-------------|----------|
| Until next relevant event | Keep the latest success until operation/navigation/playback state replaces it, then use the baseline when idle. | ✓ |
| Brief timed message | Return to baseline automatically after a few seconds. | |
| Until manual clear | Persist until explicit dismissal. | |

**User's choice:** Until next relevant event.

### Failure summary

| Option | Description | Selected |
|--------|-------------|----------|
| Concise failure + see LOG | Show a short actionable summary in the capsule and full diagnostics in LOG. | ✓ |
| Baseline only | Route all failure information to LOG. | |
| Full error in capsule | Duplicate complete error text in the header and LOG. | |

**User's choice:** Concise failure + see LOG.

### Discard Script placement

| Option | Description | Selected |
|--------|-------------|----------|
| Move to Scripts panel | Preserve manual volatile-clipboard disposal in the right-panel Scripts toolbar while the timeline ends at Apply Script. | ✓ |
| Keep timeline icon | Retain a small icon beside Apply Script. | |
| Remove manual discard | Rely on Copy replacement and window disposal only. | |

**User's choice:** Move to Scripts panel.

### Disabled script reasons

| Option | Description | Selected |
|--------|-------------|----------|
| Focusable disabled explanation | Use guarded `aria-disabled` controls with tooltip/accessibility text from controller-supplied reasons; attempted activation may update the capsule. | ✓ |
| Native disabled + title | Keep native disabled controls with hover title only. | |
| Always show reason | Continuously occupy the header capsule with the current disabled reason. | |

**User's choice:** Focusable disabled explanation.
