## Decisions Made

- **One exported seam, private helpers:** `resolvePhysicPaintRotoPhysicalEdit` is the only exported function; all sorting, cut/close/open mechanics, exact-interior generation, physical-cell generation, validation, and freezing are private implementation details so callers and later regression coverage exercise one interface.
- **Complete mapping is the authority:** the `mapping: ReadonlyMap<string, number>` field is the authoritative result; `changes`, `drag`, `selectedKeyId`, `cells`, `generatedCells`, and `status` are all derived presentation metadata computed from the validated candidate immediately before the proposal is frozen.
- **Common finalizer for every intent:** Insert, Delete, Move, and Force Spacing all route through `finalizeProposal`, which proves exact identity-set coverage, unique in-range final frames, and deterministic ascending order before constructing success. No operation-specific bypass is permitted.
- **Cut-first Drag:** the moved identity is removed and its source slot is closed before the target is resolved. Occupied before/after boundaries are resolved by stable identity against the post-cut map, never by a stale frame. Direct cells occupied in the original input by another real key are rejected because occupied keys require an identity boundary.
- **Net-change `changed` flag:** Drag and Force Spacing compute `changed` by comparing the final mapping to the input frames, so moving to the moved key's own current physical cell and Force Spacing an already-exact sequence both yield valid immutable no-change proposals with `changed: false` and no fabricated shifted metadata.
- **Delete selection rule:** the original successor (smallest `appFrame` strictly greater than the removed slot) is selected when present, otherwise the previous survivor (largest `appFrame` strictly less than the removed slot), otherwise null. The deleted identity never appears in the complete map, ordered output, cells, changes, or selection.
- **Force Spacing anchor:** the first ordered real key's physical frame is preserved as the anchor; the deterministic identity order is preserved; identity at index `i` maps to `first + i * (N + 1)`. `N = 0` produces adjacent ordered keys. Over-capacity outcomes fail at the common finalizer with no partial proposal.
- **Stable failure codes:** `PhysicPaintRotoPhysicalEditFailureCode` covers invalid capacity, malformed identity, duplicate ID/frame, out-of-range frame, empty key set, unknown operation/target identity, malformed target, invalid spacing, incomplete mapping, duplicate destination frame, over-capacity, and moved-as-target. Every failure carries a stable code, the operation kind when known, and concise text — never a partial proposal.
