This UI integration adds no dependency, credential, network service, persistence format, or package-manager install. The relevant boundaries are semantic UI intent into existing controllers, controller state into presentation, detailed diagnostics into LOG, and volatile Script lifecycle state into the right-panel toolbar.

| Boundary | Description |
|----------|-------------|
| workflow controls -> physical controllers | Untrusted pointer, keyboard, checkbox, numeric-input, and button events request acknowledged timeline operations. |
| physical/status controllers -> workflow presentation | Supplied semantic cell, pending, availability, and concise operation metadata determine visible UI state. |
