## Decisions Made

- **Strict allowlisted payload subset:** `PhysicPaintRotoRealKeyPayload` is composed from a strict subset of `PhysicPaintRenderedFrame` (`frameIndex`, `appFrame`, `dataUrl`, `width`, `height`) and excludes `source` and `nearestRealKeyFrame`. This keeps generated descriptors from satisfying real-key records and prevents old timing metadata from surviving inside durable payloads.
- **Structural discriminator separation:** Real-key records use `kind: 'real-key'` and generated cells use `kind: 'generated-interpolation'`; neither satisfies the other's interface, so a generated descriptor cannot be admitted as a durable real-key record.
- **Bounded keyId:** IDs are bounded to 256 characters and must be non-empty, matching the existing `isBoundedOperationId` convention; native UUID output is 36 characters.
- **Reconstructing parser return types:** `parsePhysicPaintRotoRealKeyRecordCollection` returns `readonly PhysicPaintRotoRealKeyRecord[]` (not mutable) to reflect the deep-frozen immutable contract.
- **Conditional spread for optional payload fields:** `cloneAndFreezeRealKeyPayload` uses conditional spread for optional `width`/`height` so the frozen clone omits undefined keys rather than materializing them as explicit `undefined` own properties.
