## Decisions Made
- **Option A over Option B** (recorded per the plan's mechanism-choice requirement): the 55-assertion source-grep contract pins the cell-loop derivation literals (`const isGenerated = semanticCell?.kind === 'generated'`, `const isPhysicalRealKey = semanticCell?.kind === 'real'`, `const dragEligible = isPhysicalRealKey && !rotoDragLocked;`, `getRotoCellStateTooltipCopy(`, `RotoTimelineCellButton`) INSIDE the `frameCells.map` slice. Option B (derivation moved into a memoized child) would relocate those literals out of the asserted block and fail the suite. Option A keeps every literal in place and changes only WHEN the expensive helpers run.
- The cache bundle is `{ vm, fill }` only — drag preview (`rotoDragPreviewViewModel`, `rotoDragVacatedAppFrames`), multi-selection (`rotoSelectedKeyIdSet`), and saved markers (`props.savedRotoFrames`) are read per-render in the cell loop and were never cache inputs, so the cache cannot serve stale drag/selection state.
- `frameCells` stays in the validity-key dep array (it is genuinely interpolated via `frameCells[0]`/`frameCells[last]`); the memo's win is eliminating the O(N) rebuild on non-frame renders (drag preview ticks per pointermove, scrollbar updates, capsule status changes).
