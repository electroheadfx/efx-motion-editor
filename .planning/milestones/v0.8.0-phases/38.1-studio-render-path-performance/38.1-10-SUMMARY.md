- Drag preview, selection, saved-marker, and semantic changes continue to invalidate only cells whose rendered props actually change.

## Decisions Made

- Kept observer installation separate from geometry refresh instead of reconnecting the observer when `frameCells` changes.
- Used local Signals for current-frame and capsule text because they preserve narrow Preact subscriptions beneath memoized static chrome without copying state through effects.
- Kept tooltip hooks inside the plain cell implementation and memoized only its component boundary, preserving local hover/focus/Escape behavior.
- Passed the cached `RotoCellViewModel` itself to the child rather than rebuilding a descriptor object, allowing default shallow memo comparison to recognize unchanged cells.
- Preserved all existing derivation-cache invalidation rules; no broader cache invalidation or custom memo comparator was added.
