# Requirements: EFX-Motion Editor

**Defined:** 2026-10-12
**Core Value:** Users can import key photographs, arrange them into timed sequences with FX layers, preview in real-time, and export as PNG image sequences — the complete stop-motion-to-cinema pipeline must work end-to-end.

## v1 Requirements

Requirements for this milestone. Each maps to roadmap phases.

### SAVE — Display-class Save Token (PKG-06/BKG-09)

- [x] **SAVE-01**: Display-only background edits (transform/lock) persist across save → close → reopen
- [x] **SAVE-02**: Display-only photo-reference edits (visible/opacity/transform/lock) persist across save → close → reopen
- [x] **SAVE-03**: Regression test saves twice (the first save masks the missing token) and fails against the pre-fix token builder

### VID — Video Import Disk-Reference Law

- [x] **VID-01**: Imported video is referenced by absolute `source_path`, never copied into the package
- [x] **VID-02**: `.mce` manifest records video assets (`video_assets` on `MceProject`) and reopens from the source path
- [x] **VID-03**: `videos/` package provisioning retired — no video directory is written
- [x] **VID-04**: Exported frames never bake the video loading placeholder; video layers await loadeddata and seeked, or the export stops naming the clip

### SND — Document-sound Decode Readiness (SND-07)

- [x] **SND-01**: Playback never silently skips a clip whose buffer failed to decode — awaits the decode or refuses with a visible error
- [x] **SND-02**: Export mix never silently drops a clip — an undecodable clip surfaces a diagnostic instead of a bare `continue`

### EXP — Export Mux Duration Law

- [x] **EXP-01**: The exported container's audio and video streams have the same duration (the shorter one)

### MBL — Motion-blur Prefs Persistence (field-drop-hole closure)

- [x] **MBL-01**: Motion-blur prefs (`enabled`, `shutter_angle`, `preview_quality`, `export_sub_frames`) persist across save → close → reopen

### REL — Release

- [x] **REL-01**: v1.0.1 version single-source across all five surfaces
- [x] **REL-02**: Signed/notarized DMG published as GitHub Latest via `efx-motion-release`
