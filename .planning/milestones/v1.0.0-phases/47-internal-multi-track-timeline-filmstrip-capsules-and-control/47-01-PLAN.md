<objective>
Prove the multi-track timeline architecture end-to-end and close the Phase 47 store-op gap. The tracer slice wires the thinnest vertical path through every layer this phase modifies: a store mutation that adds a Paint track, the generalized multi-row strip that renders every `document.tracks` entry as its own row, a row click that selects the active track through the existing routing authority, and the hide/solo truth-table filter that reflects track visibility in the Studio preview. The remaining two tasks build the complete track CRUD and hide/solo/opacity/blend store-op surface that every later plan (header column, right panel, capsule, cross-track drag) binds to.

Purpose: TML-01 (multi-row timeline) and TML-05 (per-row rendering with active-track routing) are impossible while the strip renders a single lane and while `efxPaintStore.ts` exports no track mutation ops (RESEARCH Pitfall 2 — the store-op gap). This plan makes the runtime document the row source of truth and gives the UI a fail-closed mutation surface, all writing through the Phase 45/46 serialize/hydrate path (TML-08).

Output: `efxPaintStore.ts` with `addTrack`/`renameTrack`/`duplicateTrack`/`reorderTrack`/`setTrackVisible`/`setTrackSolo`/`setTrackOpacity`/`setTrackBlend`; `PhysicsPaintTrackRow.tsx` (new 48px row); `PhysicsPaintWorkflowStrip.tsx` generalized to a row-based model; the hide/solo truth-table filter in `resolvePhysicPaintFrameSource`; the existing test suites extended with the new cases.
</objective>
