<objective>
Ship the macOS document-package treatment locked by D-03: the project folder becomes `Name.mce/` presented as a single Finder document, double-click opens it, and the open/save dialogs target packages — while Windows/Linux keep an ordinary folder.

Purpose: the package format is only usable by a human if the OS treats it as a document. This is the phase's most bundle-fragile work (LaunchServices caching, shallow Info.plist merge, `tauri dev` blindness), so the plan puts everything machine-checkable behind a contract test and leaves only the genuinely native behavior to UAT.

Output: a hand-authored `Info.plist`, bundle config aligned with it, `RunEvent::Opened` handling with cold-start buffering, the frontend handshake, and dialog targeting.
</objective>
