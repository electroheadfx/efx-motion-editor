# Phase 52.2 Plan 08: The clean break Summary

**Pre-52.2 projects are refused by a pure `formatVersion` gate positioned so nothing mutates first, the legacy carrier is deleted from the Rust model, the TS mirror and the contract allowlist, and a dev-only converter outside `app/src` turns the one old project into a payload-free package**

## Accomplishments

- **The format now has exactly one version.** `findPackageFormatRejection(manifest, { pathKind })` returns one of four terminal reasons in fixed precedence — unreadable/absent manifest, plain-file layout, missing version, mismatched version (naming `found` and `required`) — never throws, never mutates its input, and maps every reason onto the same blocking no-recourse dialog.
- **The gate sits where the mitigation lives.** `openProject` calls it after the read and before any sidecar IO or store mutation; the refusal suite now snapshots the whole open-state (name, fps, dimensions, file paths, dirty flag, script-library authority, project context id, sequences) and asserts deep equality — including the case where a project is already open.
- **The opaque carrier is gone from shipped code.** `MceProject` (Rust) and `MceProject` (TS) no longer declare it, no shipped path reads or writes it, and the contract test lost the `CARRIER_ALLOWLIST` that existed only to permit it.
- **Plan 07's manifest survives a save.** The Rust model now declares `formatVersion`, `projectId` and `efxPaint`; without them serde's declared-field projection would have erased all three on the first save and the app could not have reopened its own package. The round-trip test asserts each one comes back.
- **The one old project has a way across.** `scripts/mce-package-rescue.ts` decodes both roto collections' inline rasters into `frames/<layerId>/<keyId>.webp`, rewrites the layer documents with `media` references plus SHA-256 digests, and emits `project.mce` through the shared `buildPackageManifest`. All-or-nothing: every key resolves in memory first, and one undecodable payload aborts the run with nothing written.
- **The formerly-red contract test is green** — `efxPaintCleanBreakContract.test.ts` (3 tests) passes for the first time since plan 01 introduced the frame-transport token list.

## Decisions Made

- **Four terminal reasons, one dialog.** `not-a-package-manifest`, `old-project-layout`, `missing-format-version`, `unsupported-format-version { found, required }` — the user never gets a choice that cannot work, so all four render the identical no-recourse copy.
- **`pathKind: 'directory'` at the app's open flow.** The open flow only ever resolves a directory; passing `'file'` would have refused every project and gutted the hydration suite. The `'file'` branch is unit-tested as the plain-file refusal.
- **Rust declares the package keys.** Serde drops undeclared keys, so `formatVersion`/`projectId`/`efxPaint` had to become first-class `MceProject` fields in the same task the carrier left — a TS-only manifest field is erased by the first Rust save.
- **`efx_paint_documents` stays for now.** The gate refuses every manifest without `formatVersion` before the read, so pre-52.2 data is unreachable; the read itself is deleted by plan 09 Task 2, which must first give `layers/<layerId>.json` a reader.
- **`ipc.ts` joins the frame-transport allowlist** instead of losing `base64ToBytes` — that helper decodes the native per-key media read that plan 09's pixel resolver depends on.
- **The converter's revisions are empty.** The canonical `documentRevision`/`compositeRevision` come from the app's parser graph, unloadable from a two-import standalone; `''` is the codebase's existing "recompute this" sentinel, chosen over a fabricated digest.
- **The converter drops derived-frame cache references.** They are machine-local (D-14), their `cache/efx-paint/…` shape is exactly what the package cache guard refuses, and the app re-derives those frames from the authoritative keys.
