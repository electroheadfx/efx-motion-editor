# Phase 52.2 — Security

> Per-phase security contract: threat register, accepted risks, and audit trail.

Register authored at plan time: all 16 plans carried a parseable `<threat_model>` block. Plan-local ID collisions are disambiguated with a `(pNN)` suffix: `T-52.2-08` exists in plans 02 and 03, `T-52.2-18` in plans 05 and 06, `T-52.2-SC` in plans 13, 14 and 15.

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| TS/renderer → Rust command | `relativePath`/`layerId`/`keyId` strings supplied by application code cross into filesystem access | path strings, identifiers |
| Filesystem → Rust read | A file at the target path could be a symlink or a non-regular file placed by anything on the machine | raw bytes |
| Rust → TS | Raw bytes cross back over IPC | frame media bytes |
| On-disk JSON → parser | Layer sub-files, manifest and transaction marker read from disk are untrusted input | document JSON, marker JSON, digests |
| Runtime state → persisted JSON | A path produced at runtime could be machine-local and must not reach the package | cache/media references |
| Package root vs machine cache root | Two different filesystem roots that must not be confused | derived-frame cache refs |
| Studio window ↔ main window | Two webview contexts exchange document payloads | digest-keyed WebP bytes, references |
| macOS LaunchServices → app | An arbitrary path can arrive through the open-event channel | file URL |
| npm registry → app | Two new runtime dependencies, one an alpha | supply chain |
| User input → numeric field | Typed/pasted text crosses into numeric state and reaches the document | numbers |
| UAT session → phase acceptance | The only evidence that the shipped bundle works for a human | verdict, skill family |
