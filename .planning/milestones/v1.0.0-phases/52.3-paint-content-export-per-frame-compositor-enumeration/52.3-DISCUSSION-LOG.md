## Paint FrameEntry ownership

| Option | Description | Selected |
|--------|-------------|----------|
| Explicit paint-kind entries | Discriminated variant (kind:'paint' + owning fx sequenceId + paint layer identity, no keyPhotoId/imageId). Fail-closed by type; keeps parked Case C contract as-is. Cost: type churn across frameMap consumers. | ✓ |
| Synthetic fx-id entries | sequenceId = fx sequence id, sentinel keyPhotoId/imageId. Minimal type churn; imageId-resolving consumers must tolerate sentinels; semantics implicit. | |
| No paint entries — count-driven export | frameMap stays content-only; exportEngine iterates getTimelineRequiredFrameCount. Smallest runtime diff but contradicts the parked Case C contract and splits preview/export enumeration semantics. | |

**User's choice:** Explicit paint-kind entries
**Notes:** Flagged up front that the parked Case C contract presumes enumeration happens in frameMap — the chosen option honors it.

## N derivation + clamp owner

| Option | Description | Selected |
|--------|-------------|----------|
| Union/max — existing law | N = max(fx authored span, seqStart + loop-aware paint extent) per getTimelineRequiredFrameCount. WYSIWYG with the timeline; paint never clipped; longer span yields trailing fond-blank frames. | ✓ |
| Fx authored span clips | Span is the export range authority; keys beyond outFrame don't export. Contradicts the timeline's auto-extending display and 260918-o0n's de-clamp. | |
| Paint extent only | N = loop-aware paint extent; authored span ignored for paint-only projects. No trailing blanks, but the span loses export influence. | |

**User's choice:** Union/max — existing law
**Notes:** Recorded implication: enumeration spans [0, N) dense, with fond-blank frames where neither content nor paint exists — matching the preview canvas.

## Canvas clear lifecycle

| Option | Description | Selected |
|--------|-------------|----------|
| Top-level clear, no-content only | One clear at the top of renderGlobalFrame gated on !hasContentEntry (identity-transform clearRect, GL-path style). Content frames byte-identical; fond arrives via the flattened raster; gap frames export transparent. | ✓ |
| First-overlay clears | First visible overlay leg clears. Gap frames with zero visible overlays never clear (stale-pixel ghosts) without an extra fallback — more branch points for the same guarantee. | |

**User's choice:** Top-level clear, no-content only
**Notes:** Structural clarification surfaced here: content wins per frame, so cross-dissolve zones always have content entries and keep their internal clears untouched. Scope pinned to the export path; preview unchanged.
