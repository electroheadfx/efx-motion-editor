**Gathered:** 2026-09-28
**Status:** Ready for planning

<domain>
## Phase Boundary

Replace the salt-and-pepper bristle deposit with a structured, contained bristle footprint (real-paint tranche 1a, **R1**). The stroke raster becomes coherent translucent streaks laid along the ribbon — build-up by overlap, never by loud single pixels — and the `h > 0.72` paper cut that helped scatter the speckle is deleted with `drawBristleTraces`. R6 (one routine, two quality tiers) ships in this phase: it became mandatory once the fillFlat body left the paint path, because the live tier has nothing else to draw.

First geometry task is the deletion required by integration R3: remove `drawBristleTraces` and its `h > 0.72` paper cut (`brush/paint.ts:177`), zero call sites, install `drawBristleFootprint` in its place.

<decisions>
## Implementation Decisions

### Body vs streaks
- **D-01:** **Streaks are the body.** The footprint IS the mark — fillFlat leaves the mark-making path entirely. Overlapping streaks build the body (R1's "build-up by overlap"). A soft fill underneath is rejected: it would be a second implementation of the same phenomenon (04 R4) and would preserve the exact "flat fill + ..." shape R1 rejects. PIN 0 and thick==thin ride DiVerdi §4.1 thickness scaling (count down → thickness up), not a fill safety net. — **Reversibility:** costly — every deposit-path consumer and pin that measures body mass starts measuring streak overlap instead of a fill polygon; going back means restoring the 37× layering block and re-basing the PIN 0 harness.
- **D-02:** **Baked lateral density profile, geometry only** — dense/wide body lanes, sparse/thin rim lanes. Body lanes are specified to saturate to PIN 0 (1.0000) by overlap; rim lanes stay translucent. **Hard constraint:** the profile drives density, width, and overlap count only — **never a per-streak alpha ramp**. Per-streak alpha stays a single constant (rm2 forbids alpha modulation as an envelope mechanism; PIN 0 semantics are "pressure affects SIZE only"). The profile is baked lane geometry, identical at every water and every gesture. PIN 0 is a locked invariant, not a post-UAT tune target. — **Reversibility:** costly — the lane builder, the capture pins, and the UAT look all key on this profile shape.
- **D-03:** **Named soft-fill fallback opens on your UAT only.** The eye at zoom 4 is the oracle (project law: "native visual UAT is the oracle") — the only instrument that can tell intended bristle character from broken body coverage. Empirical ground: dh1's own pins washed against RED (`isolatedPx` 912 vs 889, `edgeCliffs` 21 703 vs 21 702), and 260924-m7w showed width-only pins missing a quasi-invisible stroke; a metric gate would add false confidence to a visual call. Scope of the UAT row: **"patchy" = holes in the stroke body where the lateral profile's body lanes should saturate, at zoom 4.** Rim translucency and dry-brush gap character are design (R2) and **NEVER** trigger the soft-fill fallback. R1 metric rows remain phase acceptance criteria — they just do not open this fallback. If opened, the change is an explicit named soft-fill addition — never silent.
- **D-04:** **Delete fillFlat paint call sites.** Every fillFlat call and the whole 37× layering block leave the paint deposit path. `fillFlat` the function survives, exported for `erase.ts` only — erase is out of scope and untouched (its R4 footprint change comes in 53.1+, when fillFlat is deleted entirely). Rejected quarantine-into-erase.ts: the "no second footprint implementation" acceptance row is **tree-wide**, and moving it would put a non-empty diff on out-of-scope erase.ts. Rejected a streak-pass repeat schedule: it would be a third saturation lever competing with the lateral profile and the §4.1 tier law ("help body saturation before UAT" is gate-tuning). Residual fillFlat export is a 53.1 cleanup note, not this phase. — **Reversibility:** costly — the deposit path has no fill body to fall back on once the block is gone.

### Live path timing
- **D-05:** **Ship the R6 tier now.** One `drawBristleFootprint(curve, params, tier)`: `tier=live` draws ~¼ brins with DiVerdi §4.1 thickness-up; `tier=final` draws full N ≈ radius. The scope lock's conditional R6 is **mandatory by consequence of D-01** — fillFlat is gone from the paint path, so the live tier must draw the footprint itself. The seeded layout (lanes + skips, arc-length-keyed in `traceSeed.ts`) is **shared and tier-independent**; the tier varies **count × thickness only**. Visible holes are a property of the shared stream, never of which individual streaks a tier happens to draw. Budget: if the measured live tier breaks the ~16 ms frame, the lever is DiVerdi §4.1 taken further (fewer, thicker), **measured first** — not a proxy mark, not a second routine. The ~¼ constant is R6's existing value; tuning it along the 4.1 curve after measurement does not reopen the architecture. — **Reversibility:** one-way — the live/final signature and the shared seeded stream are the deposit contract; splitting them later is the second implementation 04 R4 forbids.
- **D-06:** **Refine on release.** During the gesture the live tier draws the in-progress mark; on release the finalize pass redraws the same seeded stream at full N. **One visible settle at lift.** The settle changes only count × thickness — finalize adds detail, never rewrites the mark. Full-tier work stays off the gesture path (*"le geste prioritaire"*). `createPaintStrokeRasterContinuation` is reused as the incremental live raster builder — its chunking grows the live mark, it is **not** a finalize schedule. UAT row: one settle at lift; silhouette and gap positions identical across the settle; no second settle mid-gesture. If finalize of a very long stroke freezes rather than refines, the lever is to run that pass off the gesture path and present it as one settle — **not** chunked in-gesture finalize, never a second routine.
- **D-07:** **Final tier only feeds wet/physics.** The live tier is display-only: it draws the in-progress mark from the shared seeded stream and **writes nothing to the wet buffer**. On release, finalize draws the full-N footprint and that **single full-N deposit** is what the wet/physics simulation consumes. One deposit law (Q10, spec 04) stays clean. All existing deposit laws (PIN 0/0b body opacity, envelope `W_visible ≤ 8`, `DEPOSIT_KEEP_TIER = 70`, `DRY_ALPHA_THRESHOLD = 1`) keep measuring that one full-N deposit — the same artifact physics reads. **Pinning this is mandatory now that live draws the footprint: the live raster must never be routed into the wet buffer.** UAT row: wet/physics deformation appears only on the settled full-N mark; no physics-driven change to the in-progress stroke; no ghost density after the settle (one deposit, not two). — **Reversibility:** one-way — two deposits across the settle would make finalize rewrite the mark (R6 forbids) and would double-count every deposit law.
- **D-08:** **Capture-pin both tiers = identical gap positions + same silhouette with DiVerdi §4.1 thickness tolerance — never strict pixel containment** (live is fewer-but-thicker, so "final covers live" would false-fail at brin edges). This is a geometric invariant, not a look judgment. The harness rasterizes the same stroke at `tier=live` and `tier=final` and asserts: (a) **identical gap positions** — the shared skip stream (`traceSeed`, arc-length-keyed) is the gap oracle; a hole in live is the same hole in final; (b) **same silhouette** — both tiers clamp to the same ribbon footprint scale (one scale expression), with the §4.1 thickness tolerance and nothing stricter; (c) **the settle adds only detail** (count × thickness), never a new hole or a shift. Built as an extension of the existing `depositSpeckleCapture` dh1 harness (in-scope) — no new infrastructure. Reported with the R1 rows as phase acceptance evidence, **never as a gate on the look**. A tier-local skip bug (e.g. a tier reading a different seed) shows as a boil at the settle; this pin catches it before UAT.

### Streak value character
- **D-09:** **Uniform base color.** All streaks use the base color; the per-lane `×0.7` / `×1.4` value modulation is the pepper and is removed. Transparency carries the bristle character **through coverage geometry, not a per-lane alpha parameter**. Today's per-point alpha noise is the alpha half of the salt-and-pepper and is removed with it. A per-lane alpha profile is out of 52.4: (a) it would make PIN 0 saturation a per-lane gamble (a dipping per-lane alpha makes `1−(1−α)^k → 1.0000` flaky — cf. 260924-m7w); (b) it would be a second load-model, stealing R2's named role (gesture-driven translucency) and R3's (charge/depletion) — same logic as value modulation stealing spec 02 granulation; (c) rm2 stays clean: the form is held by include/exclude at `DEPOSIT_KEEP_TIER`, never an alpha fade. **Named fallback (same UAT-only pattern as D-03):** if UAT at zoom 4 reads the rim as too hard-edged, the iteration is a **baked lateral alpha profile** — deterministic, gesture-independent — never a per-brin random alpha. UAT row: at zoom 4 no light/dark striping; the body reads flat base color at saturation; rim translucency and bristle character come from coverage (thin/sparse lanes), not from value noise. — **Reversibility:** costly — every capture and UAT row is written against a flat base color body.
- **D-10:** **One alpha constant, both tiers.** A single constant streak alpha at `tier=live` and `tier=final`. Coverage parity rides DiVerdi §4.1 thickness alone (count down → width up, area preserved); the capture-pin's thickness allowance is the only tier difference. If live ever reads denser or lighter than final, the lever is the §4.1 width constant (geometry), measured at UAT — **never a second alpha**. Per-tier alpha is out: compensating coverage with alpha is exactly the modulation rm2 forbids, and two alphas would be two looks to keep in sync, weakening "finalize refines, never rewrites."
- **D-11:** **Strip all non-constant alpha terms.** Both are removed: `nA` per-sample alpha noise (the seeded salt-and-pepper's alpha half) and `pressureMod` (`0.3 + p*0.7` — that is gesture translucency = R2, out of scope, and it fights PIN 0 "pressure affects SIZE only"). One constant alpha per streak; pressure keeps its **width** lever only (`pMod` / SIZE). Geometry carries everything else: lateral density profile, §4.1 widths, shared skips. **Acceptance pin (source-shape, same pattern as the `Math.random` and `getImageData` gates):** no non-constant alpha term in the deposit path — alpha is a literal or a single named constant, **never** a function of pressure, velocity, arc length, or per-sample noise. Any future light-pressure translucency is R2's named role in 53.1+, not a hidden term here.
- **D-12:** **Width noise (`nW`) survives as bristle thickness geometry, under two named bounds.** DiVerdi §4.1 "thin bristles" is a thickness story; per-streak thickness variation is what makes a lane read as a bristle instead of tape. Value noise is fake pigment, alpha noise is fake load, **width variation is real bristle geometry**. **Bound (a):** `nW` is a **low-frequency arc-keyed bristle gauge** (seeded, coherent — a bristle thickens and thins slowly) — **never** high-frequency per-sample jitter, which would ragged-edge the streak back into salt-and-pepper. **Bound (b):** a **width floor above the sub-pixel hairline** — every trace stays inside the spec's sub-2 px bound **with a real minimum**, so it cannot alias into edge speckle. Same shared seeded stream at both tiers, so the silhouette parity pin holds. If UAT at zoom 4 reads edge chatter, the lever is the `nW` amplitude inside bound (a) — never a second noise class, never back to per-point skips.

### Bristle placement
- **D-13:** **Poisson-disk tip placement** (DiVerdi §3.6) — one placement pass at tip setup. Research notes bless it as "borrow directly — better than our current uniform offsets" and flag it as still owed to spec 01. Replaces the current uniform lateral offsets + 0.06 jitter. The Poisson radius is an implementation constant (see Claude's Discretion). — **Reversibility:** reversible — the lane builder can fall back to uniform offsets without touching the deposit contract.

### Paper law
- **D-14:** **The footprint reads NO paper height.** The Curtis-style `h > 0.72` brin cut is deleted together with `drawBristleTraces` (spec 04 R3 — *"a sixth hidden modulation, and the source of the edge salt-and-pepper"*). **All paper coupling stays in roles 1-3:** (1) wet-layer `D-08` paper height modulates the deposit, (2) `drying.ts` paper height modulates drying, (3) `paperPass` at `_resolveFlattenedFrame` is the visible paper tooth. Role 4 (spec 02 granulation) is paper-independent. The four-role list is **closed** — a fifth texture-modulation role is prohibited, and `paperMod` stays deleted. The `h > 0.72` cut must not be reintroduced in any form. **This law MUST be lifted into `must_haves` at plan-phase**, alongside 04's prohibitions table. — **Reversibility:** one-way — any paper-height read in the stroke raster re-opens the exact salt-and-pepper mechanism this phase exists to remove.

### Claude's Discretion
- Implementation constants judged at UAT, not spec gray areas: **lane count, lateral profile curve, the single alpha constant, `nW` amplitude inside bound (a), the width-floor minimum inside bound (b), Poisson radius**. Same treatment as any other tuned look constant — measure/paint, report at UAT.
- Exact `drawBristleFootprint` signature, parameter object shape, and file layout inside `packages/efx-physic-paint/src/brush/`.
- Capture-pin mechanics inside the `depositSpeckleCapture` harness extension (D-08 asserts the three invariants; the fixture/capture plumbing is free).
- Whether `darker`/`lighter` hex helpers and the `nA`/`traceShapeNoise` alpha channel are deleted outright or left unused (source-shape pin forbids their use in the deposit path either way).
- Fallback trigger wording for the two named UAT-only doors (D-03 soft-fill, D-09 lateral alpha profile) in the UAT checklist.

### Must-haves (lift VERBATIM into `must_haves` at plan-phase)
1. **Paper law (D-14)** — the footprint reads NO paper height; the Curtis-style `h > 0.72` brin cut is deleted with `drawBristleTraces` (spec 04 R3). All paper coupling stays in roles 1-3 (wet-layer D-08, drying, `paperPass`).
2. **04-integration prohibitions table** — lifted VERBATIM per `52.4-SPEC.md` Part B (fifth role; `paperMod` fallback; second implementation; flattened-frame fork; CR-01/#79).
3. **`nW` bounds (D-12)** — (a) low-frequency arc-keyed bristle gauge, never high-frequency per-sample jitter; (b) a width floor above the sub-pixel hairline (trace stays inside the sub-2 px bound with a real minimum).
4. **Capture-pin form (D-08)** — identical gap positions + same silhouette with DiVerdi §4.1 thickness tolerance — never strict pixel containment (live is fewer-but-thicker).
5. **Soft-fill trigger (D-03)** — "patchy" = holes in the stroke body where body lanes should saturate, at zoom 4. Rim translucency and dry-brush gap character NEVER trigger the soft-fill fallback.

<specifics>
## Specific Ideas

- **DiVerdi §4.1 is the tier law:** thickness scales up as count scales down so live ¼ and final full N share coverage and silhouette. "The finalize then refines the live mark and never rewrites it."
- **DiVerdi §3.6 Poisson-disk tip placement** — "borrow directly; cheap, and better than our current uniform offsets" (research notes adoption table).
- **The mark must read as bristles at zoom 4** — directional translucent streaks aligned with the gesture. Your eye at zoom 4 is the oracle for the look; metrics are acceptance evidence only.
- **Row i / f discriminator:** a thick stroke must render as clean as a thin one (hairline `d3+ = 0` CLEAN / thick `d3+ = 386` FILTHY was the dh1 failure shape).
- **Product law:** *"le geste prioritaire — la peinture s'affiche en temps réel, la physique s'applique après sur des workers, le rendu se met en pause quand je peins."* Live redraw inside one frame at 60 fps (~16 ms); only the live tier may add cost to the gesture.
- **Bristle-thickness vocabulary** (from the Value checkpoint): *value noise is fake pigment, alpha noise is fake load, width variation is real bristle geometry.*
