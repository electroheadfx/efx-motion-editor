# Phase 52.1 — Security

> Per-phase security contract: threat register, accepted risks, and audit trail.

---

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| npm/pnpm registry → app | Dependency versions pulled from the registry at install time | package manifests / lockfiles |
| crates.io → Rust build | Cargo resolves tauri/webp/image from crates.io | Cargo.lock |
| JS (invoke) → Rust command | Untrusted frame bytes and dimensions cross the IPC boundary | raw WebP frame bytes |
| Rust command → libwebp | Malformed WebP bytes are handed to the decoder | raw WebP frame bytes |
| child webview → main webview | Frame bytes cross the apply-path boundary | raw bytes (not JSON) |
| LRU → compositor draw | ImageBitmap handles cross into drawImage; use-after-close is the risk | ImageBitmap handles |
