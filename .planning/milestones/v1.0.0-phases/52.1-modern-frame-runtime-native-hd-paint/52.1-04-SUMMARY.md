# Phase 52.1 Plan 04: Byte-Budgeted LRU + ImageBitmap Decode Summary

**Byte-budgeted 512 MB LRU as the single decoded-frame cache authority with ImageBitmap handles, refs-only lazy load, and neighbor prewarm riding the playback lookahead (D-08..D-14).**

## Performance

- **Duration:** 19 min
- **Completed:** 2026-09-06
- **Tasks:** 4
- **Files modified:** 9 (2 created + 7 modified)

## Accomplishments

- `frameLru.ts` — byte-budgeted LRU (512 MB ceiling) keyed by stable frame ID, with pinning and explicit `bitmap.close()` on eviction (D-09/D-10/D-11).
- `loadEfxPaintDocuments` retargeted to refs-only — project open returns `cachePath` refs with empty bytes, no per-frame `readFile` (D-08).
- `_compositorImageCache` absorbed into the LRU; `_compositorDecode` resolves the LRU handle keyed by `buildFrameBytesToken` (D-12). `rotoAlphaCanvasRegistry` stays (canvas registry, not a decode cache).
- Decode path retargeted to `invoke('decode_webp_frame', { bytes })` → `ImageData` → `createImageBitmap(imageData, { premultiplyAlpha: 'none' })` (D-13/D-14); ImageData is transient only.
- `prefetchNeighborFrames` decodes N+1/N+2/N-1 into the same 512 MB LRU, wired into `useRotoNavigationCoordinator` on playhead advance (D-10/D-03).

## Decisions Made

- `rotoAlphaCanvasRegistry` stays — it is a canvas registry for interpolation/reveal bake, not a decode cache; only `_compositorImageCache` was absorbed into the LRU.
- `decode_webp_frame` takes bytes (not a path), so fetch-on-demand is deferred to Plan 05; Plan 04's decode path is `invoke(decode_webp_frame, { bytes })`.
- `prefetchNeighborFrames` is wired via an optional `prefetchNeighbors` callback on `useRotoNavigationCoordinator` (layer-agnostic); the Studio closes over `launchContext.layerId`.
- ImageData exists only as the transient IPC→bitmap bridge, never stored.
