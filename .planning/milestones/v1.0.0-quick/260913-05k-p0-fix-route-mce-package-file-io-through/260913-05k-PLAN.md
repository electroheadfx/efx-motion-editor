The plan suites mock the ipc+fs boundary over an in-memory package, so the real permission layer was never driven.

Purpose: route every `.mce` package file operation through app-defined Rust commands (app commands are not capability-gated, so no capability file change is needed), make the failure surface impossible to miss, and add a fail-closed contract test so a renderer package-path plugin-fs call can never be reintroduced.
