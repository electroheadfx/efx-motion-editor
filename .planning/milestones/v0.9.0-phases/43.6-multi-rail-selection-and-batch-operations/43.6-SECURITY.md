# Phase 43.6 — Security

> Per-phase security contract: threat register, accepted risks, and audit trail.

---

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| rail UI gesture → session reducer | Untrusted pointer/keyboard input (modifier combos, stale targets) enters the set/solo reducer | Selection identities + gesture intent (session-only) |
| session set → document/history | The set is session-only; it must never cross into the persisted document, revision fingerprint, or bridge payload | None by construction — session signal is module-scoped, getFrames-only |
| child intent → parent transport | Move/delete/spacing intents cross the bridge as typed payloads; malformed or forged intents must never mutate | Typed intent payloads |
| proposal → accepted document | A stale or divergent proposal must never replace the canonical document | Canonical document authority |
| pointer session → prepare/commit ports | Drag-time input (delta, timing) is untrusted until the retained publication revalidates against the current revision | Drag delta + timing, commit revalidated |
| coordinator acceptedOutput → history allowlist | Untrusted operationKind crosses into the applied undo stack; the allowlist is the only gate | operationKind (closed-union batch kinds only) |
| child delete proposal → parent bridge | The child's proposed complete state is untrusted until the parent recomputes and exact-matches | Proposed complete-state fields |
| playback filter → canonical render | The solo/filter consumes cached frames only; the canonical render source is out of reach | Cached display frames only |
| class template → CSS compound selector | The armed/solo visual depends on the exact class pairing; no user-controlled input crosses here | Base-class literal |
| parent apply payload → accepted-command ledger | Selection fields cross into the ledger's before snapshot; stale selection corrupts undo/redo replay-target equality | Recorded before-snapshot selection |
