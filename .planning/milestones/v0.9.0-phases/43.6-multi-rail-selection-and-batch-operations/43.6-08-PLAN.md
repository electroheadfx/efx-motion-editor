<objective>
Bridge the two disconnected selection tracks so a plain-selected single rail becomes the rail-set anchor
on the first modifier gesture, and commit Loop Clip set membership synchronously on modifier clicks.

Purpose: Root cause RC-B (G-43.6-3/4/8) — handleSelectRotoKeyRail (L1296-1347) and handleSelectRotoLoopClip
(L1348-1428) seed the set exclusively from railSetSelection.peek() (null after a plain click), so the
reducer's null-toggle returns a fresh one-member set and the plain-selected rail is dropped. Root cause
RC-D (G-43.6-1) — range/union fail-closed on a null anchor; the same seeding bridge promotes a
plain-selected rail into the anchor (spec M1 'plain click moves the anchor to it'). Secondary G-43.6-8
contributor — PhysicsPaintLoopClipRail.tsx commits set membership ~250ms after the click (L237-241), so
Delete pressed in that window targets a rail not yet .selected and isPhysicsPaintRotoDeleteTarget blocks
it. The reducer's fail-closed semantics for genuinely malformed/anchor-less input are NOT touched.
Output: a pure seed helper, Studio handler wiring, a synchronous modifier-commit for Loop Clip rails, and
regression tests for each behavior.
</objective>
