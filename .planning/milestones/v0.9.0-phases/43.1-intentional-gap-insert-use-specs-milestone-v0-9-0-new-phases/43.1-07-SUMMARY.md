## Decisions Made

- Keep canonical path construction inside Rust. The command accepts no arbitrary source, canonical, or destination path.
- Treat publication as accepted immediately after successful first rename or replacement exchange; old-generation deletion reports status but never revokes accepted authority.
- Keep every persisted and returned sidecar path canonical. Staging path translation occurs only at the filesystem write boundary.
- Remove only direct sibling directories matching `.physic-paint-staging-*`; unrelated cache children are never scanned recursively or deleted.
