## Decisions Made

- Kept every active recovery artifact in `scripts/.action-transactions` with canonical UUID-derived filenames, rather than mixing temporary state with the retained history namespace owned by Plan 19.
- Used a separate committed marker as the durable logical cut: a tombstone without a marker is rolled back before scan; a marker keeps the library recovery-gated until exact frontend settlement.
- Wrote a cleanup-pending acknowledgement receipt before removing active files. If cleanup is interrupted, retry resumes cleanup without restoring the Action or repeating logical settlement.
- Preserved an acknowledged receipt after cleanup so the same identity returns safe idempotent success while any changed identity or token replay fails closed.
