## Decisions Made

- Centralized missing lifecycle precedence in `physicPaintStore.getRotoPhysicalRenderSource` rather than adding separate rules to frameMap, PreviewRenderer, and export.
- Kept the established interval resolver authoritative for ordinary source occurrences and unresolved placeholders. This preserves accepted Phase 43 behavior while the complete lifecycle classifier owns exact overrides, visible generated occurrences, accepted gaps, and ambiguous ownership.
- Used the complete canonical physical revision as the Group replacement equality boundary. Lifecycle-only changes are real document changes and must increment the existing visual invalidation Signal.
- Did not add a lifecycle Signal, compatibility shim, materialized frame cache, or second durable document authority.
- Left `frameMap.ts` and `previewRenderer.ts` production code unchanged because both already subscribed to `physicPaintVersion` and consumed the shared store seam; their new parity is proven by focused integration tests.
