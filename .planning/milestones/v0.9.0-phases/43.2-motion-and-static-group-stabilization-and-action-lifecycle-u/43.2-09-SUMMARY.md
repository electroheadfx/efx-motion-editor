## Decisions Made

- Regenerate deepens the existing Play Script controller rather than creating a parallel Group lifecycle module. Callers continue to learn one interface while the controller localizes saved-Action preparation, disclosure, rendering, and publication behavior.
- A shared Action ID is insufficient to authorize shared restoration. Groups must have the same attached Action and exact ordered source cycle; partial overlap is explicitly ambiguous and fails closed.
- Frozen impact is disclosure, not mutation authority. The final Action snapshot hash/revision and physical-document revision are checked again under the canonical lease immediately before physical preflight.
- Stored Group settings are the sole regeneration inputs. Mutable dialog mode, motion, or color state cannot alter the accepted restoration after impact preparation.
- The existing floating dialog changes mode in place. A focused effect synchronizes only with the external DOM: G3a starts on Keep local changes, returning restores the Regenerate trigger, and no backdrop or Tab trap was added.
