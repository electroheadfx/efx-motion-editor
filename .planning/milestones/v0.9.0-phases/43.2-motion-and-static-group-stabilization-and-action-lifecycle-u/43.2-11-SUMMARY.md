## Decisions Made

- Canonical UUID v4 tokens are enforced in TypeScript because Rust uses canonical UUID v4 tokens as durable journal filenames and replay guards.
- Generic physical hash/revision fields follow Rust bounded transaction-text rules, while retained integrity and impact digests require exact 64-character hexadecimal SHA-256 values.
- The status wrapper accepts prepared/committed records and durable cleanup/acknowledgement receipts; recover accepts only recovery-required or recovered-prepared outcomes; other valid-but-wrong command states fail closed.
- Complete expected prepare context is never sent to token-only Rust commands, but remains available to the wrapper so stale native replies cannot be accepted.
