## Decisions Made

- Kept exact file-byte SHA-256 separate from canonical JSON revision because Rust retains and verifies the original managed bytes, while the existing revision identifies parsed canonical content.
- Forwarded the opaque script-library authority only through the trusted Physics Paint launch context so the browser can invoke durable transaction commands without broadening ordinary bridge authority.
- Added one narrow token-discovery command because restart hydration cannot know the transaction token held by Rust durable state.
- Reused `applyCommittedReferencedActionDeletion` for initial and restart settlement so semantic recomputation, authority validation, publication, history, and replay behavior have one implementation.
