## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| fixture input → future parser | Malformed lifecycle objects must remain untrusted. | structured lifecycle JSON |
| child proposal → parent harness | Claimed impact and complete candidate are untrusted until validated. | proposal payloads |
| frontend preflight → Rust journal | Requests, revisions, tokens, and payloads are untrusted. | durable transaction commands |
| restart → ordinary scan | Recovery must finish before library availability; ordinary scans stay gated. | journal state |
| parsed document → cache pruning | Shared references must survive cleanup. | reference graph |
| rendered frame → Paint target | Shared or unresolved sources cannot be mutated directly. | paint/cache ownership |
| canonical store → all consumers | Consumer divergence or stale caches can alter output. | canonical document |
| Rust JSON → TypeScript | Native responses are untrusted until parsed. | transport responses |
| persisted project JSON / sidecars → canonical document | Historical structured input and claimed revision are untrusted until exact content validation. | legacy fingerprint |
| timeline selection → destructive command | Frame vs Group-Rail scope determines Delete Frame vs Delete Group. | selection scope |
| automated evidence → native approval | Headless tests cannot substitute for one frozen restarted parent/child lifecycle session. | UAT evidence |
