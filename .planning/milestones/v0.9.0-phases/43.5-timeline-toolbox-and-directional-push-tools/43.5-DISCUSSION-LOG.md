## Push boundary edge cases

| Option | Description | Selected |
|--------|-------------|----------|
| Reject with mapped reason | Fail closed when a source-attached Group in the moved set shares its source cycle with a fixed-side Group | ✓ |
| Pull family into the set | Silently include the outside shared-source Group | |
| Placement-only for straddlers | Move the source-attached Group placement-only, leaving source keys behind | |

**User's choice:** Reject with mapped reason (e.g. `Can't push: a Group in the moved set shares its source with a fixed Group.`)

| Option | Description | Selected |
|--------|-------------|----------|
| Preflight at hover | Straddled anchor shows unavailable cursor + guarded tooltip reason; drag never starts | ✓ |
| Reject on release | Drag previews normally; rejection on release | |

**User's choice:** Preflight at hover

**User-locked edge cases (final batch):**
1. Mutation lock: Push buttons disabled with mapped reason while mutations are locked; entering a locked state disarms an armed Push tool.
2. Armed state is session-only, never persisted; save/reopen always starts disarmed.
3. Select All disarms; multi-rail selection is Phase 43.6 scope — the moved set derives strictly from the drag anchor's position, never from any selection set.
