- prepare consumes `derivePhysicPaintPushSet` (D-17) for moved-set facts instead of doing set math itself — presentation and the committed resolver result can never disagree (Pitfall 4)
- `clampPhysicPaintPushDestination` is the only push delta authority; the publication reads the committed delta (`changes` role `moved`), preview-is-the-commit (D-14)
- The accepted copy publishes from the `.then(accepted => …)` continuation of `input.executePhysicalEdit` — a bounded Extract that never re-runs physical actions
- Push Left's live mirror uses U+2212 MINUS SIGN (`Push Left −12`) for typographic consistency with the U+2013 en-dashes already locked in the copy family
- commit revalidates the freshly recomputed break-aware proposal version and fails closed with zero mutation on mismatch — the stale-authority guard (T-43.5-01) catches break-collection AND structural drift

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 2 - Missing functionality] PUSH-06 history recording missing the push-rails operation kind**
- **Found during:** Task 2 (one-Undo/one-Redo history proof — RED exposed it)
- **Issue:** `isOrdinaryOperationKind` in `useRotoPhysicalEditHistory.ts` has an explicit allowlist that excluded `'push-rails'`. A push acceptance was therefore routed to the replay-acceptance branch: `pendingReplayRef` stayed null and availability remained `{undo:0, redo:0}` — the push command could not be Undo/Redo'd, breaking PUSH-06. This is the plan's known gap (the plan assumed the history hook would accept the new operation kind without calling out the allowlist).
- **Fix:** Added `|| kind === 'push-rails'` to the `isOrdinaryOperationKind` allowlist (between `move-key-rail` and `play-script`).
- **Files modified:** app/src/components/physic-paint/hooks/useRotoPhysicalEditHistory.ts
- **Verification:** "restores the complete pre-push state … through one Undo and one Redo (PUSH-06, 43.4 D-24)" asserts records, loopClips placementStart (7→9), breaks ([]→['A']), selection, and cursor all round-trip
- **Committed in:** 8751a903 (Task 2 GREEN)
