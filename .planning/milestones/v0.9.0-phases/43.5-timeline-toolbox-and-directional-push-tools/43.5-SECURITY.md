# Phase 43.5 — Security

> Per-phase security contract: threat register, accepted risks, and audit trail.

---

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| UI/bridge → resolver | The push intent crosses from UI-originated state into the pure physical authority; all fields are untrusted input | Typed push-rails intent (anchor + delta) |
| keyboard dispatcher → timeline actions | Shortcut routing must not be captured or suspended by presentation-only surfaces | Key events / routing intent |
| prepared publication → commit | Time-of-check to time-of-use: state may change between prepare and commit | Proposal + break-aware proposalVersion |
| UI copy → accepted state | Status copy must never claim a mutation the parent did not acknowledge | Presentation facts / accepted status |
| pointer events → session → prepare/commit ports | Gesture input is untrusted; the session must never mutate canonical state directly | Pointer delta, clamped signed delta |
| pointer/hover position → preflight/preview | Pointer position is untrusted; preflight must never authorize what the resolver would reject | Pointer projection (session-only) |
| session Signals → accepted document | Preview state must never cross into canonical state before exact parent acknowledgement | Session-only Signals |
| frozen build ↔ developer session | UAT evidence must come from the frozen commit, not a mutated hot-reload state | Frozen commit hash + evidence |
