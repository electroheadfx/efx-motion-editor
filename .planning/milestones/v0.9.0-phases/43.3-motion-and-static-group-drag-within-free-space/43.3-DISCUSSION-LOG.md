| Option | Description | Selected |
|--------|-------------|----------|
| First key gets break only if gap opens | Landing adjacent creates none; existing breaks travel with identity (43.1 D-14) | ✓ |
| Always break on moved first key | Suppresses legitimate interpolation | |

### Duplicated-placement break changes

| Option | Description | Selected |
|--------|-------------|----------|
| No break changes at all | Initial recommendation — refined by user | |
| Defensive breaks anyway | Contradicts non-materialization lock | |
| User free-text refinement | See notes | ✓ |

**User's choice (free text):** A duplicated shared-source placement never moves, clones, or retimes the shared source keys, and never changes breaks owned by those source-key identities merely because the placement moved. However, the placement move may update surrounding stable-key-owned break authority when required to preserve newly vacated or residual empty intervals: the next real key after a newly vacated interval owns or reuses the incoming break; existing destination-gap breaks are preserved and reused; no duplicate break or standalone gap record is created; all placement and break changes commit atomically with one Undo/Redo. If existing breaks already preserve every resulting empty interval, no break change is needed.

**Notes:** Vacating a duplicated placement can expose an interval that surrounding real keys would interpolate across, so break protection applies there even though linked occurrences are not interpolation products.

### Timeline-edge behavior

| Option | Description | Selected |
|--------|-------------|----------|
| Break only where interpolation would bridge | No successor/no predecessor = no break needed | ✓ |
| Uniform breaks everywhere | Guards nothing | |
| Claude's discretion | | |

**Area-close refinement (user):** Phase 43.2 Group-local deleted phases and `visibleRanges` move rigidly with the Group at their original relative source phases. They remain Group-local authority and must never be converted into neighboring-key interpolation breaks. Only external gaps opened by the drag may update stable-key-owned break authority.
