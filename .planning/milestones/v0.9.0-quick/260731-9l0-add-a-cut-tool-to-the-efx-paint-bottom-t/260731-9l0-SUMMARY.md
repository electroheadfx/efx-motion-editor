# Phase quick-260731-9l0 Plan 01: Add a Cut tool to the Efx Paint bottom timeline toolbar Summary

**One-liner:** Fail-closed Roto key Cut (Scissors button + Cmd/Ctrl+X) composing the existing session clipboard copy with the atomic delete-key-group transaction, with full clipboard rollback on delete failure.

## What Was Built

- **`cutKey` action in `useRotoKeyUtilities`** (`app/src/components/physic-paint/hooks/useRotoKeyUtilities.ts`): snapshots the pre-cut clipboard, reuses the extracted `resolveCopySelection` helper (shared with `copyKey`, behavior byte-identical), then runs the injected `deleteSelection`. Delete resolving false or rejecting restores BOTH `session.copiedKey.value` and `copiedKeyRef.current` to the exact pre-cut value and publishes a cancel/error status; success publishes a concise cut message and keeps the clipboard reusable for repeated Paste.
- **Studio wiring** (`PhysicsPaintStudio.tsx`): `cutRotoFrame` re-checks `rotoPhysicalActions.canDeleteFrame` (publishing the verbatim `deleteDisabledReason` when unavailable) before delegating to `cutKey(rotoPhysicalActions.deleteRotoFrame)`; wired into the keyboard actions object and the strip props.
- **Cmd/Ctrl+X route** (`physicsPaintStudioKeyboard.ts`): the existing meta copy/paste branch now includes `'x'`, inheriting every guard verbatim (no shift/alt, no repeat, preventDefault, mutationLocked, editable-target exclusion). `app/src/lib/shortcuts.ts` untouched per locked decision.
- **Cut toolbar button** (`PhysicsPaintWorkflowStrip.tsx`): Scissors icon between Copy and Paste (final DOM order Copy, Cut, Paste, Delete), guarded-icon pattern with `canCutRotoKey = canCopyRotoKey && canDeleteRotoKey` and a disabled reason chained verbatim from the copy or delete controller port; no `destructive` class.
- **Regression coverage**: new `useRotoKeyUtilities.test.ts` (10 tests), 8 new Cmd+X keyboard cases, strip source-contract updates (seven guarded actions, Cut order/gating/tooltip contract). Full physic-paint suite: 550 passed, 0 skipped/todo. Typecheck clean.
