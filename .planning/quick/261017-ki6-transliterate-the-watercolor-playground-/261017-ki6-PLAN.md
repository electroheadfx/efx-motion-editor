1. **`paperFieldFS`** (~274-488) — per-texel `vec3`: `x = height 0..1 (mean ~0.5)`, `y = mottle 0..1 (0.5 neutral)`, `z = fleck 0..1 (0.5 none)`.
   - Primitives 1:1: `pcg`, `hash`, `hash2`, `vnoise`, `fbm`, `cells`, `blobs`, `segment`, `fibres`, `specks`, `hexDist`, `warp`.

   - Output clamp: `clamp(f, 0, 1)`.

2. **`paperLightFS`** (~493-507) — lights the height from the upper left; packs `r = lit relief (0.5 flat)`, `g = height`, `b = mottle`, `a = fleck`.
   - Neighbour taps l/r/b/t = field height at ±uTexel.
   - `n = normalize(vec3((l - r) * uBump, (b - t) * uBump, 1))`
   - `L = normalize(vec3(-0.5, 0.6, 0.62))`
   - `lit = 0.5 + (dot(n, L) - L.z) * 1.3 + (f.x - 0.5) * 0.25`
   - Call-site bump (Engine.ts:833): `uBump = (preset.bump * 1.4) / scale`, `scale` = units per texel.

3. **`PAPER_COLOUR` / `paperColour`** (~510-518) — sheet colour from a paper texel:
   - `c = base * (1 + uTexture * ((paper.r - 0.5) * 0.32 + (paper.b - 0.5) * uMottle * 2))`
   - fleck: `fl = (paper.a - 0.5) * 2 * uTexture`; then `fl < 0 ? mix(c, uFleckTint, -fl) : mix(c, min(base * 1.1 + 0.02, 1), fl)`
