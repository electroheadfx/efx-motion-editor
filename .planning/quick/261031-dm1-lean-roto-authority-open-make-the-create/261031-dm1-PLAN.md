<objective>
Make the Physics Paint Studio's Roto "Create Rail" dialog open without shipping raster bytes across the bridge: the open path asks the parent for key identities only, keeps every scalar it uses, and the same full-authority protocol stays byte-for-byte unchanged for every other call site.

Purpose: `openConfirmation` currently blocks the dialog behind an authority round-trip that base64-encodes and transports every real key's WebP bytes twice (once inside `physicalRecords[].payload`, once again in `frames`), then throws all of it away. On large rails that costs roughly a second per open and scales with key count and frame size.

Output: an optional identity-only authority request mode (validator + parent branch + result echo), a port option threaded through the child hook and used ONLY by the open path, fail-closed guards where publication builders genuinely need payload bytes, and co-located vitest coverage for the validator, the parent, the hook and the controller.
</objective>
