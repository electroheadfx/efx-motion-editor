<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| engine stroke state -> brush script store | Engine-owned points are projected and retained across frames; a bad projection or a stale frame must never leak into a later frame's script. |
| pointer gesture -> engine script mutation | The overlay sends a mutation id and a delta into the engine; an unvalidated id would delete or move an unrelated stroke. |
| physical key edit -> retained brush frames | Key delete/ripple/slot delete invalidates captured frame anchors; a stale entry must fail closed. |
| DEV devtools console -> script stats | window.__EFX_SCRIPT_MEMORY__ exposes retained sizes; it must never exist in a production build. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-g4p-01 | Tampering | brushScriptEditionPort.deleteStroke/moveStroke/stepStroke | high | mitigate | Engine public APIs validate `mutationId` against a live `tool === 'paint'` action and no-op (false) for unknown ids; the port only lists ids captured for the current frame; the port gates every op on the Studio physical-mutation lock. |
| T-g4p-02 | Denial of Service | capture path | medium | mitigate | Stroke completion only marks the frame dirty (O(1)); normalizeLogicalBrushes runs at frame leave, Move entry, an explicit edit, or a DEV read. Flush is a no-op when the frame is clean. |
| T-g4p-03 | Information Disclosure | window.__EFX_SCRIPT_MEMORY__ | low | mitigate | Existing double guard: `import.meta.env.DEV` and `typeof window`; the global is installed with a configurable property only in a DEV build and reports numbers only. |
| T-g4p-04 | Tampering | prune law / retained entries | medium | mitigate | Entries are deep-frozen at capture; pruning is fail-closed (drop every frame >= the first divergent app frame) and never remaps; a failed physical replace prunes nothing. |
