| repository/config -> Tauri bundler | Tracked release settings determine Hardened Runtime, resources, entitlements, bundle formats, and signing behavior. |
| local signed artifact -> Apple notary service | Signed app/DMG and API-key authentication cross the network boundary; only Apple's Accepted result is authoritative. |
