One press duplicates the stroke(s) as ONE undoable script edit and ONE re-bake, placing each clone directly above its source and selecting the clones.

## Decision: clone semantics (recorded in this plan, no CONTEXT.md exists)

- The clone is a full recorded stroke: fresh mutation id through the ONE allocator, fresh ordering key, fresh per-frame serial, same key anchor as the source. It is recorded first (top of payload) then placed directly ABOVE its source through the shipped `placeAquarelleStrokeInScript`.
- One press is ONE edit: one `before` snapshot before any mutation, one `after` snapshot at the end, one edit id, one re-bake, one ledger entry. Selection is set by the STUDIO caller on success, never by the edit builder, so a refused re-bake cannot move the user's selection.
- The duplicate inherits `diffusionFrames` verbatim (a clone of a settled stroke should look settled). `aquarelleStrokeToPaintStroke` is the id-allocation crossing and ignores `diffusionFrames`, so the allocator's guard is untouched.
- No paint-seed salt bump: the fresh mutation id already changes `hashMutationId`/`mixStrokeSeed`, so the clone paints its own texture without re-rolling the source.
