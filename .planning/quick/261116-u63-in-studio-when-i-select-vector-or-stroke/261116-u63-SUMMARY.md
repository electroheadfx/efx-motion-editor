## Accomplishments
- `cloneAquarelleStrokeForDuplicate` rebuilds every mutable carrier (params, points and each point, pointTicks, toolOverrides, anchors and each anchor's in/out) as fresh objects, with optional keys present only when the source carried them and no mutationId.
- `beginAquarelleCloneEdit` records one or many clones as ONE before/after edit: all ids allocated before the first record, each clone stamped above the whole recorded timeline, then placed at its source's current position-from-top minus one; key anchors inherited with a caller-key fallback; selection untouched.
