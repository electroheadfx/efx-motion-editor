<objective>
Replace the eager, corrupting brush-script replay on navigation (quick 261023-h9v) with a lazy ledger attach over cached pixels, and a faithful live-deposit rebake that runs only when the user first edits the frame.

Purpose: h9v made every arrival at a hydrated key synchronously replay the entire retained script through `restoreStrokesBaseline` -> `redrawAll()` (233 ms for the light fixture, 1.1 s for heavy at 1920x1080), and that same replay ran with `{ replay: true }`, skipping `prepareWetLayerForStroke`. The skipped dry/keep-box step makes every replayed stroke accumulate wet material, so strokes grow and gain halos and the painted look is destroyed. Navigation should be instant and display the pixels that already exist; the expensive faithful reconstruction belongs at the first edit, where it is affordable and invisible.

Output: an engine ledger-attach + faithful-rebake API with a frame-visit replay mode, paint-settings capture and restore, the studio navigation seam reordered (pixels first, attach second), all script-edit call sites routed through the faithful path, the tight navigation budget removed in favour of completeness plus a measured edit-affordability cap, and measured attach/rebake timings recorded in the SUMMARY.
</objective>

## Ground truth from h9v

- `redrawAll()` (EfxPaintEngine.ts ~4331) calls `applyStrokeToEngine(..., { replay: true })`. `applyStrokeToEngine` (~3821) only calls `prepareWetLayerForStroke` when `!options.replay`, so every replay pass leaves wet material behind; `prepareWetLayerForStroke` (~3329) is the keep-box/`forceDryAll` step that makes a live stroke's deposit local and dry.
- `restoreStrokesBaseline` (~2060) validates the whole list, rebuilds `allActions` / `strokeStack` / serials / `nextMutationId`, clears history, marks the composite dirty, and calls `redrawAll()` — the whole replay, synchronously, on navigation.
- `loadCachedRotoReferenceFrame` (useRotoReferenceController.ts) calls `engine.clear()` and then `engine.setPreviewBaseImageUrl(...)`. Ordering matters: the cached pixels must be loaded BEFORE any ledger attach, because `clear()` wipes the ledger.
- `clear()` (~1703) resets gesture state, `allActions`, `strokeStack`, serials, undo/redo/history, wet/fluid and preview base, then notifies `'clear'`. The completion listener ignores `'clear'` (`applyCompletedBrushMutation` returns early), so the store survives navigation.
- `prepareWetLayerForStroke` reads `this.lastStrokeBounds` for the local keep-box union and `redrawAll`'s `resetReplaySurface` (~3310) does NOT reset `lastStrokeBounds`.
- Measured replay costs at 1920x1080 (h9v): 10x60 = 233 ms, 25x90 = 601 ms, 40x180 = 1102 ms, 40x600 = 1492 ms; one diffusion frame = 705 ms; per-stroke fixed cost ~17.5 ms (full-frame saved-wet scan).
