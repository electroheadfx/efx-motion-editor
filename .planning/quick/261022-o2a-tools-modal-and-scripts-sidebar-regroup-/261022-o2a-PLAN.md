<objective>
Regroup the Physic Paint script surfaces around two distinct families of actions.

1. Tools popover: split the former six-clone "Scripts" row into **Scripts** (Save, Load + Apply, Create Rail — acting on saved project Scripts) and **Living Script** (Copy, Apply, Clear — acting on the in-memory script buffer), and remove the Delete Script and Refresh Scripts clones.
2. A new floating script picker: Tools `Load + Apply` and `Create Rail` open it, the user picks any project Script (no sidebar selection required), and the pick applies that script or opens the existing Create Rail dialog for it.
3. Sidebar Scripts tab: drop the top Delete Script and Copy Script buttons, give the four remaining toolbar buttons visible labels, and move deletion to a per-row hover/focus trash that still funnels through the existing confirmation.

Purpose: the user asked for a sharp split between saved project Scripts and the living script buffer, and for the Tools modal to be usable without first selecting a script in the sidebar.
Output: two Tools sections, a new picker dialog + its Studio intent state, a four-label sidebar toolbar, per-row trash with focus restoration, and updated source-contract tests.

Scope: UI arrangement, one new dialog component and its owner state. No controller changes, no persistence changes, no new dependencies.
