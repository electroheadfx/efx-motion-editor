<objective>
Add a session "Script" switch to the Physics Paint Studio top bar: On (default) keeps today's watercolor stroke→script recording; Off paints pixels without writing any script entry.

Purpose: the user needs to paint pixels on a key without the stroke entering (or extending) that key's watercolor script. The switch is a paint-time mode, not a script operation — Apply/Copy/Paste/Load/duplicate and the Raster action keep their current behavior.

Output: one session signal plus a gated record seam in aquarelleRecordState.ts, a single peek-gated branch in handleAquarelleStrokeEnd, a per-launch reset, a `role="switch"` pill in the top bar's left cluster, and plain CSS in physicsPaintStudio.css.

Locked decisions (from the task contract — never revisit):
- K-01 (user decision 1): with Script Off on a key that already has a script, the existing script STAYS in the script/Memory store and remains editable. New strokes are simply not recorded. No warning modal, no confirmation.
- K-02 (user decision 2): Water color only. Do not gate, modify or route around the Brush script capture stores (brushScriptRecordState.ts) or any Brush-module path.
- K-03: explicit script actions (Apply / Copy / Paste / Load / create rail) and the duplicate-script path at PhysicsPaintStudio.tsx:3758 are NOT gated — the switch concerns strokes the user paints, not script operations.
- K-04: Preact + @preact/signals only. No useState, no React idioms, no new dependency, no new design system, no Tailwind. Signal setters are compare-then-write; render bodies only read.
- K-05: session-scoped — the signal is never persisted in the project document (.mce format unchanged) and resets to On at every Studio launch.
- K-06: `vitest run` only, never watch; never start the dev server (the user runs it).

Known caveat (user accepted — document in the SUMMARY, do NOT add a modal):
- Unrecorded Off strokes are not in the script. A later script rebake (delete / move / Apply / Play) composites the existing script over the key's PRE-SCRIPT durable base, so those unrecorded strokes can be dropped by that rebake. This is the accepted trade of keeping the existing script editable while Script is Off.
