Move the approved Studio script snapshot from the machine app cache into the `.mce` package, in a folder per layer, resolved exclusively through the existing `scriptLibraryAuthority` capability.

**Scope laws (from the brief — non-negotiable):**
- Storage path: `<package>/scripts/<layerId>/<trackId>-v1.snap` — one folder per layer, one file per track, version in the file name AND in the unchanged SNAP v1 header.
- The package root is resolved ONLY through `ScriptLibraryState` from the opaque authority token. The renderer must never carry a raw package path for snapshots.
- Optional `authority` header on the existing read/write commands. No authority (unsaved project) keeps the app-cache path. A stale/unresolvable authority is refused on read and write — never redirected to a guessed path.
- Restore precedence: package copy first when an authority resolves; package file MISSING → app-cache fallback (l35 migration); package copy corrupt/foreign/newer-version → fail closed with the EXISTING status message and never consume the cache.
- `migrate_saved_projects` must carry `scripts/<layerId>/*-v1.snap` on Save As / Duplicate, reusing the existing identity validation; never merge files across layers or tracks.
- Preserve `scriptLibraryAuthority` in `acceptPhysicPaintProjectContextPayload` (bounded, optional) — the same defect family as the 24e71c34 `projectId` fix. The controller reads the authority LIVE at prepare/restore time.
- Reuse the SNAP v1 codec, controller queue/debounce/close laws, key validation, atomic write and fail-closed labels. Do not rewrite any of them.
- Out of scope: `.mce` manifest field, document schema change, new dependency, renderer filesystem access, gauge/purge UI, brush navigation rework. No `.mce` manifest or document-schema file may change.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| studio webview -> Rust commands | the renderer supplies a package identity (`projectId`, `layerId`, `trackId`) and an opaque authority token that select a filesystem location |
| authority token -> package root | the capability is exchanged for a canonical package path inside Rust; a stale token must never be mapped to a guessed root |
| package bytes -> studio webview | an on-disk file (possibly corrupt, foreign or a newer version) is decoded into live stores |
| Save As migration -> destination package | snapshot folders are copied into a staged destination that is rolled back on failure |
