**Area A (6a791018):** `.physics-paint-right-panel` top inset 20px → 10px (sides stay 10px). `WatercolorModuleSection` drops the parent `SectionLabel` — `AquarelleGlobalsPanel` is the first child, no comment naming the retired title. `RightPanelBrushTab` mounts `BrushResponsePanel` above `WatercolorBrushLibrary` (gate kept).

**Area D (23b7e0f4):** `BrushModuleSection` order is Brush smoothing (with bottom padding) → Shape detail → Blending → Spread → tool-gated Erase.

**Area B structure (d670eafd):** Paper tab is a flat list — `RuleSectionHeader` titles Texture / Real / Procedural replace the sticky toolbar bars; Transparent + White lead the Real section as paper-card cells (still `onBackgroundChange`, hook kept via a `display:contents` wrapper); every card is thumb + uppercase name BELOW (WatercolorBrushLibrary label pattern, no caption overlay); grid is 2 columns (`CELL_SIZE` 64 / `GRID_GAP` 8 stay); the inner `maxHeight`/`overflowY` goes so the outer `SidebarScrollArea` owns scrolling.

**Area B thumbs (0fb634c4):** new `paperThumb.ts` paints the engine sheet plus a diagonal granulating ultramarine wash (the `paperSwatchFS` port: `x = u*0.62 + (1-v)*0.38`, wash past x≈0.6 with a bright tide line, pigment `pow(rgb(0.3,0.38,0.72), gran*tide)` granulated by the sheet's green channel). Paint-once Map cache keyed by `(id, size)`, blit via `drawImage`. Real jpgs decode-once content-keyed. Never `toDataURL`/`toBlob`. `PaperCell` procedural cells and `warmProceduralReliefThumbs` ride the new cache.

**Area C top bar (5d43ed5d):** Water / Edges / Grain sliders follow Opacity in Water color mode only, reading `aquarelleParams.water/.edge/.granulation` and writing `setAquarelleParam` (same seam as the Paint-tab globals). Brush mode keeps Brush size + Opacity only. No Paper grain widgets — the Grain strength / Grain scale / Background absence pins stay.

**Area C Paint-tab pair (aba0b8c1):** both modes' Paint tabs start with a Brush size + Opacity pair above the module switch, calling the SAME routers the top bar uses. Routers extract to identity-stable `useCallback`s — one write-through pair, never a second setter. Display rules match the top bar (live aquarelle size in watercolor, `settings.size` otherwise). The I-05 shared-opacity wrapper class stays gone.
