Root cause (verified): tier math uses full-FILE peak count against the TRIMMED clip width, so short windows fall to tier1 and the In/Out slice maps to 2-3 peaks stretched across the bar; peaks are then rescaled to fill the bar, so slip swims instead of sliding.

Source-space draw law (W1 — mirror the physic-paint stain):
- sourceScale = barW / max(1, trimFrames) with trimFrames = outFrame - inFrame (equals frameWidth when barW is exact).
- sourceX = barX - (inFrame + slipOffset) * sourceScale; sourceW = max(1, totalAudioFrames) * sourceScale.
- Draw peaks at source positions px = sourceX + (pi / fullPeakCount) * sourceW (optionally limited to indices that land in the visible bar, +/- 1 peak). Clip to the bar rect. Trim reveals a cut; slip slides content; In-from-left moves the window with the bar. Never map peaks onto barW by visiblePeakCount.
- Tier: pixelsPerSourcePeak = sourceScale * (totalAudioFrames / fullPeakCount); <1 => tier1, >4 => tier3, else tier2 (same intent, source scale).
- Keep fill, centerline, edge lines, muted treatment, and the entire gain/fade block unchanged.

Fit to view law (W2):
- Viewport frames (content space, same units as scrollX/frameWidth): frameWidth = BASE_FRAME_WIDTH * zoom from timelineStore; trackArea = viewportWidth - TRACK_HEADER_WIDTH; visStart = scrollX / frameWidth; visEnd = (scrollX + trackArea) / frameWidth. Import BASE_FRAME_WIDTH/TRACK_HEADER_WIDTH from TimelineRenderer (no new store API).
- Clip bar span [offsetFrame, offsetFrame + trimFrames]. Intersection L = max(offsetFrame, visStart), R = min(offsetFrame + trimFrames, visEnd).
- No-op when R <= L (nothing on screen) or the clip bar is already fully inside the viewport.
- Source at timeline frame t is inFrame + slipOffset + (t - offsetFrame). Crop: newIn = inFrame + slipOffset + (L - offsetFrame), newOut = inFrame + slipOffset + (R - offsetFrame), newOffset = L, slipOffset = 0. Preserve a 1-frame minimum span (clamp newOut >= newIn + 1). Clamp newIn to [0, totalFramesInFile - 1] as needed.
- ONE undo: add audioStore.fitToView(trackId, {inFrame, outFrame, offsetFrame}) writing inFrame/outFrame/offsetFrame/slipOffset: 0 from a single snapshot. Do not chain setIn + setInOut + setSlipOffset (three undos).
