# Quick 260913-05k — Route .mce package file IO through Rust commands (P0)

**Status:** Automated-ready — **NATIVE UAT OWED (user-run)**. The executor does not claim native UAT passed; the native steps below (including the "empty .mce package" re-check) are the remaining gate.

## Provenance

The live P0: package saves died silently. The renderer drove `@tauri-apps/plugin-fs` at the package staging root — `forbidden path: …/.efx-paint-package-staging-<uuid>` — because the capability grants only `fs:scope-appdata-recursive`. The only feedback was a `console.error`. App-defined Tauri commands carry no capability scope, so the package IO legs (layer sub-file write/read, staging discard) now run as Rust commands; the machine-local frame-cache legs genuinely live under appdata and were left alone.

Second half of the P0: even after the reroute, *any* future save/open failure must be impossible to miss. All 13 failure sites (3 in `shortcuts.ts`, 3 in `Toolbar.tsx`, 2 in `WelcomeScreen.tsx`, 3 in `main.tsx`, 2 in `autoSave.ts`) now end in a blocking native modal carrying the underlying error text.
