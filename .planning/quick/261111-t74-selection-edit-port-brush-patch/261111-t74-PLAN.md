<objective>
Make a brush change reach the SELECTED recorded strokes as one undoable edit: extend the appearance patch with a brush id and per-brush multipliers, validate and merge them in the one record-state write, and expose a peek-only selection edit port that the Studio binds to the appearance handler it already ships.

Purpose: Phase 61's selection surface can currently change params, colour, curve mode and geometry of the selected strokes, but it cannot change the brush that paints them — the recorded `brushId` and the eight `toolOverrides` multipliers are only ever written at record time by `aquarelleBrushForActiveTool`. This quick adds the data plumbing so a later brush pick can commit onto the selection through the existing one-edit/one-undo appearance door, without a second edit path and without a new history entry per stroke.

Output: `brushId`/`toolOverrides` on both appearance patch types, whole-patch validation and a complete-bag merge inside `updateAquarelleStrokesInScript`, the module-variable selection edit port with its peek-only active probe, one Studio registration forwarding to `handleAquarelleAppearanceStrokes`, and behavior fixtures plus two source pins. No UI consumer is wired in this quick; the visible brush-pick surface is a follow-up.
</objective>
