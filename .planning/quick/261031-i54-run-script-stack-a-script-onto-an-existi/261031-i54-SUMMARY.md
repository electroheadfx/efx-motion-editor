# Quick Task 261031-i54: Run Script — stack a script onto an existing Paint rail

**Run Script stacks onto the rail under the playhead, grows the source cycle extend-only, keeps or replaces per-key scripts, composites pixel-only rails over their existing picture, adopts the run's bake settings, and resolves collisions in one atomic undo — Quick A accepted at UAT round 1.**

## Accomplishments

- Destination resolution is one pure module over the canonical `derivePhysicPaintRotoLoopRanges` output: playhead membership, repeated-occurrence mapping to `phaseOrigin + cycleOffset`, fragment-gap aware, ambiguous/reveal/override refusal.
- Extend-only cycle and lifecycle growth: appended source keys, repeat unchanged, infinity lifecycle-less, Truncate caps growth at the run boundary or parent end without ever shrinking an existing rail.
- Keep script ON for flag-on rails: a raw union re-bake (existing recorded events + this run's strokes) plus append recording; flag-on Keep OFF purges and replaces.
- Pixel-only rails (no saved per-key scripts) are composited over each touched key's current payload and record nothing; a newly appended tail key uses a blank base; an unresolvable payload fails closed with zero writes.
- A stack run exposes Rail Type (Motion/Static), Motion wiggle and Color, seeded from the rail; the rail adopts the run's `mode`, `motion` and `overrideColor` in the same commit.
- Collision surface: Cancel / Truncate (default) / Overwrite, where Overwrite removes the victim Loop Clip in the same commit (keys survive as ordinary keys) and one undo restores it; victim overrides and stale choices fail closed.
- The open stack surface is pinned, while confirm revalidates the live rail before any bake; a divergence aborts with zero writes.
- The footer reports the whole operation: Preparing (indeterminate bar), Rendering x/y, Rebuilding/Compositing, Committing, Recording key scripts; stale progress is cleared on open and the idle seed effect no longer re-derives rails on every playhead tick.
- The dialog's cards are reusable components (`PhysicsPaintPlayScriptCards.tsx`); creation, stack and Reveal compose the same views.
- Full suite 360 files / 6,736 passed / 1 skipped / 96 todo; `tsc --noEmit` clean; no persisted schema/format change.
