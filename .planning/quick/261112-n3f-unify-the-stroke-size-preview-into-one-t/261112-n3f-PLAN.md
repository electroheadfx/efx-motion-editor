<objective>
Unify the two stroke-size previews behind the one shipped "Preview stroke size" switch and remove the envelope's interior self-intersection lines.

Purpose: the switch and the Edit-path auto-preview were two parallel implementations of the same idea — the switch drew a paint-footprint band (a constant approximation for vector strokes that ignored their per-anchor widths) while opening a path edit drew the per-vertex envelope for free. One control (OFF by default) must own the vector preview, and the per-vertex envelope it now reveals must stop painting the crossing straight lines that its closed, self-intersecting ring produces inside the band.

Output: `VectorPathOverlay` gated on the shared signal with a split fill/edge envelope (masked edge); `resolveAquarelleStrokeBandPx` resolving vector strokes to the same per-vertex envelope; both test suites repointed and extended.

Scope boundary: UI/geometry-display only. NO UI removal — the one switch already exists in the Draft strip (`stroke-settings-preview-stroke-size`), there is no second button to delete; the duplicate is behavioural. No CSS edit, no new dependency, no polygon union, no SVG filter (the file's own law), no change to `projectVectorPath` / `buildEnvelope` / `buildStrokeBandCached`, no change to `ScriptStrokeOverlay.tsx`, no document write, no new signal, no new effect, no Studio render-body signal read. `vitest run` only, never watch; no dev server.
</objective>
