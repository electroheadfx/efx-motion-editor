Remove the `ModuleSwitcher` from the main editor top bar. The switcher was meant to concern only the Studio, never the editor; the product has ONE paint engine (Water color), and Krita was never developed and is not planned. Purpose: this is a v2.0.0 pre-publish fix. The editor must ship without a module switcher and without a Krita placeholder, the dead component and its CSS must leave the tree, the docs must stop claiming an inert v2.1.0 slot, and a source-scan pin must prevent the switcher from returning to the editor Toolbar. After this fix, the signed release must be re-run.

Output: a stripped editor Toolbar, the deleted `ModuleSwitcher` component plus its two test files, a cleaned Studio stylesheet, a new regression pin, and corrected v2.0.0 documentation. No engine, persistence, version, or release-artifact change.
</objective>
