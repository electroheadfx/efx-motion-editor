**Discretion decisions (documented per MUTABLE-SCOPE AUTHORITY #3786):**

1. **Arm precedence:** when both Alt (erase) and Cmd (move) are armed with
   Paint selected, move wins — `combineEffectiveTool` returns 'move'. The
   Cmd arm reads as the more deliberate "grab" intent.
2. **No script gate on the Cmd arm:** arming Cmd mirrors the Alt arm's
   existing gates (shortcut target, Paint selected, engine present, not
   mutation-locked, no key repeat) — script presence is enforced where it
   matters (a drag with no script entry finds no target and is a no-op), so
   the arm itself stays symmetric with the UAT-closed Alt module.
3. **No separate move undo entry:** a move does not push an undo
   checkpoint (matching erase's established non-resurrection semantics);
   `redoStack` is cleared so a stale redo checkpoint can never repaint the
   pre-move pixels. Undo after a move undoes the last paint checkpoint;
   redo is unavailable. Native UAT row (e) states this explicitly.
4. **Preview look:** hover ghost uses the stroke's own color (fallback
   `#888888`) at opacity 0.6 with its render radius — reads as "this stroke",
   unlike erase's red/0.3. Pointer-hand glyph reused (extend
   `cursorGlyphMode` + `overlayBoundsForCursor`).
5. **Filename kept:** the Cmd arm lives inside
   `physicsPaintTemporaryErase.ts` (dual-arm module) rather than a new file —
   both arms feed the ONE `combineEffectiveTool`, and a sibling module would
   either import circularly or depend on listener-registration order. Header
   documents dual-arm ownership; existing `handleTemporaryErase*` functions
   stay byte-identical (new `handleTemporaryMove*` functions are added).
6. **Rail disabled semantics:** `disabled = globalDisabled || !scriptInMemory`.
   The global mutation-lock `disabled` prop still applies; script presence is
   the only *feature* gate (per intention).
7. **Greyed-but-active while Cmd-held on an empty frame:** the rail highlights
   the Move item visually (via `readEffectiveTool`) even if the icon is
   disabled for lack of script — accepted cosmetic state; no drag can start
   anyway (no target).
