<objective>
Add an opt-in, off-by-default choice in the Create Rail dialog — for Paint Rail (Motion / Static) and Reveal Photo Rail (Motion / Static) — that makes every key of the resulting Rail individually editable from its own script.

Purpose: today `PhysicPaintRotoLoopClip` is the smallest editable unit; its `sourceKeyIds` are opaque baked pixels with no script payload, so one wrong key forces a whole-rail Regenerate. This plan stores the rail's script identity plus a small per-key override set so a single key can be re-derived from the script without touching its neighbours, while an untouched rail stays byte-identical to a pre-quick rail.
Output: two additive-optional Loop Clip members (a rail flag and a per-slot override collection), a Create Rail toggle wired across all four creation variants, an "Edit Key" affordance that re-bakes exactly one key, and Regenerate protection for edited keys.
</objective>
