<objective>
Fix the preview/export parity defect on the milestone's core deliverable: a track whose paper was customized (the Studio's own initial paper is canvas1 + grain 0.45) exports the DOCUMENT-level fallback fond instead of its own paper, so exported frames do not match what the Studio shows for that track.

Two heads, one cause — the fond resolution is split across two sources:
1. The DRAW authority (`_resolveDocumentFondInstruction`) reads only `document.background.fallback`, so the composite/preview/export/monitor draw the document fond regardless of the track's paper.
2. The PRELOAD GATE (`collectRotoPaperTextures`) reads only the active track's mirror, so it preloads a texture the draw never uses and fails to preload the one it does — leaving the export free to bake the deterministic color-fill fallback (`#f4efe3` and friends) into early frames.

The fix is the resolution SOURCE, per 53-CONTEXT D-09 and the user's expected law: the ACTIVE TRACK's paper mirror first, the document-level fallback only when the track has no paper of its own — consumed by both the draw and the gate (one authority, two consumers).

RED FIRST, diagnose-don't-assume: the executor first pins today's actual behavior with failing tests on BOTH surfaces and records the raw output, then applies the minimal read-path fix. The audit framed this as "the collector reads the fallback"; the code at the plan base says the opposite (the collector reads the mirror, the draw reads the fallback). The RED run defines ground truth — record which source wins today per surface before touching production code.

Scope discipline (guardrails, verbatim intent): fix the resolution source ONLY — no change to paper texture formats, no change to cache keys, no change to the preload pipeline shape. Multi-track: each layer resolves its own active track's paper. Do not touch the two-solo-system behavior (the fond resolution must not start consulting visibility/solo).

Purpose: make the export write what the Studio shows for a track's paper, closing the last user-visible parity gap before the Phase 53 acceptance pass.
Output: the shared fond resolution + gate accessor + memo-rotation guard, with RED-then-green tests on both surfaces and the rewritten superseded D-11 contract.
</objective>
