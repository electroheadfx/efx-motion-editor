<objective>
Add a **Draft** mode to the Move/Edit Stroke settings dialog (the surface shared by Water Color Select mode and Brush Move). Draft ON suspends the watercolor engine re-render only: every edit still commits to the script exactly as today and stays undoable, the committed sheet stays frozen at its last rendered pixels, and the stroke overlay shows the current edited script. Draft OFF — and each of the five exits dialog close, frame change, play, export, save — performs exactly ONE recompute from the current script. A dedicated strip below the header carries the Draft switch and a cache-visibility eye that hides the frozen sheet in both modes.

Purpose: judging a session of move/scale/recolor edits today costs a full watercolor re-bake per edit (~1.5 s each). Draft makes the script the fast editing surface and defers the expensive pixels to one explicit recompute, while a main-realm autosave gate and hard exit aborts guarantee a script can never be persisted against a frozen pixel sidecar.

Output: one session-only `draftMode` signal, one `draftPixelsDirty` invariant signal and one `frozenCacheVisible` signal beside `strokeSizePreview`; a `setDraftMode` that refuses to leave Draft while pixels are dirty; the Draft reset attempt on the `setAquarelleSelectMode` off -> on edge; one shared `settleDraftScript` Studio seam (single-flight, no undo entry, clears dirty then flips Draft false); Draft short-circuits in the six edit handlers plus the replay ports; the dialog strip whose OFF click routes through the settle; the cached-base leaf hide; the five exit wires (dialog close, frame change, play, flush for save/export) each acting on the settle result, with save/export aborting in the main realm; one new `lib/physicPaintDraftMode.ts` transport with the autoSave gate, a 5s heartbeat and a 20s staleness belt; and the tests. No schema, persistence, engine-math, hit-test, bounds, stack or punch change; `aquarelleStrokeBand.ts` is reused as-is and never modified.
</objective>
