## Decisions Made

- Roto ownership still builds the pre-state identity map separately; the shared map only supplies destinations. This keeps the unowned-frame discard and fail-closed rules byte-identical.
- The watercolor remap treats `playFrame ?? 0` as the normalized anchor and only re-anchors an entry whose normalized anchor differs, replacing objects rather than mutating snapshot-held references.
- A remap that repairs a stale timeline reference or re-anchors a counter also counts as an effective change and commits with one bump.
- Malformed layouts return `null`; the brush ledger keeps its fail-closed prune fallback and the watercolor state is left untouched.
