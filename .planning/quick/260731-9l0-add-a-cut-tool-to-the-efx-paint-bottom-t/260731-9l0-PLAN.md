<objective>
Add a Cut tool to the Efx Paint (Physics Paint Studio) bottom timeline toolbar. Cut reuses the
existing copy machinery (`useRotoKeyUtilities` / `session.copyKey` / `session.copyKeyGroup`) and the
existing delete machinery (`rotoPhysicalActions.deleteRotoFrame`, which already routes 2+ selected
keys through the atomic `delete-key-group` transaction = one Undo step), composed fail-closed:
nothing happens unless both halves can succeed, and the clipboard is restored if the delete half
fails. Expose Cmd+X in the Studio keyboard route only.

Purpose: Users can move Roto keys off the timeline into the reusable clipboard in one gesture,
matching standard Cut semantics and the existing Copy/Paste/Delete UX.
Output: Cut button (Scissors icon) between Copy and Paste, Cmd+X shortcut, fail-closed `cutKey`
hook action, and focused regression tests.
</objective>
