<objective>
Floor a bristle response's dab spacing at one device pixel and compensate that dab's ink by exactly the ratio the floor applied, so acrylic Bristle Round/Flat stops emitting several dabs per device pixel below ~30 px while every size above the crossover renders byte-identically to HEAD.

Purpose: the artist's v2.2.0 report — "the acrylic small-brush is very slow below ~30 px". Each acrylic dab costs ~9 draws (carrier + pickup snapshot + 3 deposits + cover + touch + relief + wet), and `trace()` emits dabs every `radius * spacingFrac` with no floor: on a 1080-tall sheet a Size 1 Bristle Round deposits a dab every 0.40 device px and a Size 10 every 0.74 device px. The floor caps the waste at one dab per pixel. The same pass closes a latent infinite-loop bug: when a pressure/width drop shrinks the spacing below the carried arc length, `pos += spacing - s.carry` never advances and `trace()` spins.

Output: one ~25-line change inside `Engine.ts` (trace spacing + brush dab amount + loop guard), one WebGL-free unit suite that pins the law, a reusable small-brush probe with a frozen HEAD baseline and an AFTER capture that proves the identity rows, and a SUMMARY carrying the before/after evidence table and the artist's UAT rows.
</objective>
