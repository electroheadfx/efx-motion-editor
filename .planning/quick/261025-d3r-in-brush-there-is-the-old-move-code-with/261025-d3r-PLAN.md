<objective>
Remove the legacy pointing-hand cursor from Move mode in the Brush module of Physics Paint Studio, while keeping held-Cmd momentary Move and its hover target/preview ribbon, and keeping the erase hover hand untouched.

Purpose: the hand was extended from the erase hover to the move hover in 261004-dn5. Held-Cmd only calls engine.setTool('move') (the temporary-move module exposes no cursor API), so the engine keeps the cursor visible and draws its old hand during the hold. That is the behaviour the user reported and could not reproduce. Persistent Move already hides the engine cursor behind the 261022-pim / 261023-g4p overlay, so the hand survives only on the momentary path (and on any future path that forgets to hide the cursor).

Output: one erase-only hand predicate in the engine, consumed by both the glyph mode and the cursor restore box, plus a reworked move-cursor contract test. No host-side suppression is added — the single engine law covers every trigger.

Decision map: D-01 (no Move hand) and D-05 (engine as the single source) are the code change; D-02 (held-Cmd kept, hover target + preview ribbon retained) and D-03 (persistent Move overlay untouched) are the preserved behaviour the tests pin; D-04 (erase hand unchanged) is pinned by the untouched erase suite and the cross-check in the reworked test.
</objective>
