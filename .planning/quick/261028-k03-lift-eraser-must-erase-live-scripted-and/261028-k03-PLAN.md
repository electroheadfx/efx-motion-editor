<objective>
Make Lift (tool id `lift`, label "Lift") erase paint in all three frame states the user works in — live sheet, cooked frame under a script, and raster-only key — with the script and cache layers staying consistent, and settle the three-state truth table first.

Purpose: `Engine.lift()` currently multiplies only `ink.read` and `wet.read` (Engine.ts:1869-1886), and the displayed density is `inkA.x + fixedA.x` (shaders.ts:612), so pigment baked into `fixed` by an explicit Dry cannot be lifted.
