<objective>
Make Emboss signed: one -15..15 slider whose negative half subtracts paint
thickness while painting, so the artist can smooth an existing impasto and keep
the paint.

Purpose: the relief field is additive-only today (`brushRelief` /
`bristleReliefPass` blend FUNC_ADD, ONE,ONE; Emboss 0 draws nothing). Repainting
over an emboss leaves its height untouched and keeps lighting the new colour with
the old relief; only Lift erodes thickness, and it erases the pigment too. The
artist's decided design is one signed Emboss row whose negative value erodes the
relief target with the dab's own mask, using the engine's multiplicative erode.

Output: a signed `emboss` in the ONE canonical mapping, a negative branch at the
existing relief gate with two erode passes and ONE calibration constant, a
-15..15 slider band, pinned laws for both, and a probe scene that proves the
smoothing, the kept paint, replay parity, and both byte-identity gates.
</objective>
