<objective>
Add one creation-time boolean, "Paint seed variation", to the Create Rail dialog for all four rail variants (Paint Motion, Paint Static, Reveal Motion, Reveal Static). ON seeds each stroke's render RNG with a pure mix of its existing traceSeed and the local output frame, so the same stroke paints with a different brush texture frame to frame. OFF (default) is byte-identical to today.

Purpose: the aquarelle engine draws every stochastic paint channel (dab scatter, tip angle/jitter, spatter, granulation) from one per-stroke RNG. Re-seeding it per output frame gives hand-made variation without touching geometry, brush presets, pressure, timing or the paper seed — but the sheet is cumulative, so a true per-frame re-pattern requires one full replay per output frame. The plan measures that cost and gates the app wiring on an explicit human decision; it never falls back to deposit-time-only salting.

Output: a pure seed mix plus reusable-sheet seams in the packages, a measured per-frame replay bake mode with an unchanged OFF path, and the dialog/controller/persistence/renderer wiring so the option survives reopen, Replay, Regenerate and duplication.
</objective>
