## Chosen constants + rationale

- `STREAK_ALPHA = 0.5` — inside the user-locked [0.4, 0.55] band; the old 0.995 conflict value is gone. Saturation is composite: 1-(1-0.5)^4 x (1-0.25)^m >= 0.99 at the band edge with margin (worst observed >= 0.9977 at r16 arithmetic).
- `SOFT_EDGE_ALPHA = 0.25` — top of the plan's ~0.10-0.25 discretion; the edge law 1-0.5^4 x (1-SOFT)^8 >= 0.99 needs SOFT >= 0.199, so real margin remains.
- `CORE_MAX_TRACE_WIDTH = 2`, `MAX_TRACE_WIDTH = 6`, `SOFT_WIDTH_MUL = 2`, `WIDTH_FLOOR = 0.5` — D-12(b) two-tier: soft raw x 2 tops ~6.9 px so 6 admits the full soft width; visible core never exceeds 2.
- `HAIRLINE_RADIUS = 8` — plan-bounded: above the radius-3 real-raster cell, below every lane-field pin (16/20/32/40); `8 < 8` is false, so radius-8 battery cells stay on the lane field while radius 3/6 take the hairline path.
- `BODY_WIDTH_MIN/MAX = 1.7/1.9` — guarantees the deterministic 2 px core clamp at p=1 (2.04 > 2).
- `BODY_GAP_PX = 0.24 / BODY_MIN_GAP_PX = 0.14 / BODY_MAX_REACH_PX = 0.28` — band-edge one-sided window holds 4 core lanes inside the 1 px half-width; interior samples see ~7-8.
- `RIM_COUNT_RATIO = 0.45` — density ratio (1/1.04)/(0.45/0.96) = 2.05 >= 1.5 with rim span capacity for the Poisson floor at r40.
- `POISSON_FILL = 0.7`, `BODY_BAND = 0.52`, `NW_AMPLITUDE = 0.4`, `NW_ARC_SCALE = 0.1` — unchanged from 52.4-02.
