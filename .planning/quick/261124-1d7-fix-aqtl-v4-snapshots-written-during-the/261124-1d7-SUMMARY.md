## Accomplishments

- The two relief bits (0x20 erode, 0x40 deposit) are accepted and discarded: a 0x70 body decodes to exactly one drawn stroke with `engine.vectorDrawn === true` and no `reliefOnly`/`relief` key, and `reader.atEnd()` holds (no byte consumed, same buffer length).
- Convergent repair pinned: re-encoding the decoded events is byte-equal to the ORIGINAL drawn bytes (flags back to 0x10), so the next routine save drops the legacy bits from the file — the withheld-save latch can clear and stay clear.
- Fail-closed kept: 0x80 still throws `invalid-value`; a too-wide mask cannot silently accept future payload-bearing flags.
- Encoder authority pinned: a stroke carrying every supported marker (anchors + anchor colour + curve mode + drawn) writes exactly 0x1d at the flags byte, with `(flags & 0x60) === 0`.
- No wire change: AQTL stays v4, no payload byte is added or consumed, and the pinned lengths are unchanged (minimal 96 B, FIXTURE 3752 B).

## Decisions Made

- Bits 5/6 are **provenance markers with no payload**, so acceptance cannot desync the stream; they are discarded, so no reverted relief behavior returns.
- Kept the constants private; the acceptance is a wire-compat exception, not a public API.
- Retargeted instead of deleting the stale reserved-bit pin, so the fail-closed guard keeps a live pin (0x80).
- Retargeted pin note: with bit 5 legal, the old `VECTOR_FLAG_ANCHOR_COLOR | 0x20` patch would still have thrown, but only accidentally (bit 0 cleared → byte 74 fails the presence check). It is no longer a reserved-flags pin; 0x80 restores that meaning.
