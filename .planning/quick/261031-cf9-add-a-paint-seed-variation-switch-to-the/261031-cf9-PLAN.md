<objective>
Add a "Paint seed variation" switch to the Move/Edit Stroke settings dialog (Geometry tab, first row) that makes each committed re-bake of the selected watercolor stroke(s) re-draw their stochastic paint texture under a new, persisted paint seed — the same per-output-frame effect Create Rail's `paintSeedVariation` gives, but driven by persisted stroke state so the same saved project always replays the same pixels.

Purpose: the aquarelle engine draws every stochastic channel (deposit pigment/water, dab scatter, tip angle jitter, spatter, granulation, shape noise) from one per-stroke RNG seeded by `traceSeed`. Re-salt that seed and the paint texture changes while points, pressure, brush params, tool overrides and the paper seed stay exactly as recorded. OFF must remain byte-identical to today.

Output: one reserved persisted param (`paintSeedSalt`) folded into `traceSeed` by the ONE engine→host projection, a re-roll law wired into the five script-edit doors plus the Rebake action (as undoable edits), and the switch row in the Stroke settings sheet.
</objective>
