```glsl
float e     = exp2(2.0 * uFeatherFalloff - 1.0);                       // the ONE shipped bias
```

### A2. The neutral path MUST keep PRE's source, not just its arithmetic

The first law landing FAILED the identity gate: sizes 12 / 40 / 200 differ
(`digestPigment`), size 4 passes. Cause: the law hoisted two PRE inline statements into
temporaries (`float s = smoothstep(...)` feeding `shaped`, and
`float heightPaper = mix(grainHeight(...))` feeding `height`), so the driver's codegen moved
by 1 LSB on 2–4 px. Mathematically identical, byte-different.

**Rule:** the two statements PRE evaluates on the neutral path must remain byte-identical in
SOURCE, and every new expression must live inside a uniform-gated branch:

```glsl
float featherStart = uFeatherEdge * (1.0 - mix(uFeatherMin, uFeatherReach, uFeather));
// PRE statement, UNCHANGED, no temporaries hoisted out of it:
float featherShift = uFeather * uFeatherShift * smoothstep(featherStart, uFeatherEdge, lateral);
if (uFeatherFalloff != 0.5) {
  featherShift = uFeather * uFeatherShift
               * pow(smoothstep(featherStart, uFeatherEdge, lateral), exp2(2.0 * uFeatherFalloff - 1.0));
}
float height = mix(grainHeight(css, uAxis), 0.5, rimCalm);   // PRE statement, UNCHANGED
if (uFeatherNoise * uFeather > 0.0) {
  float paperH = height;
  float e = exp2(2.0 * uFeatherFalloff - 1.0);
  float bodyW = pow(clamp(lateral / uFeatherEdge, 0.0, 1.0), e * uFeatherNoiseDepth);
  float w = uFeatherNoise * uFeather * bodyW;
  float radiusPx = uRadius * uSheet.y;
  float bandPx = (uFeatherEdge - featherStart) * radiusPx;
  float periodPx = clamp(bandPx / uFeatherNoiseFeatures, uFeatherNoiseMinPx, uFeatherNoiseMaxPx);
  float rimScale = uFeatherNoiseRefPx / periodPx;
  height = mix(paperH, grainHeight(css * rimScale, uAxis), w);
}
float threshold = uGrain * (1.0 - height) - 0.25 + featherShift;   // PRE statement, UNCHANGED
```

Do NOT hoist `smoothstep(...)` into a `float s`, do NOT rename `height` to `heightPaper`, and
do NOT introduce any other preconditioning of the neutral path. The `== 0.5` branch is
replaced by this statement shape: on the neutral path the PRE line executes and the new line
is inside a uniform branch.

**If identity still fails after this restructure, STOP and report to the artist** with the
measured pixel count and delta. Do NOT redefine the gate, do NOT accept a tolerance, and do
NOT delete the law to make the gate pass — the artist owns that decision.
